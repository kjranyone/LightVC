## Abstract

低遅延ボコーダの開発では、解析再合成（copy-synthesis）で参照信号との客観指標を最適化するのが標準手順である。本レポートは、この手順が**設計者が気づかないまま退化する**こと、そして退化が**1つ塞ぐと次へ移る**ことを、単一の実装上で 3 回連続して実証した記録である。

同一のボコーダに対し PESQ-wb 4.070 / 4.024 / 4.174 を順に達成し、いずれも独立レビューにより「参照信号をパラメータの名目で転送していた」と反証され、実装者側の再現検証を経て取り下げた。3 形態はそれぞれ (I) 倍音バンクの完全再構成フィルタバンク化、(II) 振幅の押し付けと位相復元、(III) 出力側界面の未宣言と乱数実現の暗記 であり、**互いに独立な機構**である。

さらに、退化を止めるために自然に思いつく門が 2 つとも無効であることを示す。**(a) 白色雑音再構成テストは 1周期1ノードの倍音バンクに対して原理的に不適**（そのバンクは担当帯域内で本質的に臨界標本化であり、窓長に依らず必ず反応する）、**(b) 「パラメータ数 < サンプル数」は暗記を防がない**（実測: 1.02M パラメータでも同じ学習曲線が出、6.4M＋情報ゼロ条件付けが 1.0M＋本物の条件付けを上回る）。

有効な門は**レート台帳**（各枝が消費する実数/秒 ÷ 標本化周波数）と、**学習を伴う場合の 4 点検査**（出力側レート台帳／乱数種の振り直し／未学習データ／無関係条件付けでの対照）であった。

**§2 に理論を置く。** 3 形態はいずれも初等的に説明される: 倍音バンクが窓長 2 周期未満で恒等写像になること（定理 1、Poisson 和）、冗長な STFT 振幅が信号を一意に決めること（定理 2、既知の位相復元一意性の適用）、固定乱数場への決定論的回転が情報を運ばないこと（補題 4）。効かない 2 つの門にも理由がある: 1 周期 1 ノードの倍音モデルは自帯域に対しちょうど臨界標本化であり（命題 3）、白色雑音テストはそこで窓長を測ってしまう。パラメータ数の門が効かないのは、退化が学習データの暗記ではなく**低次元の乱数場の効果の暗記**を要求するからである（命題 5）。**否定的主張は測定ではなくこの理論に立脚する。測定はその確認である。**

これらを適用した最終構成は、未使用発話で PESQ 3.16。同じ包絡にオラクル位相を与えた天井が 3.851、恒等写像の上限が 4.644 である。すなわち**位相を完璧に予測できてもこのパラメータ化では 4.0 に届かない**。純 DSP の天井は「ノイズ枝に位相モデルが無いこと」ではなく**包絡の表現力**が決めている。

### Frontier（§12 の要約 — 結論だけ要る読者へ）

**不足はレートではなく写像である。**

```
Q*(条件付け 0.31×, 学習された写像)  ≥ 4.228     BigVGAN、同一ハーネス
Q*(条件付け 0.5×,  手設計の写像)    ≤ 3.851     本レポート、オラクル位相を与えた上界
```

より低い条件付けレートで 1.07 上回られている。系 6（レート単調性）は「レートを上げねば上がらない」とは言っていない —— 言っているのは「写像を固定すれば上界に漸近する」だけである。本レポートが 3.16 で止まったのは**手設計だったから**であり、レート制約のためではない。

**低遅延側の SOTA は Wavehax 系**（TF 領域のエイリアシングフリー複素スペクトログラム推定＋調波事前分布、0.623M、HiFi-GAN の 4.5%；MS-Wavehax は因果・先読み 1 フレームで MOS ≈ 自然音声）。その前提「時間領域の点ごと非線形は必ずエイリアシングを生む」は、本プロジェクトが独立に到達していた診断と同じである。

**本プロジェクトの非自明な資産**: Wavehax の事前分布は `Σ_k √(0.02/K)·sin(2πkφ + kψ_rand)` で位相はランダム、運ぶ情報は f0 のみ。`rddsp` コアは同じ位置に**測定された声門相対位相**（周期波形相関 0.987）・MVF・非周期性をレート 0.07× で供給する。調べた範囲でこれを事前分布に用いた神経ボコーダの報告は無い。

**H-F**（§12.4、反証可能）: 同一の因果 TF ネットワークに与える事前分布を、Wavehax 式 f0 正弦波から `rddsp` コアに差し替えると上回る。**第一報**（§12.8、同一ネット 0.501M・同一損失・同一学習・話者素、事前分布のみ差し替え、利得整合済）:

| | 事前分布単体 | step 500 | ネットの寄与 |
|---|---|---|---|
| arm A（f0 正弦波） | 1.4034 | 1.1582 | **−0.25** |
| arm B（`rddsp`） | 1.4663 | 1.5428 | **+0.08** |

同じネットが arm A の事前分布からは離れて悪化し、arm B からは改善する。**ただし step 500 まで、8 発話、絶対水準 1.5（DSP コア 2.97 に遠い）であり、H-F の確認ではない。**

**H-G**（§12.5、本当の研究課題）: 変換時に声門位相は測定できないので、**声門パルス形状が低レート・話者特徴的で content から予測可能**でなければ H-F は製品に持ち込めない。これは本プロジェクトの「萌え＝構音クセの clone」を位相の側から定式化したものである。

**目標指標について**: PESQ 4.0 に到達しているのは大規模非因果 GAN のみで、パラメトリック系に前例が無い（§9.4）。敵対的損失が PESQ を下げるのは FINALLY・MetricGAN が報告する既知の挙動であり、失敗ではない（§12.7）。**次に定義すべきは目標値ではなく目標指標である。**

## 1. 問題設定

### 1.1 対象

- **信号**: 44.1 kHz、単一話者（女性、f0 中央値 170–280 Hz）、8 秒クリップ
- **ボコーダ**: 倍音枝（声門閉鎖点で測った複素振幅を持つ加算合成）＋ 息枝（時変フィルタで整形した雑音）。分割は MVF（最大有声周波数）
- **指標**: PESQ-wb。両信号を 16 kHz にリサンプルし、相互相関でアラインしてから評価
- **制約**: 実時間・低遅延（合成側に未来参照を持たない）

### 1.2 基準点（実測）

| | PESQ |
|---|---|
| 恒等写像（同一格子で STFT 往復） | **4.644** ← 指標そのものの上限 |
| 完全な振幅＋ランダム位相 | 2.078 ← 位相を持たない枝の床 |

**4.644 は「完璧な再構成」の値である。** これを常に併記しないと、4.0 という数字が上限のどこにあるか判断できない。本レポートの全ての退化は、この上限に近い値を「ボコーダの性能」として報告しかけた事故である。

## 2. 退化の理論

本節は、以降の 3 節で報告する現象を、測定に先行して説明する枠組みを与える。主張は 2 つの定理・1 つの命題・1 つの補題からなり、いずれも初等的である。**否定的な主張（このベンチマークは退化する）を測定だけで述べないために置く。**

### 2.1 設定と定義

解析再合成ベンチマークを三つ組 `(A, S, Q)` とする。

- 信号 `x ∈ R^N`、標本化周波数 `f_s`、信号クラス `X`
- 解析 `A: x ↦ θ`（パラメータ）
- 合成 `S: θ ↦ y`
- 評価 `Q(x, y)`（大きいほど良い）

設計とは `(A, S)` の族の中で `Q(x, S(A(x)))` を最大化することである。合成が枝に分かれる場合（本レポートでは倍音枝と息枝）、枝 `b` は帯域 `B_b`（帯域幅 `W_b`）を担当し、パラメータ `θ_b` を受け取る。

**定義 1（レート）** `θ_b` が毎秒 `T_b` 個の実数からなるとき、枝 `b` の**レート**を `ρ_b = T_b / f_s`、**臨界レート**を `ρ*_b = 2W_b / f_s` とする（`2W_b` は帯域 `B_b` の Nyquist 自由度 [実数/秒]）。

**定義 2（透過的枝）** 枝 `b` が**透過的**であるとは、`S_b ∘ A_b` が `B_b` に帯域制限された `X` の任意の元を所定の精度で復元することをいう。

**主張の形式化.** ベンチマーク `(A, S, Q)` の測定値がモデルの仮定について情報を持つのは、**全ての枝が非透過的であるときに限る**。透過的な枝を含む構成では、`Q` はその枝における `S_b ∘ A_b` の可逆性を測っており、モデルの妥当性を測っていない。以下はこの一般論の具体化である。

### 2.2 定理 1 — 倍音バンクが恒等写像になる窓長条件

倍音枝を次で定義する。位相トラック `Φ[n]`（`Φ' = 2πν₀`、`ν₀ = f₀/f_s = 1/P`、`P` は周期の標本数）に対し

```
z_k[n] = x[n] e^{−j2πν₀kn}        （復調）
a_k[n] = (z_k * w)[n]              （長さ L の窓 w による低域通過）
h[n]   = Σ_k a_k[n] e^{+j2πν₀kn}   （再変調と加算, k ∈ Z）
```

**定理 1.** 上の合成 `x ↦ h` は LTI であり、その伝達関数は `G(ν) = Σ_{k∈Z} W(ν − kν₀)`（`W` は `w` の DTFT）である。さらに `w[n] = 0 (|n| ≥ P)` ならば

```
G(ν) = P · w[0]   （周波数に依らない定数）
```

すなわち **`L ≤ 2P` のとき、倍音バンクは入力の調波性に関係なく信号を定数倍で復元する。**

*証明.* 復調は周波数軸のシフトだから `Z_k(ν) = X(ν + kν₀)`、窓かけは `A_k(ν) = X(ν + kν₀)W(ν)`、再変調は逆シフトで `B_k(ν) = X(ν)W(ν − kν₀)`。総和して `H(ν) = X(ν)·G(ν)`。`G` は `W` の周期 `ν₀` の周期化だから、Poisson の和公式により

```
G(ν) = Σ_k W(ν − kν₀) = (1/ν₀) Σ_m w[m/ν₀] e^{−j2πmν/ν₀} = P Σ_m w[mP] e^{−j2πmνP}
```

`w` の台が `|n| < P` に含まれるなら `w[mP] = 0 (m ≠ 0)` だから `m = 0` の項のみが残り `G(ν) = P·w[0]`。∎

**系 1.1（利得）** 総和正規化した長さ `L` の Hann 窓では `w[0] ≈ 2/L` だから、`EP := L/P` として `G = 2/EP`。`EP = 1.75` で `+1.16 dB`。§3 の実測は `+1.15 dB`。

**系 1.2（透過性）** `L ≤ 2P` の倍音バンクは定義 2 の意味で透過的である。したがってその構成での `Q` は調波モデルの妥当性について何も述べない。§3 の白色雑音再構成 17.97 dB と f0 デチューン耐性は、この系の実験的確認である。

**検証 1.4（数値、`training/rddsp_theory_check.py`）** 定理 1 は主張ではなく検証済みである。合成に**白色雑音**（調波構造ゼロ）を通し、Welch 推定で伝達関数 `G` を測って閉形式 `P·w[0]` と比較した（f₀ = 220 Hz、P = 200.5 標本、全帯域 99 倍音、毎標本包絡）:

| `EP` | 理論値 `P·w[0]` | 実測 `|G|` | リップル (dB) | 白色雑音 SNR (dB) |
|---|---|---|---|---|
| 1.00 | 2.0045 | 2.0047 | 0.301 | 22.74 |
| 1.50 | 1.3364 | 1.3363 | 0.157 | 21.30 |
| 1.75 | 1.1455 | 1.1454 | 0.095 | 20.77 |
| **2.00** | **1.0023** | **1.0023** | **0.189** | 20.32 |
| 2.25 | 0.8909 | 0.8910 | 1.051 | 19.24 |
| 2.50 | 0.8018 | 0.8021 | 3.257 | 15.48 |
| 3.00 | 0.6682 | 0.6688 | 9.301 | 8.77 |
| 4.00 | 0.5011 | 0.5020 | 41.214 | 3.01 |

**閉形式と実測が小数 4 桁で一致する。** リップルは `EP ≤ 2` で 0.1–0.3 dB（推定器の分解能）、`EP > 2` で予言どおり立ち上がる（Poisson 和の `m ≠ 0` 項の出現）。白色雑音の再構成 SNR は `EP ≤ 2` で 20 dB 超、`EP > 2` で崩壊する。

（リップルを生の `Y/X` から測ってはならない。白色励振では `|X|` が Rayleigh 分布するので比が発散し、max/min は `G` ではなく励振の谷を測る。上表は Welch 推定 `S_xy/S_xx` による。）

**注意 1.3（標本化との関係）** 定理 1 は `a_k` を毎標本利用する場合の主張である。`a_k` を 1 周期あたり `r` 点で標本化して補間すると合成は LTI でなくなり、恒等性は `r → ∞` の極限でのみ成立する。有限 `r` での偏差は `a_k` のエイリアシングであり、これが §3.4 のラダー（`r` を上げると単調に改善する）の正体である。**「補間器を良くしても改善しないが標本化率を上げると改善する」という観測は、定理 1 の極限に近づいているだけであって、モデルが良くなっているのではない。**

### 2.3 定理 2 — 過完備な振幅は信号を決定する

**定理 2（既知の一般性定理の適用）** 窓長 `N_w`、ホップ `H` の STFT を考え、冗長度を `R = N_w/H` とする。`R ≥ 2` かつ窓が全台を持つとき、一般の（generic な）信号は `|STFT|` により大域位相を除いて一意に定まる。

これは本レポートの結果ではなく、STFT 位相復元の一意性に関する既知の結果（Balan–Casazza–Edidin の枠組み、および Jaganathan–Eldar–Hassibi, Bendory–Eldar–Sidorenko による STFT 特有の解析）の適用である。Griffin–Lim 型の反復が実用上機能する事実はその経験的対応物である。

**系 2.1** 息枝が残差 `x − h` の STFT 振幅を冗長度 `R > 1` で受け取るならば、その枝は定義 2 の意味で透過的である。すなわち「振幅を渡して位相を復元する」構成は、**振幅の名目で信号そのものを渡している**。

**系 2.2（分解の解釈）** §4 の段階分解（正直な DSP 2.780 → 振幅押し付け 3.867 → Griffin–Lim 4.029）は、系 2.1 の下では自然に読める: `+1.087` は透過性の獲得であり、`+0.162` はその透過性を実際に取り出す反復である。**どちらもモデルの改善ではない。**

### 2.4 命題 3 — 臨界レートでの白色雑音テストは無効

**命題 3.** 1 周期 1 ノードの倍音モデル（`K = f_max/f₀` 本、各ノードに複素数 1 個）のレートは

```
T = 2·K·f₀ = 2·f_max  [実数/秒]     すなわち ρ = ρ*
```

であり、これは担当帯域 `[0, f_max]` の Nyquist 自由度と厳密に一致する（`f₀` に依らない）。

*証明.* `K = f_max/f₀` 本の複素数を毎周期（`f₀` 回/秒）供給するから `T = 2K f₀ = 2 f_max`。帯域 `[0, f_max]` の Nyquist 自由度は `2 f_max` 実数/秒。∎

**系 3.1（白色雑音テストの無効性）** レート 1 の倍音バンクは自帯域に対して**ちょうど臨界標本化**である。臨界標本化された表現は、解析作用素が可逆でありさえすれば任意の帯域内信号を表現できる。したがってレート 1 における白色雑音再構成 SNR が測っているのは「モデルか否か」ではなく**解析作用素の条件数（＝窓長）**である。

実測がこれを支持する（`rddsp_bankcheck.py`、レート 1 固定、窓長のみ変化）:

| 窓長 `EP`（周期） | 1.5 | 1.75 | 2.0 | 2.5 | 3.0 | 3.5 | 4.0 |
|---|---|---|---|---|---|---|---|
| 白色雑音再構成 SNR (dB) | 8.37 | 8.55 | 8.45 | 7.77 | 6.43 | 5.21 | 4.30 |

**単調で滑らかに減少し、閾値を置くべき不連続が無い。** 定理 1 が予言する不連続（`EP ≤ 2` で恒等）は、この 1 ノード/周期の標本化の下では現れない — 注意 1.3 の通り、恒等性は `r → ∞` の極限の性質だからである。したがってこの量に閾値を置く門は、**理論的な境界ではなく任意の線**を引くことになる。実際 §6.1 では、その線が正当な設定を棄却しながら透過的な 2 構成を通した。

これは §6.1 の観測（正当な設定を棄却しながら、透過的な 2 構成を通した）の理論的説明である。**門はレートで引かねばならない。**

**系 3.2（レート台帳が必要条件）** ベンチマーク結果が情報を持つための必要条件は、全ての枝について `ρ_b < ρ*_b` が成り立つことである。これは十分条件ではない（サブナイキストでも別の理由で退化しうる）。

### 2.5 補題 4 — 乱数場の決定論的回転は情報を運ばない

学習を含む構成でしばしば現れる形として、合成が固定の擬似乱数場 `z`（本レポートでは濾波雑音の位相場 `e^{jφ_z}`）を含み、ネットワークが条件 `c` から決定論的な回転 `e^{jρ(c)}` を出してこれに掛ける場合を考える。

**補題 4.** `z ⊥ c` かつ `φ_z` が一様分布ならば、任意の決定論的 `ρ(c)` に対し

```
e^{jφ_z} · e^{jρ(c)} =_d e^{jφ_z}
```

すなわち出力位相の分布は変わらない。

*証明.* 一様分布は回転不変。∎

**系 4.1** ネットワークの入力に `z` が含まれない限り、`ρ(c)` は目標との位相一致を確率的に改善できない。したがって、**この形の構成で観測される利得は `z` が学習時と評価時で同一であること（暗記）以外に説明を持たない。**

**系 4.2（検出法）** 評価時に `z` を引き直せばよい。暗記であれば性能は `z` のみのベースライン（ネットを通さない場合）**より下**に落ちる。ネットが特定の `φ_z` を打ち消すよう学習しているため、別の `φ_z` に対しては積極的に誤った回転を加えるからである。§5.3 の実測（種 1 で 4.174、種 2/7 で 3.145/3.200、ネット無しは 3.397/3.457）はこの系の確認である。

### 2.6 命題 5 — パラメータ数による門が効かない理由

**命題 5.** 「パラメータ数 < 学習サンプル数」は、系 4.1 の型の退化を排除しない。

*理由.* 系 4.1 の退化が要求するのは学習データの暗記ではなく、**低次元の乱数場 `z` の効果の暗記**である。`z` は固定された 1 本の実現であり、その効果を打ち消す写像の記述長は学習サンプル数に比例しない。したがって、パラメータ数をサンプル数以下に落としても退化は残りうる。§6.2 の実測（1.02M パラメータでも同じ学習曲線、かつ 6.4M＋情報ゼロ条件付け > 1.0M＋本物の条件付け）はこの命題の確認である。∎

**系 5.1（正しい検出法）** 測るべきはパラメータ数ではなく、**条件付けと目標の間の相互情報量が実際に使われているか**である。操作的には「無関係な条件付けで同じ学習を行い、同じ性能が出るか」を見る（§6.4 の 4 点検査の 4 番目）。

### 2.7 系 6 — 「4.0 に届かない」もレートの帰結である

ここまでの 3 つの結果は退化の説明である。同じ枠組みは、本レポートのもう一つの否定的主張 —— **この族では目標値に届かない** —— にも根拠を与える。測定だけで述べるべきでない主張だからここに置く。

**観察（本レポートの全測定にわたる例外なき規則性）**

| 構成 | 最大枝レート | PESQ |
|---|---|---|
| 退化 I（倍音バンク `EP=1.75`, 5 ノード/周期） | 透過的（定理 1） | 4.070 |
| 退化 II（息枝 `\|STFT(x−h)\|` そのまま） | 6.04× | 4.024 |
| 退化 III（出力側の自由な複素スペクトログラム） | 3.01× | 4.174 |
| — | — | — |
| 息枝 1.95×（レート無制限の FIR 構成） | 1.95× | 3.405 |
| 息枝 0.54×（採用） | 0.54× | 3.435 |
| 息枝 0.38× | 0.38× | 3.369 |
| 息枝 0.22× | 0.22× | 3.245 |
| ケプストラム 80 次 + 173 fps | 0.63× | 2.770 |
| ケプストラム 40 次 + 173 fps | 0.31× | 2.453 |

**全ての枝が `ρ_b < ρ*_b`（サブナイキスト）である構成は、一つも 3.44 を超えなかった。4.0 を超えた構成は、例外なく少なくとも一つの枝が `ρ_b ≥ ρ*_b` であった。**

**系 6（レート単調性）** 固定された信号クラスと評価 `Q` に対し、達成可能な `sup_S Q` はパラメータレート `ρ` の非減少関数である。したがって `ρ` を固定したまま `Q` を上げる設計変更は、その `ρ` における達成可能上限 `Q*(ρ)` に漸近するのみで、それを超えられない。

*理由.* `ρ' > ρ` のパラメータ化は `ρ` のそれを部分集合として含みうるから、`Q*` は `ρ` について非減少。∎（率歪み理論の初等的帰結であり、本レポートの寄与ではない。）

**含意.** 本セッションで観測された「突破」は、すべて `Q*(ρ)` の上昇 —— すなわち `ρ` の増加 —— であって、`Q*(ρ)` 内での改善ではなかった。逆に `ρ` を固定した改善（推定器の変更、基底の変更、mixed-phase、混合励振、per-harmonic 非周期性、位相平滑）は**一つも 3.44 を超えなかった**。これは偶然ではなく系 6 の内容である。

**この*実装の*上界**: 同じ包絡にオラクル位相を与えると 3.851。位相は `Q` に対する情報のうちレート台帳に載らない部分の全てだから、**3.851 は本実装のパラメータ化における上界**である。

**重大な訂正（2026-08-04）。** 本節の初版はこれを「`Q*(ρ ≈ 0.5)` の実測上界」と書き、そこから「4.0 は届かない」を導いていた。**これは誤りである。** 系6 の単調性と §12.2 の実測 `Q*(0.31) ≥ 4.228`（BigVGAN、mel 条件付け）を組み合わせると

```
Q*(0.5) ≥ Q*(0.31) ≥ 4.228
```

が従い、`3.851` が `Q*(0.5)` の上界であることはありえない。**すなわちレート 0.5 で 4.0 は到達可能であり、本レポートが届かなかったのは写像が手設計だったからである。** 「4.0 はこのアーキテクチャの外」という初版の結論は、*このアーキテクチャ*の外ではあっても*このレート*の外ではない。§12.2 が事実上この訂正を先取りしていたが、本節の文言が残っていた。

**したがって正しい主張は次の通り。** レートを固定した設計変更は `Q*(ρ)` に漸近するのみで、それを超えない（系6）。本実装の `Q*` は 3.851。**目標 4.0 に到達するには写像を変えるしかなく、それは学習を意味する。** 本セッションが十数回試した「レートを固定した手設計の変更」が一つも 3.44 を超えなかったことは、系6 の内容であって、4.0 の到達不能性の証拠ではない。

**さらに、レート台帳の定式化には未宣言の仮定がある（2026-08-04 追記）。** `ρ` は「実数/秒」であり、実数 1 個は無限ビットを運びうる。`S` に正則性（連続性、あるいは有限精度）を課さなければ、空間充填写像により任意の `ρ > 0` で恒等写像が実現でき、系3.2 の必要条件は数学的に偽になる。**実務的なヒューリスティクスとしては機能するが、定理の支えにはなっていない。** 救済は `S` を連続と宣言して次元論で述べるか、パラメータを有限精度としてビット/秒で数えるかであり、いずれも本レポートでは行っていない。

**この系が主張しないこと.** `Q*(ρ)` の形は信号クラスと `Q` に依存し、計算されていない。3.851 は**この実装のこの包絡**についての上界であって、レート 0.5 の全てのパラメータ化についての上界ではない。より良いパラメータ化が同じレートでより高い `Q*` を持つ可能性は排除されない —— それが §9 の課題 A である。§9.4 の較正（BigVGAN 4.228、ただし非因果・122M・レートは mel 0.31× だが**学習された写像**が実質的な自由度を持つ）は、その可能性が現実であることを示している。

### 2.8 訂正 — 拘束するのは条件付け側のレートであって出力側ではない

本レポートは §5 で「出力側の界面を宣言していなかった」ことを退化 III の原因として述べた。**これは言い過ぎである。** §9.4 の較正と §13 のサーベイが反例を与える。

BigVGAN・Vocos・Wavehax はいずれも出力が複素スペクトログラムまたは波形であり、**出力自由度は波形レートを超える**。にもかかわらずこれらは退化していない。理由は明確で、**入力（条件付け）が mel 等の低レートに固定され、評価が学習外データで行われる**からである。生成器が高次元を出力すること自体は退化ではない。高次元の出力は、低レートの条件付けから**生成**される限り、モデルの表現力であってデータの転送ではない。

**正しい定式化:**

- **条件付け側のレート `ρ_in` は宣言され、担当帯域に対して劣臨界でなければならない。** これがモデルと転送を分ける。
- **出力側の自由度に制約は要らない。** ただし (i) 評価が学習外データであること、(ii) 合成に含まれる確率的入力が評価時に引き直されること、が必要である。

退化 III が不当だったのは出力が 3.01× だったからではなく、**train == eval であり、かつ乱数場が固定されていたため、その 3.01× の自由度が暗記の受け皿になった**からである。補題 4 と系 4.2 はこの読みと整合する（種を引き直すと崩れた）。出力レートは暗記を*可能にした*が、*原因*は評価設計である。

§6.4 の 4 点検査は、この訂正の後もそのまま有効である —— ただし 1 番目は「出力側のレート台帳」ではなく「**条件付け側のレート台帳と、出力自由度の申告**」と読むべきである。前者が門であり、後者は解釈のための情報である。

### 2.9 本節が主張しないこと

- **定理 1 は `f₀` 一定・窓長と周期の関係が厳密である場合の主張**である。時変 `f₀` では近似的にしか成立しない。ただし近似の破れは `f₀` の窓内変動に比例し、通常の音声では小さい（§3 の実測がこれを支持する）。
- **定理 2 は generic な信号についての一意性**であり、最悪ケースの主張ではない。また `R ≥ 2` は十分条件であって必要条件ではない。
- **系 3.2 は必要条件であって十分条件ではない。** レート台帳を通っても、別の機構で退化しうる。本レポートが 3 形態を順に踏んだ事実そのものが、必要条件を 1 つ足すだけでは足りないことの証拠である。
- 本節は `Q = PESQ` に依存しない。透過的な枝を持つ構成は、**参照との一致を測る任意の指標**で高い値を出す。

## 3. 退化 I — 倍音バンクが完全再構成フィルタバンクになる

### 3.1 主張された結果

倍音の複素包絡 A_k(t) の推定を「GCI 中心の 2 周期 Hann 窓 DFT」から「合成と同じ位相トラックでのヘテロダイン復調＋長さ EP 周期の Hann による低域通過」に変え、包絡の標本化を 1周期1点から 1周期5点に上げた結果、**PESQ 3.406 → 4.070**（未使用10発話でも 2.898 → 3.929）。

### 3.2 数理

長さ `L = EP · SR/f0` の Hann 窓 `w`（和 1 に正規化）で harmonic k を復調・再変調するバンクの周波数応答の和は、Poisson 和により

```
Σ_k W(f − k·f0) = P · Σ_m w[m·P] · e^{−j2πmf/f0},    P = SR/f0
```

`EP < 2` では窓長が 2 周期未満なので `w[±P]` が窓の外に落ち、**m = 0 の項だけが残って和は厳密に定数**になる。したがって

> **EP ≤ 2 のとき、この「倍音バンク」は倍音の有無に関係なく入力波形を復元する完全再構成フィルタバンクである。**

**帰属（2026-08-04 訂正）**: これは新しい定理ではない。**Allen & Rabiner (1977)** の STFT filter-bank summation (FBS) 完全再構成条件そのものであり、「窓長が DFT サイズより短ければ条件は自明に成立する」という形で確立されている。本レポートの寄与は定理ではなく**適用先の同定** —— 調波モデルと称しているものが実は FBS 恒等系になっている、という点だけである。当初この帰属を欠いていたのは文献調査の不足である。

利得は `2/EP`。EP = 1.75 で +1.16 dB、実測 +1.15 dB。

### 3.3 検証

| 検証 | EP = 1.75（主張された構成） | EP = 4.0（倍音分離） |
|---|---|---|
| **白色雑音**（倍音構造ゼロ）の再構成 SNR | **17.97 dB** | 4.95 dB |
| f0 を 31% デチューンしたときの PESQ 低下 | −0.48 | −1.26 |

白色雑音を 18 dB で再構成し、f0 を 31% 間違えても崩れないものは、定義上、倍音モデルではない。**弱基音対応の f0 推定器も MVF 推定器も、この動作点では出力に寄与していなかった。**

### 3.4 誤った説明が正しい実験を生んだこと（記録として重要）

この構成に至った推論は「2 周期 Hann 復調器は A_k を ±f0/2 に帯域制限する。GCI レートは f0 なのでちょうどナイキストであり、線形補間では足りない」だった。**この帯域幅は 2 倍間違っている**（長さ EP 周期の Hann の主ローブ半幅は `2·f0/EP`、よって臨界ノードレートは `4·f0/EP`）。

しかし、この誤った説明から導かれた実験計画は正しかった:

| 包絡の復元 | PESQ |
|---|---|
| GCI レート・線形 | 3.657 |
| GCI レート・**3次補間** | 3.658 |
| 2倍レート・線形 | 3.912 |
| 毎サンプル | 3.976 |

**3次補間が線形と 1 桁も変わらないのにレートを倍にすると +0.25** — これは標本化不足の署名であり、実際そうだった。誤っていたのは「なぜ足りないか」であって「足りない」ではない。ただし後述のとおり、この「足りなさ」を埋める行為そのものが退化である。

## 6. 効かない門、効く門

### 6.1 白色雑音再構成テストは倍音枝に対して原理的に不適

退化 I を受けて実装した門は「その構成に白色雑音を通し、再構成 SNR が閾値未満なら合格」だった。これは**倍音枝に対しては使えない**。

1周期1ノードの倍音モデルは、K = fmax/f0 本の倍音に各 2 実数を割り当てるので

```
レート = 2·K·f0 = 2·fmax  [実数/秒]
```

これは**担当帯域 [0, fmax] のナイキスト自由度と厳密に一致**し、**窓長に依存しない**。すなわち rate-1 バンクは自分の帯域内で本質的に臨界標本化であり、どんな窓長でも白色雑音テストに反応する。**窓を短くしてもパラメータは 1 つも増えない**（時間分解能だけが上がる）。

実際にこの門は、正当な設定（`LS_PERIODS=2.0`、レート 0.07×、PESQ 3.435）を棄却しながら、**波形を転送していた 2 つの構成を通していた**（退化 II・III はいずれも倍音枝の外で起きている）。

さらに、この門は**振幅領域の漏洩を原理的に検出できない**: 系全体に白色雑音を通すと再構成 SNR 0.01 dB（無相関）なのに、同じ系が gt 振幅から PESQ 4.07 を出す。

### 6.2 「パラメータ数 < サンプル数」は暗記を防がない

退化 III に対し自然に思いつく門だが、実測で無効:

- ch=120（1,019,979 params < 1,058,400 samples）でも step 4000 で 3.6501（フル 6.37M で 3.7877）
- **6.4M ＋ 情報ゼロ条件付け（3.6797） > 1.0M ＋ 本物の条件付け（3.6501）**

**条件付けの情報よりパラメータのほうが価値が高い**という状態では、パラメータ数の制約は目的を果たさない。

### 6.3 効く門: レート台帳

各枝が消費する実数/秒を標本化周波数で割った値を、**全枝・入力側と出力側の両方**について出す。

```
倍音枝  : ENV_RATE × 2 × MVF                 [実数/秒]
息枝    : （ケプストラム次数 or ビン数） × フレーム/秒
```

判定:
- **倍音枝: ENV_RATE ≤ 1**。倍音の複素包絡は物理的に ±f0/2 に帯域制限される（変調源は声道＝50 Hz 未満と、周期間 jitter/shimmer＝定義上 1 周期を超えられない）。1周期1ノードがそのナイキストであり、それを超えて運ばれるのは隣接倍音とのうなり＝倍音間成分であって倍音の振幅ではない
- **息枝: 十分小さいこと**（本実装では 0.5× を採用）

**この門は探索ループの制約として実行しなければならない。** 事後監査では遅い。実際、PESQ 単独の座標上昇は正当な設定から不合格域へ自分で歩いていったし（`LS_PERIODS` 3.5 → 3.0）、門を監査としてしか持っていなかった段階では、再調整が息枝を 0.47× → 1.25× に戻して初めて気づいた。

また、判定グリッドには**必ず現在の設定値を含める**こと。含まないと「見ないことで合格」する。実際に一度すり抜けた。

### 6.4 効く門: 学習を伴う場合の 4 点検査

overfit gate は「表現可能性の証明」として正当な手続きだが、以下が揃わなければ**その証明にすらならない**。

1. **出力側**のレート台帳（ネットが出せる自由度 ÷ SR）
2. **乱数の種を振り直した評価**（暗記なら崩れる。しかも「何もしない」より悪くなる）
3. **未学習データでの評価**
4. **無関係な条件付けで学習した対照**（情報ゼロで同じ点が出るなら、利得は条件付けと無関係）

加えて、系全体のテストとして有効なもの:

- **DSP コアを消してスコアが落ちるか**（落ちなければコアの寄与はゼロ）
- **end-to-end の f0 デチューン耐性**（倍音モデルなら崩れる）

ただし後者には限界がある: **搬送波経由で転送しても搬送波は必要**なので、`ENV_RATE=2` のような「過完備だが搬送波依存」の構成はこれらを通ってしまう（h=0 で −2.09、f0 デチューンで −0.63 と、いずれも健全に見える）。**最終的な拠り所はレートと物理帯域幅である。**

## 7. 門を適用した結果と、DSP/神経境界の実測

### 7.1 純 DSP の天井

構造的にコピー不能な経路（時変 FIR、`|Y| = |N|·|H|` が構成上成立、位相復元なし）に固定し、レート台帳を制約として 20 発話で全ノブを再調整した:

| | PESQ |
|---|---|
| 未使用 12 発話（最終） | **3.159** |
| 同・再調整前 | 2.884 |
| 同じ包絡＋**オラクル位相** | **3.851** |
| 恒等写像 | 4.644 |

**位相を完璧に予測できても 3.851。** 位相なしの損失は +0.45 にすぎず、残る 0.79 は**包絡の表現力そのもの**である。すなわち、この族の天井は「ノイズ枝に位相モデルが無い」ことではなく**パラメータ化**が決めている。

これは本プロジェクトが別経路で得ていた「手作り source-filter ボコーダは耳で不合格」という結論に対する、独立した定量的裏づけである。

### 7.2 全滅した構造的手（すべて実測）

| 手 | 結果 |
|---|---|
| MVF を上げる（1500 → 11000 Hz） | 3.405 → 2.700、単調悪化 |
| 倍音ごとの非周期性（per-harmonic aperiodicity） | 全 MVF で −0.35〜−0.42 |
| **mixed-phase レンダリング**（振幅から導く最小位相） | cut 2500/1500/800 Hz で 3.122/3.006/2.807、覆う帯域を広げるほど悪化 |
| 混合励振（パルス列＋雑音、WORLD/MELP 流） | 最大 +0.031、採用点で +0.004 |
| 声門同期励振の包絡変調 | 0 が最良、0.9 で −0.28 |
| 声門オフセットのエポック方向平滑 | 単調悪化（推定窓が既に同じ平滑を含むため二重適用） |
| FIR 長 128/512/1024 | 差 0.0000 |
| 最小二乗（Stylianou HNM）への置換 | ±0.002（**速度は 10 倍**） |

**最小二乗と Hann 復調器が同点であることは重要な負の結果**である: 推定器を変えても時間分解能は買えない。窓長は「倍音を分離できるか」と「時間分解能」のトレードオフを固定しており、そこに逃げ道はない。

混合励振がほぼ効かないのは、PESQ-wb が 16 kHz にリサンプルして低域を重く見るためである（2 kHz 以上を gt に差し替えても +0.009）。**耳では別評価になり得るため、この数字で耳ゲートを閉じてはならない。**

### 7.3 神経スペクトルは（この規模では）寄与しない

4 点検査を満たす条件 — 毎ステップで**雑音実現を引き直し**（暗記が原理的に不可能）、位相を回転でなく**絶対値で生成**、train/test を互いに素に、**未使用の種**で評価 — で 3 回独立に測定した:

| 条件 | 結果 |
|---|---|
| 16 発話学習・旧コア | TEST 2.773〜2.782 対 ネット無し 2.779（**平坦**） |
| 54 発話学習・旧コア | TEST 2.991〜3.011 対 2.996（**平坦**） |
| 54 発話学習・再調整後コア | TEST 3.076〜3.097 対 3.143（**負**） |

**退化の逃げ道を塞ぐと、この規模（単一話者 66 発話・6.4M パラメータ・MR-STFT 損失）の神経スペクトルは寄与しない。**

ただし**これは方式の反証ではない**。この規模とこの損失についての言明であり、実用的な神経ボコーダはフルコーパスと敵対的損失で学習される。半端な実装の不合格を方式クラスの反証として記録することは、本プロジェクトが明示的に禁じている誤りである。

なお、目的関数についてはより強い結果が得られている:

| 学習の目的関数 | 結果 |
|---|---|
| log 振幅 L1（残差スペクトルに対して） | **L1 を 3.4 倍改善させて PESQ −0.12、最良が step 0（学習前）** |
| レンダラを通した波形上の多解像度 STFT | 初めて DSP コアを上回る（3.439 → 3.501） |

**振幅を正確に合わせるほど音が悪くなる。** 残差 `|STFT(x − h)|` には倍音の微細構造が漏れており、それを正確に合わせるほど、ランダム位相で倍音の上に重ねる量が増えて濁る。**ノイズ枝は包絡を運ぶべきで微細構造を運ぶべきでない**という、本レポート全体と同じ結論に独立に到達する。

## 8. 副産物: 実装上の欠陥

方法論とは別に、以下は再利用価値のある具体的な誤りである。

1. **`exp(−j·k·Φ)` の float32 キャスト**: 位相トラック Φ は 8 秒で ~10⁵ rad に達する。float32 に落としてから指数を取ると量子化 ~1.2×10⁻³ rad、harmonic k でその k 倍、しかも**ファイル長に比例して悪化**する。剰余を float64 で取ってからキャストすること
2. **有声立ち上がりのチャープ**: f0 推定器が無声区間で 0 を返し、位相トラックがその積分であるため、有声開始のたびに倍音バンク全体が 1 hop で 0 → k·f0 を掃引する。発振器には連続 f0 を渡し、有声/無声は別の振幅包絡で扱うこと
3. **因果ランプの flip 誤り**: `conv1d` は相互相関なので、左パディングと組み合わせるときカーネルを flip すると Hann の先頭 0 が現フレームに乗り、現フレームの重みがゼロになる。「因果化」が片方の枝にだけ遅延を足していた
4. **最小二乗のリッジ希釈**: 基底サイズを発話全体の最低 f0 から決めると、局所 f0 が高いノードでは大半の列がゼロになり、`ridge × mean(diag)` の平均がゼロ列込みになってリッジが意図の 1/5 になる。解も (144/30)³ 倍の無駄
5. **レイテンシ申告と実装の乖離**: 「窓の半分」だけを数え、中心 median filter（±23 ms）・発話全体の median・全区間ゲイン・前方補間を数えていなかった。合成側の未来参照を全て因果版に置き換えたコストは **−0.034** と安価だった
6. **有界先読み Griffin-Lim**: 素の GL は 1 反復ごとに全信号 STFT 往復なので出荷不可と記録されていたが、射影は局所（1 反復は窓が重なるフレームとしか混ざらない）なので、`la` フレーム先読みで確定していけば**遅延は `(2la−1)·hop + nfft/2` で反復回数に依存しない**。確定済みフレームを毎反復再固定しないとブロック境界がクリックする

## 9. 突破に必要なもの（研究課題）

本レポートの測定は「4.0 は現行アーキテクチャの外」と言っているだけで、**到達不能とは言っていない**。突破口は 3 つに絞られる。

### 9.1 課題 A — 包絡の表現力（最も直接的）

天井 3.851 の内訳は「位相 0.45／包絡 0.79」である。**包絡側が主**であり、これはレートを上げれば必ず解けるが、上げた瞬間に転送になる。したがって解くべきは:

> **宣言可能な低レートの記述（mel 相当、0.24×）から、息枝の周波数方向の微細構造を *生成* できるか。**

**第一段階を実施した**（`training/rddsp_dspecies_multi.py`）。単一話者では規模不足と目的関数不足が交絡していたので、**話者数**で切り分ける: 300 話者から 1 発話ずつ（78.8M サンプル 対 6.4M パラメータ、比 0.08）、テストは別の 40 話者。話者ごとの暗記は原理的に不可能になる。4 点検査は全て維持（毎ステップ雑音を引き直し・位相は絶対生成・train/test 素・未使用シードで評価・零初期化）。

| 学習集合 | TEST（ネット有り） | ネット無し | 差 |
|---|---|---|---|
| 16 発話 / 1 話者 | 2.773〜2.782 | 2.779 | **±0.00** |
| 54 発話 / 1 話者 | 2.991〜3.011 | 2.996 | **±0.01** |
| 54 発話 / 1 話者（再調整後コア） | 3.076〜3.097 | 3.143 | **−0.05** |
| **300 発話 / 300 話者** | **3.0174** | 2.9804 | **+0.037** |

**規模は符号を変えた。** 単一話者では平坦または負だったものが、話者を散らすと**未使用話者・未使用シードで一貫して正**になる。暗記が不可能な条件下での利得なので、これは実際の写像である — 本セッションで唯一の、正当な神経利得。

**しかし +0.037 は必要量より一桁小さい。** DSP コア 2.98 から 4.0 までは +1.0 あり、規模を 5.5 倍（54→300 発話）にして得られたのが +0.04 では、データだけでは届かない。**したがって課題 A は「より多くのデータ」から「異なる目的関数」へ再方向づけられる。** 多解像度 STFT は位相を直接は罰しないため、位相を生成する枝を駆動する信号として弱い。次は敵対的損失（README の「GAN は最後の texture fine-tune のみ」の枠内）か、位相を明示的に評価する損失である。

判定は変わらず「未使用話者・未使用種で DSP コアを有意に上回るか」の一点であり、その基準線は**本レポートで 2.9804 として確定した**。

**第二段階（敵対的損失）も実施した**（`training/rddsp_dspecies_gan.py`）。多解像度 STFT 判別器＋特徴量マッチングを、凍結した DSP 骨格の上の息枝テクスチャにのみ適用（README の「GAN は最後の texture fine-tune のみ」の枠内）。プロトコルは全て維持。

| step | TEST | ネット無し |
|---|---|---|
| 0（零初期化） | 3.0274 | 3.0274 |
| 2000 | 2.9790 | 3.0274 |
| 4000 | 2.9743 | 3.0274 |
| 6000 | **2.7790** | 3.0274 |

**PESQ は単調に下がる。** これは失敗ではなく構造である: **敵対的損失は「もっともらしいが参照と同一ではない」微細構造を生成するもので、PESQ はまさにその差を罰する。**

### 9.1' 目標指標に対する三方向の効果

3 つの実測を並べる。

| 方向 | PESQ への効果 |
|---|---|
| 再構成忠実度を上げる（DSP ノブ・推定器・基底） | 上がるが **3.851 で頭打ち**（オラクル位相を与えても） |
| データ規模（1話者 → 300話者、MR-STFT 損失） | **+0.037** |
| 知覚的リアリズム（敵対的損失） | **単調に低下**（−0.25 で打ち切り） |

**PESQ > 4.0 は、再構成忠実度を上げる経路では到達できない**（オラクル位相を与えても天井 3.851）。知覚的リアリズムを上げる経路は PESQ に罰される —— **ただしそれは品質が下がったことの証拠ではない**（§9.1''）。**この 2 つの間に 4.0 へ届く点は、本レポートが測った範囲には無かった。**

したがって**この目標指標を追い続けること自体が誤り**である。本プロジェクトは既に PESQ が同じ欠陥を 2 回誤順位付けした記録を持ち、§9.3 では PESQ にほとんど写らない高域波高率の差（−0.9〜−1.9 dB の幅に対し PESQ 差 0.05 以内）を測っている。**次に定義すべきは目標値ではなく目標指標であり、その第一候補は耳ゲートである。**

### 9.1'' 訂正（2026-08-02、§12.7 参照）

以下の「分岐」の読みは**片側しか測っていない**。敵対的損失で PESQ が下がることは FINALLY（arXiv:2410.05920）と MetricGAN が既知の挙動として報告しており、**知覚側が実際に上がったかを本レポートは測定していない**。下の表は「PESQ に対する効果」としては正しいが、「品質に対する効果」としては不完全である。修正した手順は §12.7。

### 9.2 課題 B — 倍音枝の担当帯域を上げる

現行は MVF ≈ 2 kHz までしか倍音枝が担当しておらず、それ以上は位相を持たない。MVF を上げると単調に悪化するが、その原因は「1周期1ノードでは高次倍音の包絡が表現しきれない」ことであり、**物理的な ±f0/2 の制約に触れている**。

ここを動かすには、包絡のレートではなく**基底**を変える必要がある。第一候補だった「窓内の一次項（`a_k + b_k·n`）を持つ最小二乗」は**検証し、棄却した**（`training/rddsp_slope.py`）。

素朴に置くと 4 実数/倍音/周期となり、本レポートが `ENV_RATE=2` を棄却したのと同じ 2 倍過完備域に入る。そこで**レートを固定して**定式化した — 節点を半分（2 周期に 1 点）にし、各節点が {値, 傾き} を持つ。合計 4 実数/2周期 ＝ 2 実数/周期 ＝ 現行と厳密に同じ。節点間は両端の値と傾きを使う 3 次 Hermite 補間（最近傍節点からの外挿では 2.375 → 2.121 とさらに悪化した。これは近道の性質であって基底の性質ではない）。

未使用 12 発話での結果:

| パラメータ化 | PESQ | 実数/倍音/周期 |
|---|---|---|
| 現行（値のみ、1周期に1点） | **3.1587** | 2 |
| 値＋傾き、2周期に1点（Hermite） | 2.3751 | 2（同じ） |
| 値のみ、2周期に1点 | 2.6390 | 1（半分） |

**同じレートなら値を密に置くほうが良く、しかも傾きを足すとパラメータ半分の「値のみ」にも負ける。** 原因は、最小二乗の窓（3 周期）より節点間隔（2 周期）が長く、傾きを当てはめた範囲の外へ外挿することになる点にある。窓を節点間隔より長く取れば外挿は減るが、そのぶん傾き自体が平均化されて意味を失う。**この方向は閉じた。**

残る候補は「節点位置そのものを最適化する（非一様格子）」「倍音ごとに異なるレートを割り当てる（低次は疎、高次は密）」だが、いずれも**本レポートでは未検証**。

### 9.3 課題 C — 目的関数

PESQ-wb は 16 kHz にリサンプルするため **8–22 kHz が目的関数に一度も入っていない**。ASMR 用途ではそこが納品物そのものである。また本プロジェクトは PESQ が同じ欠陥を 2 回誤順位付けした記録を持つ。

全帯域を見るゲートを実装した（`training/rddsp_fullband.py`）: オクターブ帯域エネルギー誤差（0–22 kHz）、8–22 kHz 単独の誤差、高域包絡の変調スペクトル一致（20–400 Hz）、高域の波高率。未使用 8 発話での測定結果は 3 つある。

**(1) この族では PESQ は高域について誤誘導していない。** 7 構成を測って、PESQ が好み高域が嫌う組み合わせは存在しなかった。出荷構成の 8–22 kHz は **−0.21 dB** と良好である。「PESQ は高域を見ていない」は事実だが、**この探索空間では実害が出ていなかった**。ただしこれは*このノブ群*についての言明であり、耳ゲートを置き換えるものではない。

**(2) 残る最大の帯域誤差は 0–250 Hz の −1.3 dB で、全 7 構成に共通する。** f0 が 170–280 Hz なので、この帯域には倍音が 1 本も無く、ノイズ枝が min-pool した床で埋めている。**しかしこれは「足りない」のではない**: 基本波以下でノイズ枝に完全な `|X|` を渡すと **+2.5 dB に行き過ぎ、PESQ が 3.140 → 2.763 に落ちる**（`SUBF0_FULL`）。gt の基本波以下のエネルギーは大半が**基本波自身の解析裾**であって独立した成分ではなく、それをノイズとして足すと二重計上になる。**この −1.3 dB はレベル操作では埋まらない。** 埋めるなら基本波の解析裾そのもの（jitter・subharmonic・室内低域）を再現する必要がある。

**(3) 高域の波高率が gt より −0.9 dB 低い。** 我々の高域は本物より尖っていない ＝ 「テクスチャ」より「ヒス」寄りである。ASMR 用途で最も効きうる差であり、**PESQ にはほとんど写らない**（全構成で PESQ 差 0.05 以内なのに波高率は −0.9〜−1.9 dB の幅がある）。**耳ゲートで最初に確認すべき軸はここ。**

これらを踏まえ、**耳ゲートを昇格条件に残す**こと。混合励振が PESQ 上ほぼ無価値（+0.004）でも耳では有意かもしれない、という具体的な未解決事項もある（実測: 混合励振は波高率を −0.91 → −1.52 dB と*悪化*させるので、耳でも不利な可能性が高い — これは全帯域ゲートが無ければ見えなかった）。

|---|---|---|

1. **4.0 はこのハーネスで到達可能**（BigVGAN 4.228）。ただし 122M・非因果・hop 512 であり、**製品の低遅延要件を満たさない**。目標値は「品質の目標」としては正当だが「低遅延パラメトリック系の目標」としては文献上の前例がない。
2. **`rddsp` の 3.159 は製品への経路を持たない**（2026-08-04 追記）: `rddsp` は gt から**測定した**声門位相を含む 0.5× のパラメータを受け取るが、§12.5 が自認するとおり**変換時に声門位相は測定できない**。mel だけを受け取る系と同じ列に置いてはならない。界面の違うものを同じ数値で並べるな、というのが本レポートの主題そのものであり、初版の結論文はそれを踏み越えていた。

## 12. Frontier — 本レポートから導かれる SOTA への一手

本節は結論ではなく**次にやるべきこと**である。§2 の理論、§7 の実測、§9.4 の較正、そして低遅延ボコーダの現在地から導く。

### 12.1 SOTA の現在地（2024–2026）

低遅延・小型ボコーダの最前線は、**時間周波数領域でのエイリアシングフリーな複素スペクトログラム推定 ＋ 調波事前分布**に収束している。

| | パラメータ | MACs/s | CPU RTF | PESQ | 因果性 |
|---|---|---|---|---|---|
| HiFi-GAN V1 | 13.82M | 28.01 | 0.825 | — | 非因果 |
| Vocos | 13.49M | 46.91 | 0.036 | 3.487 | 非因果 |
| **Wavehax** | **0.623M** | **1.298** | 0.196 | **3.818**（高 f0 外挿 3.927） | 非因果 |
| **MS-Wavehax** | HiFi-GAN の **2.4%** | — | — | MOS ≈ 自然音声 | **因果・先読み 1 フレーム** |

Wavehax の主張は本プロジェクトの独立した診断と一致する: **時間領域の点ごと非線形は必ずエイリアシングを生む**（`ReLU(sin ωt)` は無限次高調波を作り、帯域制限により折り返す）。本プロジェクトはこれを「ジリジリ＝倍音間ノイズ、activation aliasing、decoder 由来」として独立に特定していた（[[jirijiri-interharmonic-aa]]）。Wavehax はその原理的な解を与える —— **全処理を TF 領域に置けば折り返しは構造的に生じない**。

### 12.2 導かれる不等式 — 不足はレートではなく写像

§9.4 の較正と §7 の上界を並べる。

```
Q*(ρ_in = 0.31, 学習された写像)  ≥  4.228     （BigVGAN、mel 条件付け）
Q*(ρ_in ≈ 0.5,  本レポートの写像) ≤  3.851     （オラクル位相を与えた上界）
```

**より低い条件付けレートで 1.07 上回られている。** 系 6（レート単調性）は「レートを上げねば `Q` は上がらない」とは言っていない —— 言っているのは「同じ写像のままレートを固定すれば上界に漸近する」だけである。**本レポートが 3.16 で止まったのはレート制約ではなく、写像が手設計だったからである。** これが frontier の位置である。

### 12.3 本プロジェクトが持っている非自明な資産

Wavehax の調波事前分布は（論文 Eq.16）

```
e[n] = Σ_k √(0.02/K) · sin(2πkφ[n] + kϕ_rand) + 0.01·z[n]
```

すなわち **f0 から作った正弦波の重ね合わせで、各倍音の位相はランダム、振幅は一定**。運んでいる情報は f0 だけである。

本レポートの DSP コアは、同じ位置に**測定された声門相対位相**（声門周期波形の相関 0.987、ゼロ位相版は 0.369）、**MVF による調波/雑音分割**、**非周期性**を、レート **0.07×** で供給する。単体で PESQ 3.16。

**新規性主張の撤回（2026-08-04）。** 初版は「測定された声門位相を事前分布に用いた報告は無い」と書いたが、**これは文献調査の不足である**。Degottex らの **HMPD**（Harmonic Model + Phase Distortion、EURASIP JASMP 2014、COVAREP に実装）と **PML**（Pulse Model in Log-domain、2016）は、測定された調波位相を位相歪みの平均・偏差として**低レートかつ話者特徴的にパラメータ化**しており、聴取試験で女性声は STRAIGHT 同等、男性声は上回ると報告している。声門波形ベースの神経ボコーダ（GlotNet、GELP、GlottHMM 系）も存在する。

したがって正しい位置づけは「文献に無い」ではなく、**「古典的パラメトリック音声合成では確立された表現が、TF 領域の神経ボコーダの調波事前分布としては使われていない」**である。Wavehax が位相を明示的にランダムとしているのは事実であり、その空白を HMPD 系の知見で埋める、というのが本レポートの提案の正確な形になる。**§12.5 の H-G（声門パルス形状は低レート・話者特徴的で予測可能）も、HMM-TTS 時代に部分的に肯定されている命題**であり、「本当の研究課題」として提示するには先行研究の整理が必須である。

### 12.4 Frontier 仮説（反証可能な形で）

> **H-F**: MS-Wavehax 級の因果 TF 領域ネットワークを、`rddsp` コアの出力を調波事前分布として条件付けると、同じパラメータ数・同じ遅延で Wavehax の f0 のみの事前分布を上回る。上回り幅は、事前分布の位相精度が信頼できる帯域（本実装では ~1.5 kHz 以下）に集中する。

**根拠:**
1. 事前分布が良ければネットが発明すべき量が減る（Wavehax 自身の設計思想）
2. 本レポートの実測: 正直な構成で DSP コアを消すと −1.49（コアは実際に信号を運んでいる）
3. 本レポートの実測: 声門相対位相は **k に対して平坦に劣化**し、~1.5 kHz 以上では雑音（`|Δr_k|` ≈ 1.0–1.4 rad 対 完全ランダムの π/2 = 1.571）。したがって効果は低域に集中するはず

**反証条件:** 同一ネットワーク・同一学習で、事前分布のみを (a) Wavehax 式 f0 正弦波、(b) `rddsp` コア、に差し替えて held-out で比較し、差が有意でないこと。あるいは差が 1.5 kHz 以上に出ること（機構の予測と矛盾する）。

### 12.5 展開時の未解決点（これが本当の研究課題）

**事前分布の位相は、VC 時には測定できない。** `rddsp` は gt を解析して声門位相を得ているが、変換時に手元にあるのは content と f0 だけである。したがって H-F を製品に持ち込むには次が要る。

> **H-G**: 声門パルス形状は低レート・話者特徴的であり、content から予測可能である。位相が雑音化する帯域（~1.5 kHz 以上）では、Wavehax 同様ランダム位相で構わない。

これは本プロジェクトの [[moe-articulatory-clone]]（萌え＝構音クセの clone）および [[m2-clone-adain-grl]] と同じ対象を、**位相の側から**定式化したものである。声門パルス形状は 1 周期あたり数個の実数（レート 0.07× のうち低次倍音ぶん）で表され、話者・声質と強く結びつく —— つまり**予測すべき量として筋が良い**。これが正しければ、`rddsp` は解析器としてではなく**予測ターゲットの定義**として機能する。

**反証条件:** content + speaker 埋め込みから低次倍音の声門相対位相を予測させ、測定値との一致が偶然（ランダム位相）と有意に差がつかないこと。

### 12.6 やるべき順序

1. **`rddsp` コアを Wavehax 式の事前分布として差し込める形にする**（f0 → 複素スペクトログラム、TF 領域、因果）。現状の `resynthesize` は既に因果・RTF 0.36 なので、STFT 表現を出力する薄いラッパで足りる。
2. **H-F の対照実験**: 同一の小型 2D TF ネットワーク（0.6M 級）、事前分布のみ差し替え、held-out 話者。§6.4 の 4 点検査を全て添える。
3. H-F が通れば **H-G**（位相の予測可能性）へ。通らなければ、事前分布の価値は f0 に尽きるという negative result であり、それ自体が文献に無い知見である。

**着手状況（2026-08-02、`training/rddsp_hf.py`）— 未決**

手順 1–2 を実装した。TF 領域のみで動く因果 2D ConvNeXt スタック（時間方向は左パディングのみ、時間領域の点ごと非線形なし＝エイリアシング発生源なし）、**0.223M パラメータ、nfft 512 / hop 128（窓遅延 5.8 ms）**、出力層零初期化で step 0 は事前分布そのものを再生する。学習 200 発話・評価 24 発話、いずれも話者素。

| | test PESQ |
|---|---|
| 事前分布単体（`rddsp` 調波枝のみ、無声区間は無音） | 1.769 |
| step 0（零初期化＝事前分布と一致、実装の健全性確認） | 1.769 |
| step 1000 / 2000 / 3000 / 4000 | 1.504 / 1.653 / 1.628 / 1.654 |

**収束していない。** 損失も不安定（1.98 → 3.43 → 2.19）。

**これは H-F の反証ではない。** 0.223M パラメータ・12k step・多解像度 STFT 損失のみという規模で、mel と調波事前分布だけから確率成分を丸ごと生成させている。Wavehax は同等サイズだが学習規模と敵対的損失が桁違いであり、本プロジェクトは**半端な実装の不合格を方式クラスの反証として記録しない**という規則を明示的に持つ。したがってここに記録するのは「この規模では収束しなかった」であって「事前分布に価値が無い」ではない。

### 12.7 訂正 — 「敵対的損失で PESQ が下がる」は失敗ではなく既知の挙動

§9.1 で敵対的損失が PESQ を単調に下げる（3.027 → 2.779）ことを測り、これを目的関数の分岐として記録した。**その解釈は不完全である。**

**FINALLY**（Babaev et al., arXiv:2410.05920）は同じ現象を明示的に報告している: 「MOS と UTMOS で優れるが、**参照ベース指標（PESQ / STOI / SI-SDR）ではベースラインに劣る**」。彼らの応答は「参照ベース指標は人間の知覚判断との相関が低いことが多くの研究で一貫して報告されている」であり、**PESQ の低下を欠陥ではなく想定される挙動として扱っている**。MetricGAN（Fu et al.）はさらに直接に「敵対的損失は評価指標を最適化するようには設計されていないので、指標スコアを改善するとは限らない」と述べる。

**したがって §9.1 の測定は正しいが、そこから引くべき結論は違う。** 私は PESQ が下がったことを「知覚側の経路が指標に罰される」と読んだ —— それ自体は正しい —— が、**知覚側が実際に上がったかを一度も測っていない**。片側しか測らずに「分岐している」と述べたのは、証拠の欠落である。

**FINALLY の中核は敵対的損失ではない。** 三段階の学習で、支配的なのは **WavLM の畳み込みエンコーダ特徴上の知覚回帰損失**である:

```
L_MOS = 100·‖φ(y) − φ(g(x))‖²₂ + ‖|STFT(y)| − |STFT(g(x))|‖₁      φ = WavLM-conv
```

第 1 段はこの損失のみ、第 2 段で敵対的損失（λ=0.4）と特徴量マッチング（λ=20）を追加、第 3 段で L_MOS を 0.5 に下げ GAN を 5 に上げる。彼らのアブレーションでは、**WavLM の畳み込み層特徴が Wav2Vec 2.0・EnCodec・CDPAM を上回った**（transformer 出力ではなく畳み込み出力である点が重要）。

**本プロジェクトの規則との整合**: `CLAUDE.md` は「補助モデルによる表現監督は許可 —— WavLM-SV/ECAPA/ASR 等を loss・評価・蒸留に使ってよい。ただし推論時依存にしない」と明示している。WavLM-conv 知覚損失はこの許可の範囲内であり、`models--microsoft--wavlm-{base,base-plus,base-plus-sv,large}` は既にローカルにある。

**したがって §12.6 の手順 2 は次のように改める:**

> 2'. H-F の対照実験を、**MR-STFT のみではなく L_MOS（WavLM-conv）＋ MR-STFT** で行う。敵対的損失はその後に足す（FINALLY の段階順）。評価は **PESQ と知覚指標の両方**を必ず併記する。片側だけを見て「分岐している」と述べない。

**実施結果（2026-08-02）— L_MOS は原因ではなかった、原因は最適化である**

WavLM-base-plus の畳み込みエンコーダ特徴に対する L_MOS（重み 100）を実装し、同じ arm B を回した。

| step | 学習損失 | **TRAIN** | TEST | 事前分布単体 |

| 1500 | 2.015 | **1.320** | 1.575 | 1.888 |

**L_MOS の有無で挙動は変わらなかった**（MR-STFT のみ: 1.53/1.68/1.66）。§12.6 の手順 2' が想定した「損失が弱いから収束しない」は**外れである**。

**決定的なのは TRAIN 列である。** 学習に使った発話でも 1.29–1.33 にとどまり、**事前分布単体（1.888）を下回る**。すなわちネットワークは自分の学習データすら適合できていない。これは汎化の問題ではなく**最適化・容量の問題**であり、両者の対処法は交わらない:

- 汎化の問題なら → データ増、正則化、敵対的損失

**したがって §12.6 の手順は再び改まる:**

> 2''. H-F の対照実験の前に、**まず学習が学習データに適合することを確認する**。TRAIN が事前分布を有意に上回るまでは、損失の種類も事前分布の種類も比較できない。着手順: バッチサイズを上げる（現状 1）、学習率を下げる、勾配蓄積、そして層数・チャネル数の探索。**この確認を経ていない対照実験は、何を測っているか定義できない。**

**手順 2'' の第一段を実施した（バッチ 8、LR ピーク 8e-4 → 3e-4）:**

**診断は正しかった** —— TEST が 1.52 → 1.82 へ動き、事前分布に接近した。バッチサイズ 1 の勾配雑音が主因の一つであったことは確定である。

**しかし TRAIN は 1.39 にとどまり、依然として事前分布 1.888 を下回る。** 最適化を改善しても学習データに適合できないので、**残るのは容量またはアーキテクチャの問題**である。具体的な疑い:

- 周波数方向の受容野が狭い。カーネル (7,3) × 8 層で 56 ビン / 257 ビン。スペクトル包絡は帯域全体に相関を持つので、これでは局所的すぎる可能性がある
- チャネル 32・0.223M は Wavehax（0.623M）の 1/3。Wavehax は**非因果**でこの容量なので、因果化のぶんさらに必要かもしれない
- 事前分布が調波枝のみなので、ネットは無声区間を完全に発明せねばならない。Wavehax の事前分布にも雑音項 `0.01·z[n]` があり、これが無いと確率成分の出発点が存在しない

- **容量**: 64ch × 10 層 = **1.111M**（Wavehax 0.623M の 1.8 倍。因果化のぶんを見込む）
- **事前分布の雑音項**: `h + 0.05·σ(h)·z`。Wavehax の `0.01·z[n]` に対応する。**arm B には確率的な種が一切無く、TF 領域のネットは無音から雑音を作れない** — これが「無声区間を発明できない」ことの構造的な理由であった

**修正の効果を測定した**（反復可能にするため 48ch × 8 層 = 0.501M、膨張 `[1,2,4,8]×2`（受容野 181/257 ビン）、学習 80 発話・評価 12 発話に縮小）:

**しかし絶対水準が足りない。** 1.53 に対し DSP コア全体は 2.97 であり、ネットは息枝を置き換える水準に遠く及ばない。**+0.06 は「壊していない」ことの証拠であって「有用」の証拠ではない。**

### 12.9'' 因果性のコストは実質ゼロ（2026-08-04）

「2.9 と SOTA 4.2 の差」が **因果性 / 容量 / 学習量** のどれに帰属するかは未分離だった。分離できなければ「低遅延だから届かない」とも「規模が足りないから届かない」とも言えない。

因果性だけを切り分ける実験は安い。**同じネットワーク・同じパラメータ・同じデータ・同じスケジュールで、時間方向のパディングを左詰め（因果）から対称（非因果）に変えるだけ**である。

| step | 因果（出荷制約あり） | 非因果（制約なし） | 差 |
|---|---|---|---|
| 500 | +0.2206 | +0.2133 | **−0.007** |
| 1000 | +0.2372 | +0.2292 | **−0.008** |

**因果性のコストは 0.008 PESQ、実質ゼロである。**

**含意は二つ。**

1. **2.9 と 4.2 の差は低遅延制約ではない。** 残るのは容量（0.5M 対 122M、244 倍）と学習量である。**製品の低遅延要件は、この経路の品質上限を実質的に下げていない。**
2. これは TF 領域で処理することの帰結として自然である。時間方向の受容野が必要なのは主に包絡の連続性であり、それは過去だけで足りる。**MS-Wavehax が「因果・先読み 1 フレームで MOS ≈ 自然音声」と報告しているのと整合する。**

**この測定の限界**: step 1000 まで、0.501M、80 発話、8 発話評価、単一シード。差 0.008 は測定誤差と区別できない —— **区別できないことこそが結論**であり、「因果性が主要因である」という仮説を棄却するには十分である。ただし「因果性のコストが厳密にゼロ」を主張するものではない。

### 12.10' 訂正 — 初版の帰結 2・3 は誤りだった（査読 S4）

初版はここから「**振幅のみの目的関数の天井は 3.714**」「したがって 3.714 を超える計画は位相を直す目的関数なしには成立しない」と書いた。**両方とも誤りであり、しかも本レポート自身の定理 2 と矛盾する。**

`mrstft` は 256/64・512/128・1024/256 の 3 解像度、各冗長度 `R = 4` の**過完備**振幅を比較する。**目標 `x` 自身がこの損失を 0 にする。** すなわち大域最小点集合は `x` を含み、`mrstft` 単独で到達しうる上限は **4.644 であって 3.714 ではない**。そして §2.3 定理 2 は「過完備な振幅は信号を（大域位相を除いて）決定する」と述べている —— **同じ文書が「振幅は信号を決める」と「振幅は位相に盲目」を同時に主張していた。**

正しい言明はこうである。

> **3.714 は「事前分布の位相を保存したまま振幅だけ差し替える *パラメータ化* の天井」であり、目的関数の天井ではない。** 写像族の性質であって、損失の性質ではない。

**swapP のラベルも過大である（査読 S5）。** `|Y|·∠X` を iSTFT した波形は、非整合スペクトログラムの重畳加算射影を受けるので、**もはや振幅 `|Y|` を持たない**。射影は振幅も `|X|` 側へ引き寄せる。したがって +0.712 は「位相だけを完璧にした利得」ではなく「位相を完璧にした結果、射影が振幅も一部修復した利得」である。**「位相ヘッドルーム」という帰属は未検証である。**

**バイアスの向きについての初版の説明も誤っていた（査読 S11）。** 位相子 `Y/(|Y|+ε)` は常に減衰側なので発散はしない（ε=1e-8 に対し音声振幅は通常 1e-5 以上なので、効果は 0.1 % 未満とみられる —— **未計測**）。そして「swapP 側の潰れは目標が 0 の bin なので影響しない」は誤りで、`|X|→0` の bin では swapP が事前分布の余剰エネルギーを無料で消す ＝ **swapP に有利なバイアス**である。結論の向き（補正すれば振幅側に傾く）は偶然保たれるが、理由は違っていた。

**§12.10 から生き残るのは「振幅と位相がほぼ等分で、片方だけでは 3.71」の一点である。**

事前分布への白色雑音加算だけで **0.266 PESQ** を失っている。そして +0.237 はその劣化した値に対する利得である。**学習後の値が、何もしなかった場合に届いているか**を見るには 8 発話上のクリーンコアが要るが、それはログに無い。12 話者の雑音コスト 0.2657 を当てた推定値は ≈2.914 なので:

雑音を入れた理由はログのコメントに残っている —— arm B（事前分布＝調波枝のみ）では「TF 領域ネットは決定的入力から雑音を作れない」ため、無声音を合成する種が要る。**arm C の事前分布は息枝を含む DSP コア全体なので、この理由は成立しない。** 種は既に事前分布の中にある。

§6.4 の 4 点検査との関係を明示しておく。検査が要求するのは「事前分布が乱数場を持つならそれを毎ステップ引き直せ」であって、「乱数場を持て」ではない。**`PRIOR_NOISE=0` は場そのものを消すので、検査は空虚に満たされる**（暗記すべき乱数場が存在しない）。したがってこれを外すことは退化ガードの緩和ではない。

`--pnoise 0` を追加して再学習中である。**§12.9 / §12.9' / §12.9''' の「+0.237」「2.885」は全て、この訂正後の数値に置き換えられる予定であり、それまで暫定値として扱う。**

`rddsp_gpu.py` は同一のネットワーク・損失・データ・クロップ手順で、実行だけを変えたものである（デバイス CUDA、コーパスを GPU 常駐、B クロップの Python ループを 1 回の積層前向きに、`prep` をディスクキャッシュ、**チェックポイント保存** —— CPU 系列は学習済みの重みを 1 つも保存しておらず、いま事後的に調べることができない）。§2.8 の退化ガードは全て保存している（事前分布の確率項は毎 step 再抽選、評価話者は学習に出現せず、条件付けは mel と事前分布のみ、TRAIN と TEST はそれぞれ自分の事前分布に対して報告）。

**「実行だけ」は厳密には正しくない（自己申告）。** 積層バッチ化は `mrstft` の第 1 項を変える:

```python
loss = (Y - T).norm() / (T.norm() + 1e-8)      # バッチ全体の Frobenius 比
```

CPU 版はこれをクロップごとに計算して `l/BATCH` で平均していたので、**バッチ内の各クロップが等重み**だった。GPU 版はバッチ全体の比なので、**音量の大きいクロップが重く**なる。第 2 項（対数振幅 L1、reduction=mean）と `L_MOS`（`.mean()`、クロップ長は固定）は両者で一致する。乱数列も異なる（生成器のデバイスが違う）ので、引かれるクロップと雑音実現は別物になる —— これは分布が同じなので偏りではない。

**査読 S3 がこれを定量した**: バッチ内に 18 dB のレベル差があると、クロップごとの実効重みが最大 **8 倍**傾き、損失値そのものが約 2 倍になる。`L_MOS` と対数振幅 L1 は `.mean()` なので不変であるから、**`mrstft` と `100·L_MOS` の相対重みが変わっていた**。さらに `clip_grad_norm_(1.0)` が別のスケールに掛かるので実効学習率も動く。

**修正した**（`rddsp_gpu.py` の `mrstft`）: `(freq, time)` でノルムを取ってからバッチ平均する。これは CPU のクロップごとループが計算していた量と一致する。**この修正以降の実行（`--tag clean` 以降）は修正版、`--tag conv` / `--tag noLmos` の対は修正前である。** 対どうしは同一定式なので比較は有効だが、CPU 系列との突き合わせには修正版を使う。

等価性は**主張ではなく測定**で確かめる: CPU と同じ 1000 step・同じ OneCycle 地平・同じバッチ・同じデータで走らせ、CPU の +0.2358 / +0.2372 に戻るかを見る（`--tag repro`）。**戻らなければ、この節の比較は全て無効である。** 参考として、地平 6000 の GPU 実行は step 1000 で +0.2055 —— 交絡込みだが、「実行だけの変更」で動きうる幅が **0.030** であることを示している（初版が主張したノイズフロアの 21 倍）。

**チェックポイント選択のバイアスも除去した（査読）。** 初版は TEST が最良の step で重みを保存していた —— **後でその `test` 値を系の値として引用すれば、最大 12 回の評価にわたる max になる**。§2.8 のガードを保存していると主張する当のファイルが新しい選択バイアスを導入していた。固定 step 保存に変更した。あわせて、評価が持っている**発話ごとの PESQ** を返すようにした（追加計算ゼロで対応差の 95 % CI が出る。初版はベクトルを捨てて誤差棒なしの差を報告していた）。

### 12.13 復調包絡は本当に ±f0/2 に帯域制限されているか（査読の未実施項目、2026-08-04）

§13 が「受け入れたが未対応」として記録した第一項:

復調器は 2 周期 Hann（通過帯域 ±f0）、k = 1,2,3,4,6,8 の平均、有声サンプルのみ。

| female（未使用 6 話者） | 380 Hz | **4.44 %** | 6.24 % | **−1.80 %** |
| ~~**male**（6 話者、`male_tts_corpus`）~~ | ~~62 Hz~~ | ~~1.58 %~~ | ~~4.31 %~~ | **撤回（下記）** |

**超過は検出されなかった。** real は両コーパスとも対照を下回る —— f0/2 より上のエネルギーは、対照が示すアーティファクト水準に埋もれている。**しかも生の real の値そのもの（女性 4.4 %、男性 1.6 %）が超過の上界である**（その一部は漏洩なので）。

**男性の行は撤回する（第 3 回査読 A5）。** `rddsp.py:374` の `harmonic_sum_f0` は `fmin = 60.0` であり、**6 話者中 3 話者がちょうど 60.0 Hz を返している —— 推定器のレール値である**。`rddsp.py:1475` 自身が「f0 は無声区間で 60 Hz へ落ちる」と記録している。

そして機構的に、f0 を半分に誤ると復調窓 `L = 2 周期 = 2·SR/f0m` が 2 倍長くなり通過帯域が半分になるので、**超過が小さく出るのは当然である**。§10 が開示した F0 オクターブ誤りの病理を、その開示を根拠に使う節で踏んでいた。加えて `pick_from()` はどの発話を選んだかをログに残しておらず、`male_tts_corpus` は 5 スタイル中 2 つ（`deep` / `calm_low`）が意図的に低ピッチである。

**再測が要る**（`fmin` を 40 Hz に下げるか、オクターブ補正した f0 を使い、選択発話を記録する）。それまで「低 f0 でこそ厳しいはずが逆だった」という物理的解釈は成立しない。少なくとも `(f0/2, f0)` の範囲では、包絡は周期に対して相対的に遅い。

> **【限定・第 3 回査読 A6】区間 `(f0/2, f0)` における超過の上界は、女性 6 話者で 4.44 % である。**

**「等号は物理的に正当」「査読の第一項は解消した」は言い過ぎであり、撤回する。** 理由は三つ:

1. **対照は漏洩床として無効である。** male・1 周期版・k=2 では対照が 39.44 %、real が 4.00 % —— **測定信号を 35 ポイント上回る「床」は床ではない**。原因は構成にあり、対照の包絡は複素ガウス雑音の低域通過（振幅 Rayleigh）なので**深い零点を頻繁に通り**、その瞬間は隣接倍音の漏洩に支配される。実音声の倍音包絡はそこまで零点を作らない。さらに 1/k 振幅は隣接比 ≈1 ＝ 漏洩最大の配置である。
2. **初版の「過大な床だから保守的」は論理が逆である。** 過大な床は「超過は検出されなかった」という**受け入れたい帰無を受け入れやすくする**。
3. **合否線が事前に宣言されていない。** 4.44 % は −13.5 dB 相当で、これを「無視できる」とする基準は §6.3 が要求する形式で宣言されていない。k 別では女性 k=1 で **+0.57**、k=8 で **+1.79** と 6 個中 2 個が正の超過であり、本文は平均だけを載せていた。誤差棒なし・n=6・1 発話ずつ・選択発話の記録なし。

**したがって §13 の第一項は「解消」ではなく「より弱い形で部分的に前進」である。**

**この測定が言っていないこと（自己申告）**:

- **復調器の通過帯域より上は見えない。** 2 周期 Hann の通過帯域は ±f0 なので、押さえたのは `(f0/2, f0)` の 1 オクターブだけである。それより速い包絡変動は測れていない。この 1 オクターブを選んだ理由は、標本化の議論では Nyquist のすぐ上のエネルギーが折り返してすぐ下に落ちるためで、最も効くのがここだからである。
- **1 周期 Hann（通過帯域 ±2f0）に広げる試みは失敗した**: real 38.9 % 対 対照 41.4 % で、両方とも漏洩に飽和している。**この構成では 2 オクターブ目は原理的に測れない**（隣接倍音が通過帯域の中心付近に来る）。負の結果として記録する。
- 対照は包絡の低域エネルギー分布が real と異なるので、アーティファクト水準を**過大に**見積もる。したがって「real < 対照」は保守的な向きの比較であり、逆向きの誤りは生まない。
- **男性側は `male_tts_corpus`、すなわち合成音声である**（実男性収録は `data/male_feat` に特徴量でしか無い）。合成音声は実収録より包絡が滑らかでありうるので、低 f0 の結論は**楽観側に偏りうる**。実男性収録での再測が要る。

安価な決定版は学習側でなく評価側にある: **学習済みのネットに、別話者の発話の mel を食わせる**（事前分布・雑音の引き・重みは同一、`rddsp_mismatch.py`）。

### 12.17 条件付けチャネルが最大 9.2 kHz ずれていた — §12.15 / §12.16 の帰属を取り消す（2026-08-04）

§12.16 の「クリーンな事前分布では利得ゼロ」を、overfit gate（学習する 4 発話そのもので評価）まで下ろしても **step 250 で +0.0000** だった。学習データすら改善できないなら「学ぶべきものが無い」ではなく実装を疑うべきである。チェックポイントを開くと出力層は `absmax 2.3e-4`、残差の RMS は事前分布の **0.13 %** —— 零初期化からほとんど動いていない。

原因は条件付けの提示方法だった。

```python
m = torch.nn.functional.interpolate(mel[None, None], size=(NBIN, T), mode="bilinear")
```

これは **80 本の mel 帯域を 257 本の線形周波数 bin の上に *線形に* 引き伸ばす**。mel 帯域は線形間隔ではないので、ほぼ全ての bin で違う帯域の値が入る:

| 線形 bin | 真の周波数 | 実際に見せていた mel 帯域 | その帯域の周波数 | 誤差 |
|---|---|---|---|---|
| 32 | 2 756 Hz | 10 | 543 Hz | **−2 213 Hz** |
| 128 | 11 025 Hz | 40 | 2 876 Hz | **−8 149 Hz** |
| 160 | 13 781 Hz | 49 | 4 548 Hz | **−9 233 Hz** |
| 224 | 19 294 Hz | 69 | 12 594 Hz | −6 700 Hz |

**周波数方向の受容野は 7 タップ・膨張 8 まで、すなわち ±50 bin ≈ ±4.3 kHz である。9 kHz のずれは橋渡しできない。** したがってネットは、**自分が補正しようとしている周波数における目標振幅を読めなかった** —— 振幅損失が必要とするまさにその量である。

修正は固定の `[NBIN, N_MEL]` 行列 1 つで済む（mel 帯域を真の中心周波数の上に置いて線形補間）。宣言された 80 帯域の界面は変わらない。修正後の実測: bin 32/64/128/192 で誤差 0 Hz。

**この節が取り消すのは結果ではなく帰属である。** 数値はそのまま残るが、「方式がこうだから」と読んではならない。

| 節 | 測定値 | 帰属の変化 |
|---|---|---|
| §12.15 | 利得の 88.8 % が別話者 mel でも生存 | **取り消す。** mel が壊れていれば mel が効かないのは当然。「事前分布に対して mel が冗長」という解釈は支持されない |
| §12.16 | クリーン事前分布で利得ゼロ | **取り消す。** 目標振幅を読めないネットが振幅を直せないのは当然 |
| §12.11 | 4 倍の容量が効かない | **取り消す。** 容量では壊れた条件付けは直らない |
| §12.9 / §12.9'' | +0.237、因果性コスト 0.008 | 対照実験としては内部的に有効（両腕とも同じ壊れ方）。**絶対水準は無効** |
| §12.10 / §12.13 / §12.14 / §12.12 / §12.12' | 振幅位相分解・包絡帯域幅・較正・デバイス・事前分布ハンデ | **影響なし**（ネットを通らない測定、または実行ログの算術） |

**これは本レポートが 4 回繰り返している同じ誤りの 5 回目である。** §5 は「数値の帰属を確かめずに方式の性質として記録するな」と定式化した。§12.12 は同じことを計算資源について犯した。ここでは**条件付けチャネルについて犯した** —— 「mel を与えている」と書いた時点で、それが読める形で与えられているかを一度も確認していない。**確認の操作は、mel 帯域の中心周波数と bin の中心周波数を並べて印字する 6 行だった。**

修正版で `--overfit 4` / `--pnoise 0` / 通常設定を再実行中である。**修正前後の差が、この節の主張の全てになる。**

### 12.18 【説明は撤回】mel は原因ではなかった — 勾配が雑音である（2026-08-04 → §12.20）

**修正版の overfit gate も step 250 / 500 で +0.0000 だった。** mel のずれは実在の欠陥だが、**これの原因ではない**。§12.17 の帰属取り消しはそのまま有効（壊れた条件付けで測った否定的結果は方式に帰属できない）だが、**「直したら動く」という予測は外れた**。

出力層の勾配を直接測った（`out` は零初期化なので、step 0 では全勾配がここに集まる）。

| 事前分布 | 損失 | `out.weight` の勾配ノルム |
|---|---|---|
| コア＋雑音 | 1.815 | 2.65 |
| **クリーンコア** | 1.069 | **8.47** |

**勾配は小さいどころか、クリーン側の方が 3 倍大きい。** Adam の ε 抑制でも学習率でもない。

そこで**勾配の一貫性**を測った —— 24 バッチの勾配を集め、`‖平均‖ / 平均‖·‖` を出す。1 に近ければバッチが方向に合意しており、`1/√24 = 0.204` なら純雑音である。

| 事前分布 | 勾配 SNR | 純雑音の水準 | バッチあたり ‖g‖ |
|---|---|---|---|
| コア＋雑音 | **0.509** | 0.204 | 1.81 |
| **クリーンコア** | **0.264** | 0.204 | 12.9 |

> **クリーンな事前分布に対しては、勾配はほぼ純雑音である。** バッチごとに必要な残差の向きが食い違い、その平均がほぼ 0 になる。**この目的関数の下で学ぶべき一貫した補正が存在しない**、という条件付き期待値の言明である。

**§12.10 と組み合わせると、何が起きているかが言える。** 振幅を完璧にすれば +0.742 得られる（swapM）。つまり補正は**存在する**。しかしそれは条件付き平均ではない。理由は情報にある:

- 事前分布の倍音は周波数・振幅がわずかに違うので、bin ごとに `|T|` を上回ったり下回ったりする。**どちらであるかは倍音の微細構造で決まる。**
- ネットが目標側について持っている情報は **80 帯域の mel** である。高域では 1 帯域が f0 より広く、**倍音の位置を解像しない**。
- したがってネットは「この bin は目標より上か下か」を知りようがない。**符号がランダムに見える ⟹ 勾配が雑音。**

**そして BigVGAN は同じ mel から 4.010 を出す。** 矛盾しない —— **BigVGAN は補正していない。生成している。** 生成物は自前の倍音構造を持てばよく、我々の（わずかに違う）倍音位置に合わせる義務がない。**補正は生成より多くの情報を要求する。**

> **反証可能な予測**: 同じネット・同じ損失・同じ条件付けでも、**事前分布を「直す」のではなく「生成の足場」として使えば**、勾配は一貫するはずである。`--prior wavehax --direct`（事前分布は f0 の正弦波のみ、出力はスペクトログラムを直接予測）で検証中。**これが外れたら、上の情報論的説明は捨てる。**

この構成は同時に、**本セッションで唯一 deployable なアーム**でもある（f0 と mel はどちらも変換時に利用可能で、測定声門位相を使わない）。比較対象は同一 12 話者上の BigVGAN 4.0097 である。

### 12.19 【撤回】補正の勾配は雑音、生成の勾配は一貫している（2026-08-04 → §12.20 で撤回）

§12.18 の予測を、学習を待たずに勾配 SNR で直接測った。**同じネット・同じ損失・同じ条件付け・同じデータ・同じクロップ列。変えたのはパラメータ化だけである**（事前分布の上の残差か、スペクトログラムの直接予測か）。

| 構成 | 出力 | 勾配 SNR | バッチあたり ‖g‖ |
|---|---|---|---|
| 補正: コア＋雑音 | `P + o` | 0.509 | 1.81 |
| **補正: クリーンコア** | `P + o` | **0.264** | 12.9 |
| **生成: f0 正弦波を事前分布に** | `o` | **0.880** | 21.9 |
| **生成: DSP コアを *特徴* として** | `o` | **0.978** | 18.3 |

（純雑音の水準は `1/√24 = 0.204`。）

> **補正の勾配は雑音（0.26）、生成の勾配はほぼ完全に一貫している（0.98）。差は 3.7 倍で、雑音床からの距離で見れば 0.06 対 0.77 ＝ 13 倍である。**

§12.18 の情報論的説明が支持された。**補正は「この bin は目標より上か下か」を要求し、それは 80 帯域 mel が解像しない倍音の微細構造で決まる。生成は目標値そのものが勾配の向きを与えるので、その符号問題が存在しない。**

**最良は「DSP コアを特徴として渡し、直接予測する」（0.978）である。** 事前分布の情報を捨てずに、補正の符号問題だけを回避する。これは残差結合を外す 1 行の変更であり、`--prior core --direct` として実行中。

**この結果が言っていないこと（重要）。** 勾配 SNR は**学習可能性**についての言明であって、**与えられた step 予算での到達点**についてではない。残差型は step 0 で事前分布そのもの（2.9726）から始まる —— 巨大な出発点の優位である。直接予測型は step 0 で**無音ないし雑音**から始まる（実測: `coredir` は step 0 で 1.1023、`deploy` は 1.1891）。**6000 step で 2.97 を超えて生成することは期待できない。** Wavehax の公表実装は 100 万 step 規模で学習されている。

したがってこのセッションで示せるのは **SNR の差と初期の軌跡であって、終点ではない**。「生成の方が良い」は現時点で**学習可能性の主張**に限定される。

**副産物の罠（記録に値する）**: 直接予測で出力層を零初期化すると、**勾配は厳密に 0 になる**。`|STFT(0)| = 0` であり `abs()` の劣勾配は 0 なので、**振幅損失は無音解で微分が消える**。零初期化のネットは無音から永久に脱出できない。本プローブの初回は `mean|g| = 0.000e+00`、`SNR nan` を返し、最初の deploy 実行は 500 step にわたって PESQ 1.0 に張り付いた。零初期化は「step 0 が事前分布と一致する」という**残差設計のための道具**であって、直接予測では有害である。

### 12.20 §12.18 と §12.19 を撤回する — 測定は動作点に交絡していた（2026-08-04）

§12.18 の情報論的説明には直接のオラクル検査がある。**目標振幅を 257 bin のフル解像度で 1 チャネル足す**（レート 0.5 の条件付け ＝ 転送であり、§2.8 の下で系として報告できない。診断としてのみ使う）。説明が正しければ勾配 SNR は跳ね上がるはずである。

| 条件付け | 勾配 SNR |
|---|---|
| mel のみ（80 帯域） | 0.2635 |
| **mel ＋ オラクル `log|STFT(gt)|`（257 bin）** | **0.2929** |

**動かなかった。** 目標振幅を完璧な解像度で与えても、勾配は雑音床（0.204）のすぐ上のままである。**§12.18 の「解像度が足りないから符号が分からない」という説明は反証された。撤回する。**

**そして §12.19 の主張も撤回する。理由は測定の交絡である。**

補正型は `S = P + o`、生成型は `S = o`。どちらも `dS/do = 1` なので、**同じ `S` の点で評価すれば `dL/do` は厳密に同一である。** 両者の SNR が違ったのは、**測定した動作点が違うから**にほかならない:

- 補正型は初期化時に `S = P` ＝ **既に 2.9726 の音声らしい信号**。ここでの勾配は「最後の詰め」であり、bin ごと・クロップごとに要求が食い違う。
- 生成型は初期化時に `S = o` ＝ **ランダムなゴミ**。ここでの勾配は「とにかく音声らしくしろ」であり、全クロップ・全 bin が同じ方向を向く。

**目標から遠い点で測れば勾配は必ず一貫している。** それは「生成というパラメータ化が優れている」ことの証拠ではなく、**「初期化が目標から遠い」ことの証拠でしかない。** 0.880 / 0.978 という数字は、パラメータ化ではなく距離を測っていた。

**本セッションの SNR 測定は全て初期化時のものであり、したがって「最初の数ステップ」についてしか語らない。** これを明記していなかった。

**生き残る事実**（説明ではなく観測）:

1. **クリーンな DSP コアを事前分布とする補正型は、2500 step 動かなかった**（TEST 利得 ±0.0001、出力層 `absmax` 1.5e-4）。overfit gate（学習する 4 発話そのもの）でも同じ。
2. その動作点での初期勾配は雑音床のすぐ上（0.26）であり、**目標振幅をフル解像度で与えても変わらない**（0.29）。
3. 雑音を足した事前分布（2.7043）からの補正は動く（0.51、そして +0.24 に到達する）。**差は「除去すべき既知の劣化があるか」である。**

**なぜ 2.97 の近傍で勾配が一貫しないのかは、未解明のまま残る。** 情報の解像度ではない（オラクルで反証）。静的な傾斜でもない（§12.15）。条件付けの誤配置でもない（§12.17 で修正後も同じ）。**説明を持たない観測として記録する。**

**§12.19 の副産物（直接予測＋零初期化で勾配が厳密に 0）は独立に有効である** —— `|STFT(0)| = 0` と `abs()` の劣勾配 0 は動作点の議論と無関係な事実であり、`mean|g| = 0.000e+00` として実測されている。

**§12.20 自身も反証可能な形にしておく。** 主張は「同じ動作点なら 2 つのパラメータ化は等価」である。それを直接試す構成が既に走っている: **直接予測型を、最初の 600 step で事前分布の複製に warm-start する**（`--direct --warm 600`、損失は `‖S − P‖²`）。事前分布の複製に到達した時点で両者の動作点は一致するので、

> **§12.20 が正しければ、warm-start 後の直接予測型は残差型と同じく停滞するはずである。改善したら §12.20 は誤りである。**

warm 段階は機能している（step 0 で TEST 1.1023 → step 500 で 2.5799、MSE 0.0168）。切り替え後の軌跡:

| step | 段階 | TEST | 事前分布（2.8905）との差 |
|---|---|---|---|
| 0 | 直接予測・ランダム初期化 | 1.1023 | −1.788 |
| 500 | warm（`‖S−P‖²`） | 2.5799 | −0.311 |
| 1000 | 実損失（切替は 600） | 2.8150 | −0.075 |

**動作点に到達した。** ここから先が判定である。**残差型（`--pnoise 0`、同じクリーン事前分布）はこの点で 2500 step 動かなかった。** 直接予測型が同じ点で同じく停滞すれば §12.20 は支持され、超えれば §12.20 は誤りである。

### 12.20' 同一動作点で測った — §12.20 の「等価」も強すぎた（2026-08-04）

§12.20 は「同じ `S` なら `dL/do` は厳密に同一だから、パラメータ化は無関係」と論じた。**論じるのではなく測った。**

`coredirw`（warm-start 済みの直接予測型）は step 2000 で **TEST 2.8898、事前分布 2.8905** —— すなわち**初期化直後の残差型が座っているのと同じ動作点**にいる。そこで勾配 SNR を測る。

| ネット | 動作点 | 勾配 SNR | バッチあたり ‖g‖ |
|---|---|---|---|
| 残差型・**ランダム初期化** | クリーンコア | **0.2635** | 12.9 |
| 直接型・**2000 step 学習済み** | クリーンコア（同一） | **0.9904** | 60.1 |

**同じ動作点で 0.26 対 0.99。§12.20 の「等価」は誤りである。**

**ただし §12.20 の論証自体は正しい。** `dL/do` は確かに同一である。違うのは**その先**である:

```
d(loss)/d(out.weight)  =  Σ_positions  dL/do[·, pos] · h[·, pos]
```

`dL/do` が同一でも、**上流の特徴 `h` が違えば射影が違う**。ランダム初期化の `h` は情報を持たないので、24 672 個の位置にわたる和が打ち消し合う。学習済みの `h` は必要な補正と揃っているので、和が残る。

> **効いているのはパラメータ化でも動作点でもなく、上流の特徴が情報を持っているかである。**

**そしてここでパラメータ化が間接的に効く。** 「事前分布をそのまま出す」という解が、

- **残差型では `o = 0`** —— 零初期化そのものであり、**ブロックは何も学ばない**。
- **直接型では `S = P` を作る非自明な写像** —— ブロックは入力（事前分布のスペクトル、mel）から出力を組み立てる表現を**学ばざるを得ない**。

**残差型は「何もしない」が無料なので、特徴を獲得する契機が無い。** これが §12.16 の停滞（クリーン事前分布で 2500 step 動かない）の、現時点で最も整合的な説明である。

**この帰属も反証された（下記）。**

### 12.20''' 移植実験 — 「学習済み特徴が効く」も誤りだった（2026-08-04）

`coredirw` の学習済みブロックを**零初期化の出力層とともに残差型に移植**した。動作点（`o = 0` ⟹ `S = P`）もパラメータ化も揃い、**変わるのは `h` だけ**である。

| 構成 | 勾配 SNR | バッチあたり ‖g‖ |
|---|---|---|
| ランダムブロック・残差・`out=0` | 0.2635 | 12.9 |
| **学習済みブロック・残差・`out=0`** | **0.0971** | 8.4 |
| 学習済みブロック・直接・`out` も学習済み | 0.9972 | 118.3 |

**学習済み特徴を入れると SNR は 0.264 → 0.097 に *下がった*。純雑音の水準（0.204）すら下回る。** §12.20' の「効いているのは上流の特徴が情報を持っているかである」は**誤りである。撤回する。**

残る差の出所として考えられるのは、**直接型の動作点が実は `P` ではないこと**である。直接型の出力 `o` は `P` の*近似*であり、両者の差はネット自身が作った系統的な誤差である。**その自作の誤差を直す勾配が一貫しているだけかもしれない** —— それは DSP コアの残差を直すこととは別の課題である。

**したがって機構は未解明である。** 本節で試みた説明は 3 つとも直接の検査で反証された:

| 説明の試み | 反証した測定 |
|---|---|
| 「条件付けの解像度が足りない」（§12.18） | オラクル `log|STFT(gt)|` を与えても SNR 0.26 → 0.29（§12.20） |
| 「補正と生成というパラメータ化の差」（§12.19） | 同じ `S` なら `dL/do` は同一（§12.20） |
| 「学習済み特徴の差」（§12.20'） | 移植すると SNR が 0.097 に下がる（本節） |

**確立しているのは経験的事実だけである**: 同じクリーンな事前分布に対し、**残差型は 2500 step 動かず、直接型＋ warm-start は事前分布を超える**。**なぜかは分かっていない。**

### 12.21' 唯一意味のある比較 — 学習したネットは「何もしない」に勝つか（2026-08-04）

本セッションの数字は全て、それぞれの系が**自分の事前分布**に対して測られてきた。しかし正しい基準は自分の事前分布ではない。**ネットを一切走らせずに得られる値、すなわちクリーンな DSP コア 2.9726 である。** 完走した 3 本を、未使用 12 話者全体でその基準に対して測り直した（`final_cmp.py`）。

| 実行 | 構成 | ネット | 自分の事前分布に対して | **クリーンコアに対して** |
|---|---|---|---|---|
| `convfix` (6000) | 残差・雑音事前分布・`L_MOS` 100 | **2.9970** | +0.2927 ±0.0922 | **+0.0244 ±0.0225** |
| `nolmosfix` (**6000、完走**) | 残差・雑音事前分布・`L_MOS` なし | 2.9947 | +0.2904 ±0.0919 | +0.0221 ±0.0230 |
| `coredirw` (**6000、完走**) | **直接＋warm-start・クリーン事前分布** | 2.9786 | +0.0060 ±0.0025 | **+0.0060 ±0.0025** |

> **勝つ。ただし +0.02 である。**

### 12.21'''' 振幅損失の勾配の 86 % は、聞こえない bin に費やされていた（2026-08-04）

§12.21'' が残した非自明な問い ——「`mrstft` は 3 解像度の**対数振幅 L1** を含む、すなわち振幅を直すための損失である。なぜ 0.5M のネットが 6000 step かけて帯域レベル誤差を 0.045 dB しか動かさないのか」。

対数振幅 L1 には既知の失敗様式がある。

```
L = | log(|Y| + eps) − log(|T| + eps) |,   eps = 1e-5（絶対値）
```

微分は `1/(|Y| + eps)` なので、**目標がピークより 100 dB 低い bin は、ピークの bin の 10⁵ 倍の勾配を受け取る**。対数は下端を潰すのではなく**引き伸ばす**。

測った（`rddsp_lossmass.py`、保留 12 話者、3 解像度、モデル非依存 —— これは損失とデータの性質である）。全 (周波数, 時刻) bin を、その発話のピークからの目標レベルで分類する:

| 目標のレベル | bin の割合 | 損失の割合 | **勾配の割合** |
|---|---|---|---|
| 0 〜 −20 dB | 1.10 % | 0.38 % | **0.00 %** |
| −20 〜 −40 dB | 7.49 % | 6.21 % | **0.01 %** |
| −40 〜 −60 dB | 21.20 % | 19.50 % | **0.19 %** |
| −60 〜 −80 dB | 20.15 % | 20.51 % | 1.63 % |
| −80 〜 −100 dB | 18.57 % | 20.05 % | 12.25 % |
| **−100 dB 以下** | 31.49 % | 33.34 % | **85.91 %** |

> **可聴域（ピークから −60 dB まで）は bin の 30 % を占めながら、勾配の 0.20 % しか受け取っていない。**
> **−100 dB 以下の bin が勾配の 86 % を持っている。**

**ネットは無音を最適化していた。** 聴取者が名指しした 2–4 kHz のプレゼンス帯は、聞こえない bin と**同じ土俵で競争させられていた** —— しかも 500 分の 1 の重みで。

**これは説明であって、まだ結果ではない。** 反証可能な形にする:

> **対数の床を目標のピークに対する相対値（−60 dB）に変えれば、勾配は可聴域に戻る。戻れば BLE は改善するはずである。改善しなければ、この説明は誤りである。**

`--logfloor -60` / `-80` を実装して実行中。**修正は 1 つの数である**（絶対 `eps = 1e-5` → 目標ピーク比 −60 dB でクランプ）。

**この節が本セッションで最も移植性が高い。** 対数振幅損失は神経ボコーダの標準部品であり、絶対 epsilon はその標準的な書き方である。**同じ配分は、この実装に固有ではない可能性が高い。**

## 14. 一文で

> **解析再合成ベンチマークで高いスコアが出たら、まず「その構成は参照信号をパラメータの名目で運んでいないか」を疑う。界面は枝ごとに、入力側と出力側の両方について、レートで宣言する。門は監査ではなく探索の制約として実行する。学習を入れたら 4 点検査を必ず添える。**

これを 3 回の失敗で学んだ。

**そして 2026-08-04 に、同じ規律が測定の *環境* にも要ることを 4 件の失敗で学んだ。** 数字を出す前に:

1. **デバイスは意図どおりか。** `torch.cuda.is_available()` を分岐に入れ忘れて、GPU の隣で全実験を CPU で回し、それを「計算枠の限界」として方式の結論に書いた（§12.12）。
2. **baseline を自分で劣化させていないか。** 事前分布に足した雑音だけで 0.266 PESQ 失っており、「+0.237 の神経利得」はその劣化分に対する数字だった（§12.12'）。
3. **表の全行が同じ評価集合か。** 単一話者 12 発話と未使用 12 話者を同じ列に並べ、「別系と並んだ」と読んだ（§12.14）。しかもその単一話者は、比較相手が最も多くのデータを持つ個体であり、集合を変えるだけで同じ重みが 0.67 動いた。
4. **条件付けは、受容野の内側で正しい位置に入っているか。** mel 80 帯域を線形 bin に線形補間して**最大 9.2 kHz ずらして**与え、その状態で「mel は冗長」「クリーン事前分布では利得ゼロ」「容量が効かない」を negative result として書きかけた（§12.17）。

**5 件目は、書いた 30 分後に自分で反証した。** 「補正の勾配は雑音、生成の勾配は一貫している（0.26 対 0.98）」と書き、**そこから「補正は生成より多くの情報を要求する」という説明まで導いた**。オラクル検査（目標振幅をフル解像度で与える）が説明を反証し、さらに考えると**測定そのものが動作点に交絡していた** —— 同じ `S` で評価すれば両者の勾配は厳密に同一で、違ったのは初期化が目標からどれだけ遠いかだけだった（§12.20）。

> **目標から遠い点で測れば、勾配は必ず一貫している。それはパラメータ化の優劣ではない。**

**残るのは説明ではなく観測である**: クリーンな DSP コア（2.9726）を出発点とする補正は 2500 step 動かず、その動作点の勾配は雑音床のすぐ上で、**目標振幅を完璧に与えても変わらない**。理由は分かっていない。
