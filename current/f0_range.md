## 2. 教師 `f0hi.teacher_f0` v2(`training/f0hi.py`)
- A = 既存の harvest + stonemask(上限 1000Hz・既存の npy をそのまま使う)。B = 48kHz の DIO + stonemask(上限 2400Hz)。**harvest は 1.2〜1.5kHz 以上で無声と返すことがある**ため B は DIO。
- B を採るのは、B ≥ 950Hz で次の gate を**全て**通るフレームが、隣と ±300cent 以内で連続する 6 フレーム(30ms)以上のときだけ(それ以外は A とビット一致):
  1. 基音より下が空(ピークが 80Hz〜0.55p の最大より 25dB 以上大きい)。
  2. 倍音の谷(1.5p・2.5p の最大よりピークが 20dB 以上大きい: 基音が極端に弱い声の第 2 倍音では第 3・第 5 倍音が出る)。
  3. 音の線(±25% の中央値より 10dB 以上高い: 雑音の帯を落とす)。
  4. 第 2 倍音の線(2p が基音の 35dB 以内で ±40% の中央値より 8dB 以上高い)。
  区間の両端は最大 4 フレーム延ばす(B ≥ 600・隣と ±300cent・(4)を除く gate: グライドの出入りの階段を避ける)。区間内で A が B と 100cent 以内なら A を残す。区間の前後 8 フレームの半分以上で A が B/2 に安定して有声なら、B は第 2 倍音の取り違えとして区間ごと棄却する。
- 経緯(独立レビューで v1 の穴を指摘): v1 は (1) 15dB・(2) 12dB(1.5p のみ)・(4) が実質空で、item 16 の第 2 倍音と item 1 の雑音の帯を誤採用し、基音が極端に弱く傾き k^-4 の合成音(強制 B)で gate を 100% 通した。v2 で上記に強め、区間内の連続性・縁の延長・A との差・取り違えの文脈棄却を足した。
- 検証:
  - 合成音(`python f0hi.py`): 高音だけ 1000〜2000Hz × 傾き k^-1/-2/-3 × SNR 25/10dB: SNR 25dB で全て 100%・SNR 10dB で 84〜100%。普通の声 300〜900Hz × H1 を 0〜−40dB 弱める × 傾き k^-1/-3/-4 × 高域通過 = **150 条件で B 採用 0 フレーム**。gate 単体に強制 B = 2·f0 を与えた 180 条件で通過 **0**(v1 の穴)。
  - 実データ(`f0hi_audit.py`・`results/f0hi/audit_v2b.json`・実音声 300 + TTS 100 ファイルの先頭 12 秒・標本抽出 seed 固定・A は manifest の npy): 実音声 39 ファイルで B 採用 = 有声の 0.42%(1,592 フレーム)・TTS 0 件・区間内の 300cent 超の跳躍 0・採用の内訳 = A が B/2 107・A 有声で無関係 352・A 無声 1,133。**独立の pYIN(fmax 2400)が B 採用フレームの 98.4% を有声と判定し、93.6% が 100cent 以内で一致**(盲検ではないが B の選別に使っていない手法)。区間の縁 154 のうち A 無声 77・A 有声で 300cent 超の階段 21(A がオクターブ違いの縁)。
  - 層別の目視(A が B/2・A 有声で無関係・A 無声の 3 群・各 4〜12 区間のスペクトログラム・盲検ではない): v2 で A が B/2 の群は 4 区間とも本物の基音。v1 で見つけた第 2 倍音の誤採用(9 フレーム)は文脈棄却で消えた。残る不一致 6.4%(pYIN との差)は有声フレームの約 0.03%。
- 限界: 参照(正解)が無いので精度は pYIN との一致と目視による。基音が極端に弱く、第 3 倍音も弱い声(傾き k^-4 以上・高域通過)の第 2 倍音は gate を通さないが、通りうる実例は未確認。再現率は精度の下に置く(拾えない叫びは A のまま = 従来どおり)。

## 3. 作業の順序(各段に prereg・独立レビュー・数値の合否)
1. **教師の確定**: 実データでの精度の定量(未): 参照を持たないので、(a) 1kHz 以下で A と一致(B を採らない)・(b) 採用フレームの目視の標本検査(30 区間)・(c) pYIN(fmax 2400)との一致率。合格したら (2) へ。
2. **データ作成**(CPU・約 1〜2 時間の見込み): renderer の学習用の f0(`data/rvoc_f0` を複製して B を差し替え・`prep_f0hi.py`)と F1 の学習用の f0。A は既存の npy を再利用し、B のフレームだけ置換して台帳に枚数を残す。
3. **F1 の再学習**: f0est を上限 2200Hz で作り直し(CMNDF の遅れ 20〜960・分類 329 bin)・f0est2 と同じ手順・データ。合格線は f0est2 の値(オクターブ誤り 0.4〜0.7%・女声の偽有声 11% を悪化させない)+ 1kHz 超の再現率。
4. **出力部の追い学習**: rvoc2am2 の 300k から、新しい f0 の学習データで + 約 30k step。f0 の分布の寄せに 1kHz 超の層を足す(区間の 3% 程度)。評価: held21 を新しい教師の f0 で(item 8 の頭出しを含む)+ 1kHz 超のフレームの層別(logmel・PESQ)+ 耳(rvoc_08)。
5. **変換器への波及**: 目標の f0 の写像・表の単位の f0 依存・C0-7(高い f0 の領域)。
