## 1. なぜこの形か(直前の実測から)

| 実測 | 帰結 |

| STFT 窓合成は窓の半分の隠れた遅延 | 時間領域の加算合成+48k 因果後段=アルゴリズム遅延 10ms |

## 2. 構成

```text
入力 x(48k)─因果 log-mel(左寄せ 1024・hop 240)─(学習時のみ: 周波数伸縮 α・利得の摂動)→ content 符号器 C(因果 8 層)
目標の参照音声 ─ log-mel ─→ 話者符号器 S(平均+標準偏差)──────────── FiLM
明示 f0(因果 YIN・推論は目標レジスタへ写像)・レベル(入力 mel の平均)
          ↓
生成器 G(因果 10 層・200fps)→ 調波包絡 80 帯・雑音包絡 80 帯(対数振幅)・後段条件 32
          ↓
DDSP 骨格: Σ_k A_k sin(k·φ)(φ = 2π∫f0・A_k = 包絡(k·f0)・k·f0 < 22kHz)+ 帯域整形雑音 → s0
神経後段 P(48k 因果・dilation 1..512・残差形・0 初期化)→ y
```

- 時刻規約: フレーム t は入力 x[:(t+1)·240] だけで決まり、出力 [(t+1)·240, (t+2)·240) を t−1→t の直線補間で描く。y[n] ≈ x[n − 480]。
- 物理の軸: ピッチは f0 経路だけ(content 側の倍音は摂動で嘘)、調波の周期構造と位相は骨格が決定、息は雑音枝(一級市民)、
  包絡は生成器が周波数の関数として出す(k·f0 で標本化=声道のフィルタとしての意味を保つ)。
- ゼロショット: 参照音声だけで目標が決まる(学習した話者の ID を使わない)。

## 3. 学習

女声フルコーパス(実 2,775 + TTS 669 話者)の自己再構成。段 R(15k)= 15·多尺度 logmel + 2·mrstft + ContentVec 補助。
段 G = + LSGAN(MPD+MRD+CQT)+ 2·FM + 2·CIPT。L/I/C は事前登録を参照。

## 4. 推論(男→女)

content = C(男声の mel)、話者 = S(目標の参照)、f0 = 男声の因果 f0 を目標レジスタへ写像
(log f0' = μ_T + (σ_T/σ_S)(log f0 − μ_S)・μ/σ は登録時の定数)、レベル = 男声の mel 平均。
