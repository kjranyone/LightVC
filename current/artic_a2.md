## 1. 設計原理: NAM A2 の思想を声の物理へ写す

NAM の成功条件は 3 つ: (1) **速い高エントロピー構造(位相・周期・過渡)は入力信号が運ぶ**のでネットは作らなくてよい、
(2) 系そのもの(回路)は決定論的で**小さな因果ネット**で同定できる、(3) 学習は入出力の波形回帰(ESR+多解像度STFT)で済む。
A2 はここから tanh ゲート・FiLM・ボトルネックを削ぎ、LeakyReLU+活性化後1x1・非2乗等比 dilation の極小因果網に至った
([rep_theory.md](rep_theory.md) §8-5-A)。

声の生成(音源フィルタ理論・構音音声学)に写すと:

| NAM | 声(音声生成の物理) | 本設計の界面 |
|---|---|---|
| 入力信号(ギターの生信号) | **声門音源**: 声帯振動の周期パルス+声門乱流(気息)+狭めの乱流(摩擦) | **励起界面 e(n)**: 48kHz の励起波形。速い構造(周期・位相・ジッタ・息の微細 texture)は**ここだけ**が運ぶ |
| 回路(アンプ) | **声道+口唇放射**: 時変の共鳴・反共鳴、音源-声道相互作用 | **物理骨格**(時変全極フィルタ)+**A2 回路**(骨格が表せない非線形・非理想) |
| (NAM に無い拡張) つまみ | **構音状態**: 舌・顎・唇・軟口蓋の配置=声道形状。慣性があり遅い | **構音界面 a(t)**: 低次元・遅い・ピッチを持たない声道表現 |
| — | 声門の設定(開大率・緊張・気息) | **声門ノブ**: 傾斜・気息雑音量(ピッチ同期変調)など |
| — | 話者の静的な声質 | 静的話者条件(1 ベクトル) |

**設計の一文**: 速い構造は本物の入力声から持ってきて作らない。変えたいもの(声道・構音の癖・声門の質)は
遅く物理的な界面で変える。声道という回路は小さな因果網で同定する。

## 2. 今週の実測がこの切り方を要求する理由

1. **コーラスの正体**: Y-S1 decoder は潜在のずれを帯域によらずコーラス化し、閾値が低い(rms~0.1 で微〜有・合成ガウス雑音でも鳴る)。
   codec 潜在は物理的に意味のない座標なので、生成誤差がそのまま「声でない音」になる。
   → 構音界面なら生成誤差は「少し違う口の形」=自然な声の変動として鳴るはず(§8 S0-4 で検証)。
2. **帯域の安全性**: codec 潜在は 16–50Hz 帯がピッチ/位相を運び、低域通過するとピッチが崩れた(GT −12.7 半音)。
   構音器官は慣性で遅く、SPARC は構音軌道を **10Hz で低域通過しても MOS 3.82**(GT 4.01)で再合成している。
   → 構音界面では生成誤差の速い成分を物理的根拠つきで捨てられる(ピッチは励起側なので巻き添えにならない)。
3. **A/S 天井 vs 波形保存**: パラメトリック音源の分析再合成(WORLD・NSF-LTV oracle)は耳で不合格、波形保存(istft)は合格。
   → 本設計の恒等経路は**実音声の残差をそのまま通す線形予測の分析合成=数学的に可逆**(A/S 天井の外)。
4. **F0 権威**: 条件の間でピッチ情報が冗長になることが 7 負例の根因。
   → ピッチは励起だけが運び、構音界面はピッチを持たないように作る(§8 S0-3 で検証)。構造的な権威。
5. **萌え=構音クセの clone**(データ検証を生き残った唯一の仮説・`training/articulatory_probe.py`):
   萌え構音 = F1↑(cute +0.82・intimate +1.54 SD)・F2 幅↓(−1.09)・構音の動き↓(−0.86)・母音空間↓(−0.75)、
   構音の話者間割合 0.56〜0.64。→ 変換の本体を構音界面の軌道変換にでき、そのまま意味の分かるノブになる。

## 3. 界面の定義

### 3.1 励起界面 e(n)(48kHz・速い構造の唯一の運び手)

- **学習時**: 実音声を(固定係数のプリエンファシス後)因果な時変線形予測で逆フィルタした残差。厳密には声門流そのものではなく
  「声門流の微分+乱流」を平坦化した近似で、声門のスペクトル傾斜は全極包絡の側に入る。VC で声門の質を目標側へ替えるには、
  傾斜を包絡から分離する IAIF 型の分解(声門成分と声道成分を反復で分ける)を併用する(S0 では通常の LPC から始め、Step 2 で要否を判断)。
- **変換時**: 入力話者の残差を物理的に変換する。
  - ピッチ: 残差の因果 TD-PSOLA(声門閉鎖点=残差のピーク列で周期単位に並べ替え)。フォルマントは残差に無いので
    音声全体の PSOLA より破綻しにくい(古典的手法)。
  - 声門の質: 傾斜フィルタ(開大率・声門の柔らかさ)、**気息雑音をピッチ同期で変調して加算**(Hermes 1991: 定常雑音は別の流れに
    聞こえ、ピッチ同期変調だけが気息として融合する。メモリ「NSF-LTV 設計レビュー」の知見)。
- 息・囁き・無声音は残差の雑音がそのまま運ぶ(ASMR の息を「作らない」)。

### 3.2 構音界面 a(t)(遅い・低次元・ピッチを持たない)

要件(§8 で数値検証してから選ぶ): (R1) 遅い: 変調スペクトルの大半が ~15Hz 以下、(R2) ピッチ盲: a(t) から f0 を予測できない、
(R3) 内容を運ぶ、(R4) 声道長(VTL)と構音の癖を操作できる、(R5) 因果に推定できる。

| 候補 | 中身 | 長所 | リスク |
|---|---|---|---|
| A. 声道面積(LPC 反射係数/LAR) | Wakita 1973 型の無損失管近似 | 因果・安価・骨格フィルタと可逆に対応・VTL 操作が自然 | 高 F0 で LPC が倍音に釣られる(R2 違反の恐れ) |
| A'. 離散全極モデル(DAP) | 倍音点だけに当てる全極包絡(El-Jaroudi & Makhoul 1991) | 高い声でも包絡が倍音に釣られにくい | 反復推定の計算量・因果窓での安定性 |
| A''. 周波数ワープ LPC | 低域の解像度を上げた全極(音声符号化で標準) | 低い次数でフォルマントを捉え、高域は粗く=倍音への張り付きが減る | ワープ全極の因果合成と可逆性の実装 |
| B. フォルマント(F1–F5・帯域幅) | LPC 根 | 萌えの検証指標と同じ座標 | 追跡の飛び(遅さ R1 に反する)・高 F0 |
| C. 擬似 EMA(舌・唇・顎) | 補助の構音逆推定モデルを教師にした自前因果推定器 | 話者非依存(VC に理想) | 教師(SPARC 系)は英語・WavLM 依存・東アジア言語で劣化(CER 31%)、ライセンス要確認 |

初期の本命は **A 系(A/A'/A'')=骨格と可逆に対応するため**。a(t) は全帯域の LAR(48kHz で次数 ~48、または A'' で ~24)を
2.5ms 毎に更新する「少数次元・遅い」系列で、萌えノブ・VTL は a(t) から導いたフォルマント(B)として表示・操作し、極の角度として骨格へ戻す。
LAR = log((1−k)/(1+k)) は実数全体が安定なフィルタ(|k|<1)に対応するので、**誤差や低域通過を LAR 上で加えても骨格は不安定にならない**。
注意: 次数が高いほど高い声で極が倍音に張り付き、遅さ(R1)とピッチ盲性(R2)を同時に壊す。次数・帯域・A/A'/A'' を S0-2/S0-3 で掃引して選ぶ。
C は Step 2(話者間の構音スタイル写像)で必要になったら検討する。

### 3.3 静的条件・ノブ

- 話者の静的声質: 1 ベクトル(AdaIN 系で静的音色の clone は実証済み)。
- 萌えノブ(構音軌道の変換): F1 シフト・F2 軌道の圧縮・構音速度の減衰・母音空間の中心化(`articulatory_probe` の効果量で初期値)。
- 声道長ノブ: フォルマント(極の角度)の一様スケーリング(女声化で ×1.15〜1.2 程度)。
- 声門ノブ: 傾斜・気息量・(任意)ジッタ/シマ。

## 4. ネットワーク構成

```text
入力声 x(n) ──因果LPC解析──┬─ a_src(t)(構音界面) ──[変換: VTL・萌え・話者の構音癖]──→ a_tgt(t)
                           └─ e_src(n)(残差)──[因果PSOLA・声門ノブ]──────────────→ e_tgt(n)
                                                                                        │
  e_tgt(n) ──→ 物理骨格: 時変全極フィルタ H_{a_tgt} ──→ s0(n) ──→ A2 回路 ──→ y(n)
                                                        ↑            ↑ 各層1x1注入: a_tgt(t)・声門ノブ・静的話者
                                                        └ e_tgt(n) も回路へ(音源-声道相互作用の手がかり)
```

- **物理骨格**: 時変全極(LPC 合成)フィルタ。解析と同じ係数列を使えば**残差→音声が厳密に可逆**。
  声道の線形部分(時変共鳴)を明示するので、加算条件だけでは表しにくい「入力×時変フィルタ」の積を回路に学ばせなくてよい。
- **A2 回路**: 骨格出力 s0 と励起 e を入力に、構音界面・ノブを各層 1x1 で注入する極小因果網
  (48kHz・上げ層なし・LeakyReLU+活性化後1x1・A2 dilation・先読み 0)。役割は骨格が表せないもの:
  音源-声道相互作用(Titze 2008)、混合位相、放射、そして**変換で生じる不整合の修復**(PSOLA の荒れ・残差に残った元話者の痕跡)。
  恒等(無変換)では骨格だけで可逆なので、回路は「変換時の差分」を学ぶ。回路は残差形 y = s0 + A2(…) で出力層を 0 初期化し、
  学習開始時点から恒等が厳密に成り立つようにする。
- **変換器(Step 2)**: 構音界面上の軌道変換(遅い・低次元)。生成するのは遅い軌道だけ=今週の「速い微細構造を生成して壊す」問題の外に出る。

## 5. 検査 L/I/C(Step 1 の回路学習に対する見込み・prereg 前の下書き)

- **L**: 回路の学習は「変換往復で劣化させた界面 → 元の実音声」。L1/mel の最適は劣化で消えた情報の条件付き平均
  (微細構造がぼける)→ GAN(MPD/MRD/CQT)を併用。劣化は物理的に小さく保ち(§8 で上限を測る)、回路の仕事を主に決定論的な修復にする。
- **I**: ピッチ=励起だけ(構音界面はピッチ盲 R2 を S0-3 で実測してから)。話者性=静的条件+構音界面(VTL・癖)+**励起の声門形状**。
  励起が元話者の声門形状を運ぶ漏れは、学習時に励起へ形状摂動(傾斜・位相の無作為化)を入れて分布レベルで遮断する(摂動は入力側・教師は実音声)。
- **C**: (1) 回路が残差に残ったフォルマントの痕跡から声道を再構成し構音界面を無視 → 構音差し替えで出力が追従するかの感度試験で検出。
  (2) 回路が PSOLA の荒れを消すために周期構造ごと平滑化 → f0 追従と有声率で検出。(3) 変換を元に戻す → 学習は往復のみ・推論の変換は未知なので不可能。

## 6. 遅延・演算の見込み(Step 0 で実測して確定)

| 部品 | 先読み | 備考 |
|---|---|---|
| 因果 LPC 解析(左寄せ窓 20ms・2.5ms 毎更新) | 0 | 係数は窓ぶん遅れて追従(遅れであって先読みではない) |
| 残差の因果 PSOLA | ≲1 入力周期(男声 ~10ms) | D1 路線(c) の「先読み 10ms 生存」はスクリプト未保存のため**再実測** |
| 構音界面の低域通過(~15Hz) | 0 | 構音が励起より ~10ms 遅れる(遷移の鈍り)。S0-2 で影響を測る |
| 物理骨格・A2 回路 | 0 | サンプル単位で動く。**10ms フレームの待ちが不要** |
| 合計(アルゴリズム) | ~10ms | I/O ブロックを小さくできれば E2E 20ms 級が視野(README の理想値) |

演算: 骨格(次数 48 の全極・毎サンプル)≈2.3M MAC/s、解析 ≈20M MAC/s、A2 回路(12〜16ch)≈1.4〜2.4 GMAC/s(c32 decoder 同級)。
Rust で p95 3.5ms 以内の見込み(実測で確定)。発話全体の統計は使わない(窓内の自己相関のみ・正規化は固定定数)。
Rust 移植は Levinson 再帰・全極フィルタ・PSOLA の単純ループで、FFT も不要。

## 7. 合格錨に届く見込み(design_laws §3-7)

| 問い | 分かっていること | 分からないこと → Step 0 での測り方 |
|---|---|---|
| 天井は足りるか | 恒等経路は可逆(実残差+同じ係数)=元音声そのもの。錨 BigVGAN より上 | 実装上の可逆性 → S0-1(SNR≥60dB) |
| 構音界面は遅くて安全か | SPARC は 10Hz 低域通過で MOS 3.82 | 我々の LPC 系表現で「速い成分を捨てても元に近い」か → S0-2 |
| 構音界面はピッチを持たないか | 通常 LPC は高 F0 で倍音に釣られる | → S0-3(f0 予測 R² と倍音張り付き率) |
| 構音誤差はコーラスにならないか | codec 潜在では合成雑音でもコーラス | → S0-4(今週の chorus_probe と同じ形式の盲検 8 本) |
| 励起のピッチ変換は回路で直せる範囲か | 残差 PSOLA は古典的に中程度の変換まで良好 | 往復劣化の大きさ → S0-5 |
| 高 F0・囁き・喘ぎで解析が壊れないか | 囁きは雑音励起なので LPC に有利 | → S0-6 |

回路の容量: GlotNet は励起領域でモデルを小さくしても WaveNet より劣化が小さい(TASLP 2019)。本設計は恒等が可逆なので、
回路の仕事量は **S0-2/S0-5 で測る「変換による劣化」の大きさで上から抑えられる**。S0 で劣化が錨水準(logmel ~0.2)なら
回路は小さな修復で足り、劣化が c32 水準(~0.45)を超えるなら励起の作り方から見直す(§8 の fork)。

## 8. Step 0: 学習なしの検証(事前登録・この順で実施・耳は S0-4 のみ)

評価の共通規約: held24(各 held 話者の先頭発話・≤8s)+耳バッテリー(会話・喘ぎ・囁き)。数値は元音声参照の logmel/mrstft
(`eval_dec2.py` と同じ物差し)。錨 = BigVGAN v2 held24 logmel 0.195 / mrstft 1.02。

| ID | 何を | 合格の目安(事前固定) | fork |
|---|---|---|---|
| S0-1 | 因果 LPC 分析合成の可逆性・未来不変性(実音声プローブ)。float64 と float32(Rust と同じ精度)の両方 | float32 で SNR ≥ 60dB・先読み 0 | 不可なら実装を直す(方式の問題ではない) |
| S0-2 | 構音界面の遅さ: LAR の変調スペクトル(15Hz 超のエネルギー比)と、**残差は元の係数・合成は LAR 上で 10/15Hz 低域通過した係数**での再合成(製品と同じ因果フィルタ。零位相は参考値) | 因果 15Hz で logmel ≤ 0.195(錨以下) | 超えるなら次数・帯域・表現(A/A'/A'')を替える。全滅なら「構音は遅い」前提が我々のデータで不成立 |

| ID | 何を | 合格の目安(事前固定) |
|---|---|---|
| S0-7b | 因果パイプライン(因果 LPC・因果 f0・因果マーク・出力遅延 D の因果 PSOLA)の D 掃引(0/2.5/5/7.5/10/12.5/15ms)を**開発集合**(VCTK 男声 p226/p227/p232 の 8 発話=S0-5 で事後に見た集合)で行い、D* を決める | D* = 次の全てを満たす最小の D: +8 半音で片道 f0 誤差の中央値 ≤ 0.5 半音・オクターブ誤り 0・往復 logmel が同じ開発集合のマーク既知版(0.205)+0.03 以内。かつ実音声プローブの未来不変性で先読み ≤ D(INCONCLUSIVE は不可)。D* ≤ 15ms なら S0-7 を確定 PASS |

- 往復の復路は S0-5 と同じ(出力マークを再利用する非因果 PSOLA)。往路の因果化の代価だけを測るため。
- 開発集合で D* を選び、検査集合は D* を決めた後に 1 回だけ走らせる(検査集合で D を選び直さない)。
- 実装の修正(17:10・開発集合のスモークで判明・基準は不変): 因果 f0 を ship_front.causal_f0 の 48k 版から**自前の左寄せ YIN**(窓 1536・有声 d'<0.25・RMS>−60dBFS)に替えた。調波和は 48k の 1024 点窓で男声の倍音を分解できず harvest との有声一致 0.33〜0.48 だった。YIN は開発集合で 1 半音以内 97%・オクターブ誤り 1.4%。しきい値 0.25 は開発集合で決めた(検査集合は未使用)。
- **S0-7b = FAIL(17:18)→ fork「PSOLA の方式を替える」を実行(S0-7c)**: 因果マーク方式は有声検出の遅れ(YIN 32ms 窓)で各有声区間の先頭 30ms の 96% を
  変換できず(中間 23%・末尾 43%)、+8 半音の片道 f0 誤差 1.0〜1.7 半音。有声を検出してからマークを置く限り、立ち上がりの取りこぼしは約 2 周期より短くならない。
  **新方式 RRPS(残差の再標本化ピッチシフト)**: 残差を有声では毎サンプル ratio で読み(窓付き sinc・1/ratio 帯域制限)、読みが供給限界 n+D に届く前に局所周期の
  整数倍だけ戻して余弦クロスフェード(跳び先は直前 1 周期の相互相関で整列=WSOLA 型)。包絡は全極フィルタ側なので再標本化でフォルマントは動かない
  (声門パルスは時間方向に 1/ratio に縮む=女声の短いパルスの向き)。無声では等速で素通し(雑音に周期変調を作らない)。有声判定は出力遅延 D ぶん先まで使う(壁時計 n+D で既知)。
  開発集合の「入力有声フレームのうち出力 f0 が目標±1 半音に入る割合」: RRPS(D=10ms)0.606 > 非因果 PSOLA(マーク既知)0.577 > 因果 PSOLA 0.328。
  同じ指標の天井の目安 = WORLD で f0 だけ変えた合成 0.772(harvest 自身の誤りを含む)。基準は §8.1 と同一のまま S0-7c(開発集合の D 掃引)→ S0-5b(検査集合 1 回)。
- **界面の選び直し(17:54・開発集合と S0-3 の学習話者で測定・規則は実行前に固定)**: 男声(VCTK 開発集合)で残差に取り残される包絡の凹凸
  (200–5000Hz・傾き除去・白色床を差し引いた dB)と、S0-3 と同じ話者群での線形プローブ(Ridge・中心化 log f0)を次数×窓で測った。
  p24 因果 4.70dB/R² 0.076・p24 中心化 3.86/0.090・p32 中心化 3.16/0.111・p40 中心化 2.17/0.150・p48 中心化 1.12/0.182(因果は各 +0.8〜1.7dB)。
  規則「R² ≤ 0.1 の中で残差が最も平坦」→ **p24・解析窓の先読み 10ms(中心化)**。男声の包絡分散の取り込み 48% → 65%。
  RRPS の出力遅延 D ≈ 10ms がもともと要るので、中心化窓は**全体の遅延を増やさない**(D ≥ 10ms が条件)。
  次数を上げるほど包絡は取れるがピッチも漏れる(トレードオフが明確)。これを崩す候補は周波数ワープ LPC(A'')。
  以後の S0-7c・S0-5b はこの界面で行う(D 掃引は 10/12.5/15ms・基準の PSOLA 参照も同じ解析で取り直す)。

- **コーラスの一般則(耳で確認)**: 時変フィルタの包絡を 4Hz 以上・自然変動の 25% 以上で揺らすとコーラス/フェーザー感が出る。生成器の包絡誤差はこの帯域と大きさを避けなければならない(表現を替えても同じ)。

## 追記(2026-09-30): VC の励起演算の上限(学習なし・CPU・held 女声 10 発話 4s)

nvoc(mel → 波形生成)の耳 FAIL(元音声 > BigVGAN > nvoc)を受け、オーナー「NAM A2 思想と構音モデリングは?」への再検討。
A2 の前提「速い構造は入力が運ぶ」は、LPC 分析再合成(本物の残差)が PESQ 4.64 で透明なことで裏付けられる。詰まり所は約 1 オクターブのピッチ変換:

| 励起の作り方 | 指標 | 値 |
|---|---|---|
| 本物の残差を RRPS で ±11 半音往復(+声道長 α) | DTW 揃え log-mel L1 | 0.78(0.77) |
| 本物の残差を RRPS で ±4 半音往復 | 同上 | 0.54 |
| nvoc5r2(mel → 波形・耳 3 位) | 同上 | 0.26 |
| 正解タイミングで周期を近傍 5 周期の平均形に置換 | PESQ / logmel | 1.31 / 0.46 |
| 同上 + 周期ごとのずれを同スペクトルの位相乱数で作る | PESQ / logmel | 1.09 / 0.76 |

- 残差の時間方向の並べ替え(RRPS)は大きく壊す(dspvc_p0「コーラス出まくり」の実体)。
- 声門パルスを平均形や統計で作り直すと PESQ 1 点台 = 周期ごとの細かな揺らぎそのものが声の質を運ぶ(A/S 天井と同じ結論)。
- ∴ 「本物の励起を保ったまま 1 オクターブ上げる」演算が無い限り、A2 の源フィルタ形は VC に使えない。方針はオーナー判断。
