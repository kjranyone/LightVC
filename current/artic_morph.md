# 構音写像 VC — 操作者の身振り × 目標の声道と動き方 (status: PROPOSED・rev1・2026-10-25)

オーナー指示: 「構音モデリングの観点をしっかり入れないと、フォルマントシフトの質が製品の評価に直結する」「Graillon3 との違いは？」「OK、その目指す構音モデルを実現しましょう」(10-25)。前提の正本 = 10-01 のオーナーの選択「構音 = 声道の物理形状・変換は声道の形の空間で」([artic_inv.md](artic_inv.md)・メモリ articulatory-premise-division)。

## 1. 製品の枠

- 男声 → 女声は**固定の半音**(+0 / +5 / +7 / +12)で使う。目標の声域への自動のずらしは運用に無い(10-25)。
- 高さが利用者の手にある以上、変換の価値は**声道と動き方の変え方**だけで決まる。競合 = Graillon 3 級の DSP(高さ + 一律のフォルマントシフト = 声道を相似形に縮めるだけ・入力の細部はそのまま)。
- 合格の最低線 = 同じ入力・同じ k で「高さ + 一律のフォルマントシフト(最良の α)」(GU*)に、独立の本人らしさの物差しと耳で勝つこと。

= **静的な母音の配置は目標に寄せている(GU より 4.5 dB 近い)が、独立の網の本人らしさはフォルマントシフタと区別できない**。耳(10-24・自動の高さ)の「ピッチシフターを適用した質の悪い声・らしさが全く出ない」と合う。一律のフォルマントシフトは α によらず本人らしさ 0 = 目標の人を運ぶのは配置の先にあるもの。

## 3. 分担(本設計の核)

| 出どころ | 持つもの | 今の実装 |
|---|---|---|
| 操作者(因果) | 何を言うか(内容の単位)・いつ(タイミング)・高さ(入力 + k)・音量の大きな流れ | C1 の事後・F1・c0n(水準ずらし) |
| 目標・形態 | 単位ごとの声道の目標(母音・子音の位置・非一様) | 単位の平均の表(静的) = **D570 で配置は可** |
| 目標・動き方 | 単位の間・単位の中の動き(速さ・行き過ぎ・弱まり・調音結合)= 調音の動力学 | **無い**(表 + 汎用の文脈補正・操作者の C2 / c0n から動きが漏れる) |
| 目標・声の源 | 声門の開き方・息の混ざり・源の傾き | 汎用の倍音の素 + 帯の周期性の水準だけ |

過去の証拠(この順で効く見込み): 単位の平均は実軌道の本人らしさの 6〜7 割(ECAPA)/ 3〜4 割(WavLM)止まり(artic_inv §6e)・目標本人の c0 + 動きを内容に揃えると同一性 0.14 → 0.42(実女声 D165)・一律 / 非一様の声道の伸縮を入力の包絡に掛けるだけでは本人らしさが動かない(physvc_zs 段 2b)・声道の物理の管は話者を運ばない(artic_inv §6d)= **物理は骨格とつまみ、話者は動き方の細部**。

## 4. 段 1(学習なし・オラクル): 目標本人の実現のどの層が固定の半音で本人らしさを運ぶか(D571)

- 組 = 実女声の目標の参照外の台詞を男声 TTS に読ませた並行の組(D165 の作り方を作り直す・C1 の事後の DTW で整列・三角閉包で整列の誤差を確認)。
- 描画 = rvoc3hi(条件 = c0・包絡 c1〜c24・log f0・有声・4 帯の周期性・女声の再合成で耳の記録あり)・高さ = 操作者の f0 + 7 半音(全版共通)。
- 版: COPY(本人の録音の写し合成・天井)/ TAB(目標の表を操作者の単位の並びで = 静的な配置)/ DYN(目標本人の整列した包絡の軌道 = 動き方の上限)/ SRC(TAB + 目標本人の整列した周期性 = 声の源)/ DYNSRC / GU*(錨)。
- 物差し = WavLM-SV の余白(主)・ECAPA・配置。DYN − TAB と SRC − TAB の大きさで、段 2 で先に作る層を決める(規則は OVERNIGHT に測る前に書く)。

## 4b. 段 1 の結果(D571〜D576・2026-10-25・d571par 93 組・+7 半音・学習なし)

| 版(静的な表 TAB0 に足すもの) | WavLM-SV | ECAPA | 学習外 LDA の平均順位(29 人) |
|---|---|---|---|
| 錨 GU(一律のフォルマントシフト) | −0.012 | 0.002 | 14.8 |
| TAB0(静的な配置) | 0.027 | 0.085 | 9.2 |
| 製品 P57S0(D573) | 0.014 | 0.092 | 10.3 |
| 目標本人の動き XDYN | 0.026 | 0.122 | 7.8 |
| 声の源(4 帯の周期性)XSRC | 0.028 | 0.085 | 9.1 |
| 句の音量 c0 XC0 | 0.030 | 0.103 | 8.5 |
| 全部 XCDS | 0.028 | 0.137 | 5.9 |
| 本人の録音を高さだけ +7 へ REALK(天井) | 0.033 | 0.141 | 4.6 |

- 声の源は 0・動き方が最大の層・c0 は次(操作者のもの)。固定の半音では WavLM-SV の天井(REALK)が静的な表のすぐ上(本人の録音も高さを移すだけで 0.055 → 0.033)。
- 動き方の 7 割は 3 Hz 以上の速い成分(D574)・高さに頑健な CheapTrick の界面でも同じ = 倍音の縞の漏れではない(D575)・同じ揺らぎの整列を壊すと 0 = **内容に揃った軌道**(D576)。
- 線形の追従系(D572a)・参照の内容で索引したリッジの表(D574 XRT)は運ばない。

## 5. 段 2(候補・段 1 の結果で選ぶ)

- **A 動き方のパラメトリックな話者モデル**: 単位の目標へ近づく 2 次の追従系(時定数・減衰・行き過ぎ・弱まり・調音結合の強さを包絡の帯ごとに)を話者ごとの少数の値で持ち、20 s の参照から当てはめる(登録時・推論は因果の追従 = 先読み 0)。オラクル(当てはめた値で表の目標を動かす版 TAM)が DYN の何割を出すかで可否を決める。
- **B 声の源のパラメータ**: 源の傾き・息の比・帯ごとの周期性の分布を参照から推定し、励起(倍音の素 + 雑音)に入れる。
- **C 学習で読む動き方**: A が足りない場合だけ、参照を注意で読む生成(許可済み・写し / 継ぎはぎは禁止)を、話者の数 × 文の数の規模(rr14c / rr16c の教訓)で。
- 共通: 操作者の包絡・C2 から男声の形態が漏れる経路を、入力側の声道長・高さの摂動(分布の層)で塞ぐ。L/I/C は腕ごとに prereg へ。

## 6. 関門(男声 → 女声・固定の半音)

- 構音の軸 = WavLM-SV の余白で GU* に区間で勝つ(k = +5 / +7 / +12)。関門の線への追加はオーナー確認。
- 既存の軸(d109 の 4 軸・明瞭さ CER・出荷)は維持。耳は GU* を基準として並べる(実物の Graillon 3 の出力が手に入れば差し替える)。
