# 論文の骨格: 構音界面による実時間の男声 → 女声変換 — 女声だけの学習で男声の入力へ一般化する条件 (status: PROPOSED・rev0.14・2026-10-31)

## 要旨

固定の半音(+0 / +5 / +7 / +12)で使う実時間・因果の男声 → 女声変換で、今の生成器の経路は女声の入力なら本物の帯の内に入るのに(自己変換 −1.1・学習の外の女声 → 女声 −1.0)、本物の男声の入力では官能指数 v1 が +4.6〜7.6 に落ちる。本稿はこの落差を 2 つの共変量のずれに分ける。(A) 操作者の音響から作る界面が、操作者の形態・声の源・録音の経路に不変でない(界面のずれ)。(B) 目標の声の包絡は目標自身の f0 の倍音の位置でしか観測できず、目標の自然な高さより低い出力の高さ(k5 で約 150 Hz・k12 で約 220 Hz に対し学習の女声は 394 Hz 中心)では、観測されない帯を描く必要がある(観測されない帯)。主張は 2 つ。(1) ## 1. 問題

- 製品: CPU・因果(先読み 0)・E2E p95 < 30 ms・48 kHz。男声 → 目標の女声(ゼロショット・参照 20 s 以上)。高さは固定の半音で、目標の声域への自動のずらしは無い(10-25)。抑揚と時間は操作者のもの(10-23)。
- 合格の定義: 耳で「本物だけが合格」(10-29『いままで聴かせたものは全部不合格』)。解析の代わりの物差し = 官能指数 v1(WavLM-large の 0.5 s の窓の本物 / 合成の線形の検出器・D678: 本物の保留 95% 通過・耳に出した合成 90% 不合格・耳で合格した神経の写し合成 −0.1〜−1.7)。v1 ≤ 0 = 本物の帯の内。

## 2. 生成の模型と変換の定義

音声を次の要素の描画とみなす。

  x = R( Φ_{D_s}(g), M_s, S_s(f0), π, n )

| 記号 | 中身 | 持ち主(変換で) |
|---|---|---|
| g(t) | 身振り = 構音の目標(内容の単位)の並びと時間 | 操作者 |
| π(t) | 抑揚 = f0 の軌道・音量の流れ | 操作者(f0 は × 2^{k/12}) |
| D_s | 動き方 = 目標へ近づく速さ・行き過ぎ・弱まり・調音結合 | 目標 |
| M_s | 形態 = 声道の長さと形 | 目標 |
| S_s(f0) | 声の源 = 声門の開き方・H1−H2・息・傾き。**f0(声区)の関数** | 目標 |
| n | 録音の経路 = マイク・部屋・符号化・雑音 | 消す(きれいな録音へ) |

変換: y = R( Φ_{D_tgt}(g_op), M_tgt, S_tgt(f0_op · 2^{k/12}), π_op^{(k)}, n_0 )。分担は [artic_morph.md](artic_morph.md) §3 と同じ。

系の部品:
- 界面 h_t = E(x_op)_{≤t}(因果)。g を運び、M_op・S_op・n_op を運ばないことが要件。
- 抑揚 p_t = (log f0 + k·ln2/12・有声・音量)(因果)。
- 登録 T_tgt = 内容で索引した目標の記述(表・R の記憶 = M・D・S の推定)。
- 描画器 G(h, p, T) → 波形。

学習 = 女声のコーパスの自己再構成: G(E(x_s), p(x_s), T_s′) → x_s(T_s′ は同じ話者の別のファイルから)。

## 3. 主張

### 主張 A: 一般化の条件は界面の不変性

推論の組 (h_m, p_m^{(k)}, T_f) が、学習の組 (h, p, T) の分布の台(と十分な密度)の内にあるところでだけ、G は学習で覚えた本物らしさを出す。推論のずれは次の 3 つに分かれる。
- **A1 界面のずれ**: p(h | 男声・録音の経路) ≠ p(h | 学習の女声)。E が M_op・S_op・n_op に不変でないこと。rev0.7 で 2 つに分ける。
  - **A1a 録音・形態の経路**: 事後の形・C2・c0・R の操作者の参照。設計で断てる。E-A1t / E-A1t2 で外郎売の距離の約 3 割 / 2.4 割(VCTK の男声では 0 以下)。
  - **A1b 操作者の時刻・f0・有声とその推定**: 単位の時刻と並び・f0 の軌跡と細部・有声の区切り。設計で残す経路(§2 の g と π)だが、推定器(F1 = 因果の f0・有声の推定)は M_op・S_op・n_op に不変とは限らない。学習の f0・有声は非因果の教師(harvest)で、推論は F1(既知の不一致・女声でも有声 18% が割れる)。
- **A2' 出力の高さ**: 中立の界面のままでも、出力の f0 が学習の f0(中央値 394 Hz)より低いこと自体の罰。主張 B(表の声区・D693 で約 +0.12 / 半音)より広く、生成器が低い f0 を描けるかを含む。**D698**: 女声の入力を N65 で外郎売と同じ出力の高さへ下げると +1.60(約 273 Hz)/ +3.09(約 182 Hz)。表の声区の見積もり(約 1.0 / 1.8)を引いた残り約 0.6 / 1.3 は、生成器の低い f0 の描き方か入力の組の違い(E-B1c で分ける)。
- **A3 の測り(D698)**: 同じ出力の高さで男声に固有の分 = 外郎売 N65 − 下げた女声 = +2.0 [+0.8, +3.0] / +3.1 [+2.1, +3.9](群の差・目標の組の違いを含む)。F1 → 教師の差し替えはこのうち −0.35 / −0.20 だけ(F1 は男声の入力で女声より悪くない: 有声の割れ 5〜7% 対 10%)= 推定器でなく操作者の時刻・f0 の形・有声・単位の並びそのもの。
- **A2 組み合わせのずれ**: 出力の f0 と目標 T の組が学習に無い(主張 B)。
- **A3 抑揚のずれ**: 操作者の抑揚の分布と学習の演技の抑揚の違い。小さい見込み(D684: 抑揚の幅 1.6 倍で −0.23〜+0.10)。

- **A-i(識別可能性)**: 自己再構成では h と T が同じ話者から来る。h が話者の情報を運べば G はそれを読む(design_laws §0-2)。推論では操作者の情報を読む = 漏れ。よって界面の不変性は、一般化の条件であると同時に、T に目標らしさの権威を持たせる条件でもある。
- **A-ii(覆いの手は効かない)**: 男声の自己再構成の行 (h_m, p_m, T_m) → x_m を足すと、学習の分布に「男声の h ⇔ 男声の T」の相関が入り、h から描き方を読む近道が報われる。推論の組 (h_m, ·, T_f) は覆われない(腕 64・D691)。対の学習 (h_m, ·, T_f) → x_f′ は、G に h の不変でない分を打ち消させる音響の写像を学ばせる。ただし x_f′ は目標の g と π を持つので分担(§2)と衝突し、整列の誤差が入り、主張 B には触れない。
- **A-iii(覆いと不変性の費用)**: 覆いは推論の領域(全てのマイク・全ての男声)を学習に入れることを要し、上限が無い。不変性は E がそれらを同じ h へ写すことだけを要する。
- **A-iv(rev0.9・覆いは不変な界面の下でだけ移る)**: 演技(単位の時刻・並び・抑揚)と出力の高さは設計で残す経路なので、不変性では消せない。G は女声の自己再構成から p(x | 演技, 高さ, T) を学ぶので、演技と高さの組み合わせが学習に無いところ(男声の演技 × 150〜270 Hz・高い声の女声の演技 × 低い高さ)で本物らしさを落とす(D698・D699)。この組み合わせの覆いには男声(か声の低い話者)の自己再構成の行が要る。A-ii(腕 64)では界面が男声の M・S・n を運んだので、男声の行は『男声の界面 ⇔ 男声の表』の近道を教えた。界面が不変なら男声の行が教えるのは『男声の演技 × 低い高さ × 与えられた表 T を描く』だけで、声は T からしか読めない = 覆いが推論の組へ移る。予測 = 交互作用: 中立の界面では男声の行が男声の入力を良くし(E-C1)、全部の界面では良くしない(D691)。**D701(TTS の男声の行)では支持されない**: 中立の界面でも悪化し、低い高さほど悪い = 不変な界面は近道を減らすが、残った手がかり(f0 の高さ)に行の音声の性質がそのまま結びつく。A-iv の検証は本物の男声の行(E-C1r)に持ち越す。残る危険: 低い f0 そのものが男声の声の源 S を示す手がかりになる(学習の男声の行では低い f0 ⇔ 男声の S)→ k5 では G が男声の S を描く可能性(C の検査で測る)。**D703(本物の男声の行・rev0.12)**: 外郎売へは移らない(DiD +0.08 / +0.22)が、行と同じコーパスの学習の外の話者(VCTK の男声 17 人)へは移る(k12 −0.90・k5 −0.41・区間は 0 を含まない)。守りは通る(目標の余白 −0.002〜+0.004・操作者への近さ ≤ +0.012)= 男声の声の源の近道ではない。**改めた A-cov(rev0.12)**: 演技 × 出力の高さの覆いは不変な界面の下で話者をまたいで移るが、行と入力の領域(言語・録音の経路・話し方)の内でだけ移る。外郎売は日本語・mp3 78 kbps・朗唱の 1 人で、行(英語・スタジオ・朗読)と 3 つとも違う。**D704(rev0.14)**: 符号化は領域を分けず(mp3 の VCTK で DiD −0.76)、2 人目の日本語の男声(namikawa・196 kbps)にも移らない = 言語(か日本語の話し方)が分ける。A-cov の行は操作者の言語の本物の男声でなければならない。領域の内でも利得は距離の約 1 割(VCTK k12 +5.6 → +4.9)= 覆いは ≤ 0 への主な手ではない。

### 主張 B: 観測されない帯は物理の骨格で外挿する

- 事実: 高さ F の声の包絡の推定は、伝達特性を倍音 kF の位置で標本化したもの。F より下と倍音の間は推定器の補間にすぎない。学習の女声(話者の中央値 394 Hz)の表は 420 Hz より下が平ら(190〜420 Hz の差 0.1 dB・声の低い女声の表は 4.1 dB・D688)。
- 主張: 目標 T を f0_out < f0_T で描くには [f0_out, f0_T] の伝達特性と声の源の形が要る。その目標のどの登録もそれを観測していない。自己再構成で学習した G は、出力の f0 が自分の f0 に近い行しか見ないので(220 Hz 未満の話者は 3%)、この帯を描くことを学ばない。固定の半音の運用(k5 で約 150 Hz・k12 で約 220 Hz)はちょうどこの帯にある → 罰は高さの開きに比例する(D688: +0.21 / 半音・ρ 0.81)。k5 の H1−H2 は同じ高さの本物の女声より約 5 dB 低い(基音の弱さ)。
- 設計の原理: 観測されない帯はデータでは決まらない。そこで声道(M_tgt: 観測帯に管の模型を当てはめると F1 より下の伝達特性が決まる・training/vtract.py)と声の源(S(f0): 話者の中の f0 の変化で H1−H2 などがどう動くかを学習のコーパス全体から集めた事前分布)で外挿し、表を (単位, f0_out) の関数として条件の側に与える。合成そのものは神経の描画器が行う(手作りの合成は +4.9〜6.4・D680)。物理は条件の骨格に限る(「物理は骨格とつまみ」10-01)。
- 傍証: 声の低い実女声の自己変換は 235 Hz で −0.52(帯の内 52%・D688)= 組み合わせが自然なら G は低い f0 を描ける。
- 表現の制約(10-30 実測・results/conv_p0/d692/build.json): 今の表は 0〜24 kHz の mel 128 帯の DCT 24 係数で、観測されない帯を独立に持てない。f_c(目標の f0 の 0.9 倍・中央値 422 Hz)より下だけを声の低い表の形に替えようとすると 0.4〜1.2 kHz(F1 の帯)が最大 26 dB 動き、0.4〜1.2 kHz を保つと下は 0.09 dB しか動かない。= 低い帯の情報は表の大きな傾きと結びついていて、『観測されない』と『平らな声道』を表の上で区別できない。
- **E-B1 の結果(D692・10-30・results/conv_p0/d692/verdict.yaml)= partial(向きは支持・大きさは小さい)**: 表を低い声区の形へ写す B1R は 4 条件とも良くなり(対の差 −0.45〜−0.72・良くなった組 79〜93%)、逆向きの B1X は 4 条件とも悪くなった(+0.26〜+0.93)。明瞭さは失わない。ただし (1) 利得は ≤ 0 までの距離の約 1 割(B1R の中央値 3.9〜6.9・≤ 0 は 0 / 162)、(2) 本人らしさの余白が約 3〜4 割減る(WavLM-SV −0.010 / −0.011・ECAPA −0.013 / −0.015・物差しの中心が目標の声域にある交絡を含む上限)、(3) 外郎売では両向きとも学習の分布の外へ出る代価(+0.2〜0.3)がある。事後の観察: 利得が大きかったのは出力の f0 がオラクルの声区(170〜250 Hz)の内の 2 条件。= 主張 B の『低い声区の情報を条件に与えれば良くなる』は向きとして成り立つが、母集団の平均の写しは目標の個別の形を母集団へ寄せる。M-B の外挿は『その目標が低い声区でどう変わるか』でなければならない(§5 M-B を改訂)。
- **E-B1b の結果(D693・results/conv_p0/d693/verdict.yaml)= B_small**: 声の低い実女声の入力(界面が出力の高さにある)を k0 で高い目標(開き 7.5 半音)と別の低い女声(開き 0)へ変換すると、同じ入力どうしの差は +0.87(95% 区間 [+0.51, +1.17]・開きが大きいほど大きい ρ +0.38)。B1R はその 83% を戻す。D688 の +0.21 / 半音は界面も高いまま下げた分を含んでいた(表の声区の分は約 +0.12 / 半音)。男声の入力での B1R の利得(D692)はこの罰の大きさとほぼ同じ = 男声の入力の表の声区の分は約 0.5〜0.9。**主張 B は副に縮める**: 低い出力の高さでの罰は在るが小さく、条件の側でほぼ消せる(本人らしさの代価つき)。M-B は保留し、主張 A を先に。
- 先行の観察: 高い声で包絡の推定が [0, F0] を過大に見積もる(Villavicencio ら 2016・§8.3)。声の源の形は f0 < 175 Hz で f0 と結びつく(H1*−H2*・Iseli ら 2007)= S(f0) を出力の高さで変える根拠。

### 主張 C: 本人らしさは目標の動き方(既存の結論・本稿では律速でない)

内容に揃った速い包絡の動きが本人らしさを運ぶ(D571〜D576)。P58 + R は固定の半音で構音の天井に達した(D586)。男声 → 女声の本物らしさの律速ではないので、本稿の方法では変えない。**rev0.7 の注**: R は男声らしさの運び手ではないが(D696)、入力を問わず本物らしさを約 0.6〜0.9 下げる(女声の入力でも devff2 −1.02 → −1.52 で R なしが良い)。R の本人らしさの利得とこの代価の引き換えは未測定(d394 で測る・§9)。距離の大部分(+3〜7)の前では副。

### 主張 D: 物差し

本物らしさ = 官能指数 v1(gen fold)を本物の男声の入力で。TTS の男声の入力はそれ自体が合成と判定されるので主の物差しにしない(D678)。

## 5. 方法(設計の候補)

### M-A 不変な界面
- 経路ごとに §4 の表の分類で「残す(g・π)」と「断つ(M_op・S_op・n_op)」を決め、断つ経路(操作者の遅い揺らぎ・R の操作者の参照)は界面から外すか、不変にした界面から作り直す。
- 不変性は分布の層で作る(design_laws §1 の検査 I):
  - 録音の経路: 入力の側に実在する経路の変換(マイクの応答・部屋・符号化・帯域・雑音)を掛け、E の出力が変わらないことを損失にする(不変性の正則化)。教師は実音声のまま。
  - 形態・声の源: 実話者の間の不変性 = 界面の窓から性別・話者・コーパスを当てる判別器に対する敵対(対を要しない)。本物の男声のデータ(VCTK・日本語の男声)は入力の側の判別器にだけ使い、教師には使わない。
  - 音量: 低い帯域(0.1〜4 kHz)の水準で定義し直す(RESEARCH の c0n の提案・低域通過に 0.0 dB で不変・D431)。
- L(下書き): 不変性の項の最適 = 判別器が偶然の水準。内容の項(C1 の目標・明瞭さ)との引き換えがある。
- I(下書き): 内容と話者が同じ経路に載るので、不変性が強すぎると内容も落ちる → 監視 = 学習の外の CER。
- C(下書き): (1) E が内容ごと情報を捨てて不変になる → 内容の項で塞ぐ。(2) 判別器の盲点に話者の情報を隠す → 学習に使わない別の判別器(D689 の判別器)で測る。(3) G が T を無視して平均の声を出す → 表の差し替えの試験。
- 費用: 界面が変わる = G の重みの流用は不可・学び直し・出荷ゲートの取り直し。

### M-B 音域の外挿(f0 の関数の表)
- T_tgt(u, f0_out) = 観測帯(≥ f0_T)の推定 + 観測されない帯(< f0_T)の外挿。外挿は、管の模型を観測帯に当てはめた低域の伝達特性と、声の源の事前分布 S(f0_out) から作る。
- D692 からの要件(rev0.3): (a) 外挿は出力の高さの関数(一定の写しでなく f0_out で決まる声区の形)。(b) 母集団の平均の差を足すと本人らしさが 3〜4 割減る → 外挿は話者の中の声区の変化(同じ話者が高さを変えたとき包絡・声の源がどう動くか)の事前分布から作り、目標の観測帯の個別の形は保つ。話者の中の声区の変化のデータ = 同じ話者の高さの違う区間(学習の全量の女声・声優の別の役の声域 = 独立の中心の中央値 3.9 半音・identity-center-register-confound)。(c) 今の生成器は学習の分布の外の表で代価を払う(外郎売で +0.2〜0.3)→ 条件の側だけで与えるより、学習の中で同じ規則の表を見せる(E-B2)方が筋。
- 表現(§3 B の制約から): 観測されない帯は 24 係数の表と別の経路で持つ(低い帯の水準・声の源の形 = H1−H2 などの明示の条件を出力の高さの関数として)。
- 学習と推論の一致: 学習でも同じ規則で表を作る。自己再構成の中に「表の f0 と出力の f0 が違う」行を作る(同じ話者の高さの違う区間どうし・声の低い話者を含む全量のデータ)。
- L / I / C は腕の prereg で詰める。入口の検査は §6 の E-B1。

### M-C 目標の動き方
既存の表 + R(変更なし)。

### M-S 声の源の中立化(rev0.9・D700 から)
- 学習と推論の両方で、f0 を因果に平滑(対数の EMA τ 15 ms・飛びの保持)し、有声を単位の関数(単位ごとの有声の率)にする。f0 の細部と有声の区切り(声の源 S のうち操作者のもの)を界面から外し、G が目標の声の源を描く = §2 の分担どおり。
- D700(中立の界面の診断の生成器)で入力を問わず −0.4〜−0.8。学習の教師の f0 と推論の F1 の不一致も同じ式で両側から消える。製品の界面(柔らかい事後・本物の C2・c0)で同じ利得と明瞭さの非劣性を示すのが E-S1。
- 先読み 0(因果の EMA・保持・後ろ向きの平均)。抑揚(遅い軌跡)は操作者のまま。
- **E-S1 の結果(D702・10-31・results/diag_ppgvoc70/verdict.yaml)= partial**: 製品の界面(P58 の構成・兄弟の対照 C69)でも 5 条件とも向きは保ち、明瞭さは線の内(外郎売 CER +0.027 / −0.015)。ただし大きさは中立の界面の約半分以下: 外郎売 −0.35 / −0.38・女声 −0.21・VCTK の男声 −0.06 / −0.17(D700 は −0.84 / −0.51・−0.39・−0.55 / −0.66)。外郎売の DiD −0.14 / −0.17 は区間が 0 を含む = 入力を問わない型のまま。柔らかい事後・C2・c0 が f0 の細部・有声の区切りの情報の一部を既に運ぶ(条件の冗長)と読める。≤ 0 までの距離(外郎売 +4.4 / +7.2)の 1 割未満 = **M-S は製品の構成要素として残すが主因ではない**。Rust への実装は v1 ≤ 0 に近い候補と一緒に行う。

### M-V 覆い(rev0.9・A-iv から)
- 不変な界面の下で、男声(と声の低い女声)の自己再構成の行を足す。教師は実音声のまま(男声の行の目標は男声本人の音声・表も本人)。G は演技 × 低い高さを描くことを学び、声は表から読む。
- 男声の行の音声は本物の男声が望ましい(TTS の男声の行は低い f0 で TTS の質感を教えた疑い・D691)。E-C1 は既存の TTS の男声の行(腕 64 と同じデータ)で交互作用を先に測り、読めなければ本物の男声の行(VCTK の学習の側の話者・評価の話者は除く)で取り直す。
- **D701・D703(rev0.12)**: TTS の行は悪化させ、本物の行は同じ領域(VCTK)の別の話者だけを良くする(k12 −0.90)。M-V は操作者の領域(日本語・普通の話し方・製品のマイク)の本物の男声の行を要する = データの取得はオーナーの判断。利得は距離の約 1 割なので、M-V は他の手(A2' の低い高さの描き方)と組み合わせる部品で、単独の候補ではない。

- 基準の行: 入力そのもの・自己変換・GU*・P58・写し合成(・kNN-VC は非因果の参照)。
- 耳: 主の物差しで帯の内に入った候補だけ(10-30 の約束)。
- **不足**: 日本語の本物の男声が 1 人しかいない。論文の主張の確認には、非圧縮・普通の話し方・複数話者の日本語の男声の評価の組が要る(取得の手段はオーナーの判断)。**rev0.12**: D703 で覆いは領域(言語・録音の経路・話し方)の内でだけ移ると分かったので、外郎売(mp3・朗唱・1 人)だけで A-cov を読むと、領域の違いを方法の失敗と取り違える。E-C1d で符号化の分を測る。**rev0.13**: これまでの DiD の対照 devff2(日本語・別の録音)は言語と録音の違いを含む。VCTK の男声の対照は同じ文・同じ目標の FE の対(D705)に替える。

## 8. 関連研究(2026-10-30 の調査・一次資料で確認できたものだけ・論文に引く前に再確認)

主張 A・B とほぼ同じことを主張・実証した文献は見つからなかった。部品の先行はある。

### 8.1 構音の界面(主張 A の枠)
- Cho ら 2024 "Coding Speech through Vocal Tract Kinematics"(SPARC・arXiv:2406.12998): 単一話者の EMA の空間の構音 12 ch + f0 + 大きさ + FiLM の話者埋め込み、描画器は多話者で学習。VC の目標は平均 f0 80〜230 Hz の 6 人で、性別をまたぐ評価なし。
- Liu ら 2025 "RT-VC"(arXiv:2506.10289・ACL 2025 demo): SPARC を因果化し DDSP で描画。CPU で 61.4 ms(先読み 32 ms)。多話者学習。性別をまたぐ評価なし。最も近い先行。
- Cho ら ICASSP 2024 "Self-Supervised Models of Speech Infer Universal Articulatory Kinematics"(arXiv:2310.10788): SSL → 構音の逆推定がアフィン変換だけで性別・言語をまたいで移る = 界面の不変性は達成できる見込みの傍証。
- Illa & Ghosh Interspeech 2019(doi:10.21437/Interspeech.2019-2664): 目標話者だけで学習した構音 → 音響を別人の構音で駆動。主張 A の構造の先行(性別をまたいだかは未確認)。
- Bollepalli ら Interspeech 2012(古典): 構音の特徴の軌道に話者の情報が残る = 界面は自動的には不変にならない(注意)。
- Aryal & Gutierrez-Osuna Interspeech 2015(古典): L1 の EMA を Procrustes で L2 の空間へ揃えて L2 の合成器を駆動。

### 8.2 不変な内容の表現と単一の領域の学習(主張 A の手段と前提)
- van Niekerk ら ICASSP 2022 "soft speech units"(arXiv:2111.02392): 音響モデルとボコーダを LJSpeech(女声 1 人)だけで学習し任意の入力へ。入力の性別ごとの分析なし = 「女声だけの自己再構成で任意の入力へ」の最も直接の先行だが、性別をまたぐ一般化としては未検証。
- Qian ら ICML 2019 "AUTOVC": 情報の絞りが適切なら自己再構成だけで変換になる。
- ContentVec(Qian ら ICML 2022)・NANSY(Choi ら NeurIPS 2021)・Spin(Chang ら Interspeech 2023)・FreeVC(Li ら arXiv:2210.15418): フォルマント・f0・周波数特性の摂動で話者を分布の層で遮断 = M-A の手段の先行。
- Hsu ら 2020 "Towards Robust Neural Vocoding for Speech Generation"(arXiv:1912.02461): 女声で学習したボコーダは男声の入力で男声で学習したものに勝てない = mel を条件にすると共変量シフトが起きる(主張 A の前提・本稿の対照)。

### 8.3 学習の外の f0・f0 より下の包絡・声の源(主張 B)
- Villavicencio ら Interspeech 2016(古典): 高い声で True Envelope が [0, F0] を過大に推定 → 女声を 1 オクターブ下げて支点を人工的に作る(DSP)。**主張 B の観察そのものの先行**。物理の外挿は無い。
- Assmann & Nearey JASA 2008(古典): f0 が高いと包絡の標本化が疎で母音の識別が最も悪い。
- Perrotin ら Interspeech 2021: ニューラルボコーダの極端な f0 への外挿 = LPCNet・PWG は学習の f0 の中央値へ戻る。
- Yoneyama ら ICASSP 2023 "Source-Filter HiFi-GAN"(arXiv:2210.15533): 女声の歌手 1 人で学習し f0 を 0.5 / 2 倍。源-フィルタ型が保つ。Wavehax(arXiv:2411.06807)・QHARMA-GAN(arXiv:2507.01611)も外挿の妨げを報告。
- Iseli ら JASA 2007(古典・Hanson 1997 の系譜): f0 < 175 Hz で H1*−H2* が f0 と正に相関・高い声では F1 に依存 = **声の源の形を出力の高さで変える根拠**(M-B の S(f0))。
- 骨格の先行: NSF(Wang ら TASLP 2020)・DDSP(Engel ら ICLR 2020)・GlotNet(Juvela ら TASLP 2019)・GOLF(Yu & Fazekas 2023・LF-Rd の声門 + 微分可能な LPC = 「声門 + 全極の管」の最も近い先行)・Südholt ら DAFx 2023(微分可能な管の当てはめ・成人男性以外の声道長は今後の課題)。

### 8.4 実時間の VC
- StreamVC(Yang ら ICASSP 2024): Pixel 7 で 70.8 ms。
- LLVC(Sadov ら 2023): CPU で 20 ms 未満だが、変換音声の人工の並列データと蒸留 = 本プロジェクトが禁じる型。
- Nercessian ら DAFx 2023: 源は DSP・フィルタはニューラル・60 ms 未満。
- 男声 → 女声の品質を DSP のピッチ / フォルマントシフタと比べた実時間 VC の報告は見つからなかった(Beatrice・RVC の査読論文も見つからない)。

### 8.5 本物 / 合成の検出器を物差しに
- Kinnunen ら Odyssey 2018: 対策(CM)の EER を変換の傷の物差しに使い、MOS とは「強い関連はないが相補的」= **注意**。本稿の官能指数 v1 は自前の耳のラベルとの一致(D678・D680)を論文の中で示す必要がある。
- Pascu ら Interspeech 2024(arXiv:2309.05384): 凍結 SSL(WavLM を含む)+ ロジスティック回帰で汎化する検出器 = 線形の検出器が成立する根拠。
- Wang & Yamagishi ICASSP 2023: ボコーダの写し合成だけで偽物の学習データとして足りる = 検出器は描画器の痕跡を見る。
- TTSDS2(Minixhofer ら 2025): 本物の分布との距離で MOS と相関。

### 8.6 声道長の正規化(VTLN)
- Sündermann ら ASRU 2003・Erro ら TASLP 2010・Jaitly & Hinton 2013(VTLP)(古典): 区分線形・重みつきの周波数の伸縮と学習時の摂動。一律 / 区分線形の写像 = 錨 GU* と同じ族(本稿の比較対照)。

### 8.7 新規と言える範囲の見立て
1. 単一の性別の自己再構成で学習し、構音の界面の不変性で男声の入力の共変量シフトを除くことを、性別ごとの評価で示した例は見当たらない(Hsu ら 2020 の逆の結果が対照になる)。
2. 「目標の f0 の倍音でしか包絡は観測されない」を、高さを下げる変換の外挿の問題として定式化し、管と声門の物理を事前分布に置く組み合わせは新しい見込み(観察は Villavicencio 2016 に先行・部品は GOLF・Südholt・NSF)。
3. 先読み 0・30 ms 未満の CPU で構音の界面を使う VC は見当たらない(RT-VC は 61 ms・先読み 32 ms)。
4. SSL 上の線形の検出器を主の物差しにする点は先行と部分的に重なる → 耳との一致を自前のデータで示す。

## 9. 限界・未決・オーナーの判断

- 関門の主な軸を「官能指数 v1 ≤ 0(本物の男声の入力)」にする案(10-30・返事待ち)。
- 日本語の本物の男声の評価の組(§7)。rev0.12 で優先度が上がった: 覆いの行(M-V)にも同じ領域の本物の男声が要る(D703)。rev0.14: 言語が領域を分けると分かった(D704)= E-C1j の行に日本語の本物の男声の複数話者・数時間が要る(VCTK の行は 30 人・12 時間)。取得の手段(録音・公開コーパスの利用条件)はオーナーの判断。
- M-A・M-B はどちらも界面か条件の表が変わる = G の学び直しと出荷ゲートの取り直し(AGENTS の「front-end だけ差し替えは不可」)。
- 本稿の主張 A・B は事後の導出(D681〜D691 から)。E-A1・E-B1 の前に結論として引用しない。E-B1(D692)で主張 B は向きだけ支持(大きさは小さい)。 主張 A の運び手は E-A1(D694)で読めず、E-A1t / E-A1t2(D695〜D697)で A1a は外郎売の距離の ≤ 3 割と分かった。残り約 7 割の帰属(A1b・A2'・A3)は E-A1b0 で決める。
- R の本人らしさの利得と本物らしさの代価(D696: 入力を問わず約 0.6〜0.9)の引き換え(d394 で測る・距離の大部分が片づくまで保留)。
- 本人らしさの物差し(声域をそろえた中心)は目標の声域(±3 半音)の録音で、低い出力の高さの目標の『本人の声』は観測されない = 物差しそのものが主張 B の問題を持つ。低い声区の出力の本人らしさの損失は今の物差しでは上限しか言えない。
