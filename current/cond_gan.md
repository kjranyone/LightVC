# 条件の空間の分布を合わせる変換器(cond_gan) — status: PROPOSED(rev0・2026-10-18)

## 1. 目的と根拠
- 目標関数 v1 / v1⊥(本物の女声と区別できないこと・`results/conv_p0/OVERNIGHT_2026-10-18.md`)で、男声 → 女声は学習なしのどの手でも 0.98〜0.99(AUC 1.00)。
- D270: 出力部に入る前の条件(31 行)の段で、男声 → 女声の条件は本物の女声の条件と AUC 1.00 で分かれる(包絡の統計 0.99・周期性 0.999・c0 0.94・有声の割合 0.91・f0 0.74)。女声 → 女声は 0.81。
- D271/D272: 行ごとの平均・標準偏差・差分の大きさを登録の定数で女声へ写しても、音声の男声らしさは減らない = 男声らしさは条件の時間の構造・行どうしの関係にある。回帰(平均への当てはめ)の R も 0.976 止まり。
- 結論: 男声の条件を女声らしい条件の分布へ写すには、分布を合わせる目的(敵対)で学習した変換器が要る。

## 2. 構成
- **前段は固定**: Rust `--causal-ct`(因果な CheapTrick の c0・包絡・F1 の f0・F4 の周期性)。条件の時刻規約は出力部と同じ(フレーム t の窓は (t+1)H で終わる)。
- **土台**: 今の最良の解析の変換(表 γ0.7 + 色 + `--floor-apply`・高さと周期性を目標へ)の条件 u_t。
- **G(学習する)**: 因果な 1 次元畳み込み(左寄せ・先読み 0)。入力 = 土台の条件 u(31 行)+ 操作者の条件(c0・包絡・有声)+ 目標の登録の要約(表の数で重みづけた平均・per_p75・mu)。出力 = c0・包絡 c1..c24・周期性の補正 Δ(f0・有声は変えない = 操作者の抑揚と時間を保つ)。最終の条件 = 下限つきの log-mel の領域で u に Δ を足す(`--floor-apply` と同じ式)。
- **D(学習だけ)**: 条件の列(1 秒の窓)の判別器・非因果で可。本物 = 実女声(female-dataset の全量・評価外)の自分自身への写し合成の条件。偽 = G の出力。目標の登録の要約で条件づけた射影の判別器(本人らしさも分布で押す)。
- 推論の経路 = 前段 + 土台 + G + 出力部(rvoc3hi)。G の規模は計算の予算(1 ブロック 5 ms・今 p99 3.3〜3.6 ms)に収める = 1 フレームあたり 0.2 M MAC 以下(目安 128 ch × 6 層)。

## 3. 設計三層則(起動前の検査の下書き・prereg に転記)
- **L(損失の最適解)**: LSGAN の最適 = G の出力の条件の列の分布が本物の女声の条件の列の分布と一致(目標の登録で条件づけ)。内容の保存の項 = 条件から C1 の単位の事後を当てる凍結の探針(実女声の条件で学習)の出力が、G の入力(操作者)の C1 の事後と一致(KL)。Δ の大きさの罰則(小さい補正を優先)。
- **I(識別可能性)**: 男声の入力の条件の時間の構造を変えずに女声の分布に入る道は無い = D が見る情報(包絡の動き・周期性の動き)を G は変えられる(f0・有声・時間は固定なので、リズムは操作者のまま = 判別器はリズムでは G を罰せない側に作る: D の入力から有声の列を外し、有声フレームの中だけを見る束を主にする)。
- **C(チート)**: (1) 内容を捨てて女声らしい平均の列を出す → 内容の探針の KL で塞ぐ・CER で監視。(2) 判別器の穴を突く小刻みな揺れ → 音声の v1⊥(別の空間)で検証・D270 の条件の統計の AUC で検証。(3) 目標を無視した一般の女声 → 射影の判別器 + LDA / ECAPA で監視。
- 人工データを目標の側に置かない(本物 = 実女声の条件だけ)。VC の教師の蒸留はしない。

## 4. データ
- 入力(男声): data/male_tts_v4l(Irodori v4 Large・48 人 × 40 文)+ VCTK の男声(英語の実音声・評価外)。評価の dev / dev2 / dev3 / eval / eval2 の操作者と目標は学習から除く。
- 本物(女声): female-dataset の全量(評価外)の条件を新しい前段で前計算。
- 目標の登録: 本物の女声の話者を擬似の目標にする(登録 = その話者の別のクリップ 20 秒)。

## 5. 評価と打ち切り
- 主: dev の男声 → 女声 30 組の音声の v1⊥ の決定値の中央値(土台 3.2〜3.4)。副: 条件の空間の AUC(D270 の特徴)・LDA / ECAPA・CER。
- 途中の打ち切り: 2k step(約 30 分)で条件の空間の AUC が土台より 0.05 以上下がらなければ停止・5k step で音声の v1⊥ の決定値が 0.5 以上下がらなければ停止。
- 出荷: G は因果・先読み 0(未来不変性を実音声で)・計算の台帳。
