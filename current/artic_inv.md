# 構音の逆推定 — 声道の物理形状の界面 (status: PROPOSED・rev1・2026-10-02・段 2 の推定器 artic_inv1 = 骨格とつまみ用)

オーナー指示: 「構音 = 声道の物理形状」(10-01)・「構音モデリングをしっかり続けてね」(10-02)。全体設計は [a2vc.md](a2vc.md)。

## 1. なぜ構音か(実測)
話者を運ぶのは包絡の音素速度の軌道 = 声道をどう動かすか(a2vc 設計レビュー 4 巡目: 目標の DCT24 軌道へ差し替えで同性 45 人中 top-1 ECAPA 89%・WavLM 62%、静的な写像は 0%、励起の細部は 9/20%)。萌えの署名(F1・F2 幅・動き・母音空間)も同じ場所にある。ただし DCT24 の包絡はピッチを運ぶ(女声の f0 で +4 半音に自然変動の 0.75〜0.83 倍動く)・声道形状として読めない。→ 声道の物理形状を、ピッチを持たずに推定する界面を作る。

## 2. 前向きモデル(`training/vtract.py`・決定的・微分可能)
声門 → 口唇の N 区間の音響管。損失つき伝送行列の積・口唇の放射インピーダンス(円形ピストン)・声門は理想体積速度源・放射 +6dB/oct。声道長 L は連続値。声門流の傾斜は別関数。
単体検査(済): 均一管 17.5cm の F1–F3 = 500/1500/2500Hz(理論と一致)・L/1.2 でフォルマント ×1.200・/a/ 型 F1 754・F2 1128Hz、/i/ 型 216・1771Hz・帯域幅 65/102/157Hz(実測の桁)・断面積への勾配 有限。
限界: 鼻腔の分岐なし(鼻音)・平面波(約 5〜7kHz まで)・声門−声道の相互作用なし。

## 3. 表現(構音座標)
- 断面積: log A(x, t) = log Ā(x) + Σ_{k=1..K} q_k(t) φ_k(x)。φ_k は管の長さ方向の滑らかな成分(K = 6・余弦)。Ā は中立の形。
- 声道長 L(話者ごとに静的・発話の窓で推定)。
- 声門: 傾斜(fc・傾き)と利得(フレームごと)。
- f0 は界面に入れない(励起側)。

## 4. 推定(段 1 は最適化・段 2 で因果のネットへ)
- 観測: 有声フレームは倍音 k·f0 の位置の振幅(ピッチ適応の窓)、無声フレームは平滑化したスペクトル。照合は観測のある周波数だけ = 高い f0 で倍音が疎でも、物理の拘束と時間の連続性が間を埋める。
- 段 1: フレームごとの合成による分析(勾配法・時間方向の滑らかさ・中立の形への引き)。学習データ不要。この表現が関門を通るかを先に測る。
- 段 2: 関門を通ったら、因果の推定器(ネット)を段 1 の解または合成による分析の損失で学習。

## 5. 関門(段 1・数値)
| ID | 問い | 合格 |
|---|---|---|
| G0 | 当てはまり: 男女の実音声で倍音の位置の誤差(dB RMS) | 男女とも ≤ 3dB(DCT24 の再構成誤差と比べて記録) |
| G1 | ピッチ盲: 同じ発話の f0 だけを変えた再合成(±4 半音)で q(t) と L の動き / 自然変動 | < 0.2(DCT24 は 0.75〜0.83・DCT12 は 0.11〜0.15) |
| G2 | 話者を運ぶ: 男声の包絡を、目標の q(t)(DTW 整列)から作った包絡へ差し替え → 同性候補中の目標 top-1(ECAPA/WavLM) | DCT24 の 89/62 の 7 割以上 |
| G3 | 時間の滑らかさ: 推定の 4–50Hz 成分のうち、推定の揺れ(同じ発話の雑音違いでの差)の割合 | 自然変動の 0.125 倍以下(S0-4 の耳) |

## 6. 段 1 の結果(2026-10-02・`results/artic_inv/g0g1.json`・`training/artic_fit.py`)
- 当てはめ器の検証(合成信号・既知の形状): 利得をフレームごとの閉じた式(変数射影)にし、コードブック(10 万形状 × 声道長 5 段)+ 動的計画法の初期値で、包絡は 0.05〜0.24dB で再現。**ただし形状は一意に決まらない**(包絡の誤差 0.05dB でも成分の誤差 0.45〜1.26・声道長 16cm を 19.2cm と推定する例)= Mermelstein の非一意性が実測で出た。
- 実音声(女 4・男 4): G0 = 女 3.49dB・男 4.17dB(関門 ≤ 3dB に届かず)。**G1 = 成分の動き / 自然変動 1.03(f0 ±4 半音)= 不合格**。同条件の DCT24 は 0.36。f0 が変わると倍音の標本位置が変わり、フレームごとの最適化が等価な別の形状へ跳ぶ。
- 読み: フレームごとの最適化(段 1)ではピッチ盲な構音界面は作れない。声道の物理形状は音声だけからは一意でないので、界面は「真の形状」ではなく、一貫性・ピッチ盲・時間の安定・話者を運ぶことで評価し、一意性は分布の側で決める → 段 2(推定器をネットにし、同じ発話の f0 違いで座標を一致させる不変性をコーパス全体で学習)。

## 6b. G2(話者を運ぶか・`results/artic_inv/g2.json`・`training/artic_g2.py`・学習なし)
男 → 女 45 組(VCTK 同文・男声は RRPS で音域移動)。両側とも有声のフレームだけ包絡の差を掛けて同性 45 人中の目標の top-1(ECAPA / WavLM):
PHYS(管 K=6 + 声門 2・最適化の当てはめ 4.1dB)**24% / 16%** ・ 同じフレームの DCT24 = 73% / 42% ・ 全フレーム DCT24 89% / 62% ・ DCT12 51% / 27% ・ 差し替えなし 0% / 7%。
→ **G2 不合格**(DCT24 の 1/3)。当てはまりの誤差の分だけ話者を見分ける細部を表せていない。段 2 には進まず、物理の表現力(成分の数・帯域幅)を上げて測り直す(K=16 + 帯域幅可変で当てはまり 女 1.90・男 3.43dB)。

## 6c. G2 の帯域の切り分けと表現の決定(`results/artic_inv/g2_k16ls.json`・`g2_band.json`・20 組)
| 差し替え(同じフレーム) | ECAPA | WavLM |
|---|---|---|
| DCT24 の 5kHz 未満だけ | 45% | 40% |
| DCT24 の 5kHz 以上だけ | 5% | 15% |
| DCT24 の全帯域 | 65% | 55% |
| 物理 K=16 + 帯域幅(倍音 ≤ 5kHz・当てはまり 約 3.2dB) | 40% | 10% |
| 物理 K=6 | 25% | 20% |

- 帯域を揃えると、物理 K=16 は ECAPA で DCT24 の低域に近い(40 対 45)。WavLM の劣後(10 対 40)は、フレームごとの当てはめが等価な別解へ跳ぶ揺れ(段 1 の G1 = 1.03)による傷の可能性が高い(K を増やすと WavLM が下がった)。
- 5kHz 以上は単独では話者をほぼ運ばないが、低域と合わさると +20 ポイント。管の物理が成り立たない帯域なので、**構音界面 = (a) 5kHz までの物理の管(K=16・声道長・帯域幅・声門)+ (b) 高域の包絡の成分(mel から直接・推定不要)** の 2 本立てにする。
- 次: 段 2(`results/artic_inv1/prereg.yaml`)で揺れを抑えた推定器を学習し、その出力で G1・G2 を測る。

## 6d. 段 2 の結果と役割の決定(`results/artic_inv1/`・`results/artic_inv/g2_inv1_10k.json`)
- 推定器(因果・K=16 + 帯域幅・物理損失 + WORLD の f0 違いの対で不変性・1 万区間・20k step・約 1 時間): G0 3.79dB(合格)・G1 0.33(不合格・頭打ち・f0 の差に比例しない床 = 推定の床)・G3 の揺れは DCT24 と同程度(余計な揺れなし = 段 1 の別解の跳びは消えた)。
- G2(10k の重み・20 組): ECAPA 20%・WavLM 15%(差し替えなしと同じ)。物理の表現は、最適化(K=6 24/16・K=16 40/10)でも学習した推定器でも、同じフレームの DCT24 低域(45/40)・全帯域(65/55)に届かない。
- **決定**: 声道の物理の管は話者を運ばない(当てはまりの誤差 3〜4dB の部分と 5kHz 以上に話者の手がかりがある)。構音の物理モデルは **骨格とつまみ**(声道長・構音の範囲 = 母音空間・萌えの座標)に専念させ、話者らしさは **包絡の時間軌道の細部(物理の残り + 高域)** として変換器が運ぶ。オーナー判断(10-01「物理は骨格とつまみに限定」)と一致。

## 6e. 話者は静的な単位の形か・単位の中の動きか(`results/artic_inv/g2_unit.json`・`training/artic_g2_unit.py`・学習なし・45 組)
単位 = ContentVec の k-means(VCTK 男女の発話 41〜51 で学習)。R0(男声・音域移動)の DCT24 包絡を、目標の包絡の系列へ差し替え(全フレーム・25ms 平滑)て女声 45 人中の目標の順位。
| 差し替える系列 | ECAPA top-1 / top-5 | WavLM top-1 / top-5 |
|---|---|---|
| 目標の実軌道(DTW 整列 = H1_24) | 91% / 100% | 62% / 82% |
| 同じ軌道を 25ms 平滑 | 93 / 100 | 62 / 82 |
| 目標の単位平均・同じ文(k200 / k50) | 64 / 56 | 27 / 20 |
| 目標の単位平均・別の文の参照 10s(k200 / k50) | 64 / 56 | 22 / 18 |
| 同・参照 30s(k200 / k50) | 56 / 51 | 29 / 20 |
| 同じ表(参照 10s / 30s)を **R0 自身の単位の並び**で(変換器が実際に見る側・k200) | 69 / 64 | 13 / 20 |
| 同(k50) | 58 / 58 | 20 / 16 |
| R0 の単位ごとに平均のずれだけ写す(元の単位内の動きを残す・k200 / k50) | 36 / 22 | 13 / 11 |
| 差し替えなし | 0 / 9 | 7 / 24 |

- 単位ごとの静的な形は話者の一部しか運ばない(実軌道に対し ECAPA 6〜7 割・WavLM 3〜4 割)。残り = 単位の中の動き・文脈依存(k200 > k50 = 細かい文脈ほど上がる)。参照 10s・30s・同じ文で ECAPA の top-1 は差なし(ただし top-1 は飽和に近い)。**WavLM の順位では網羅が効く**(同じ文の表 対 参照 10s: 中央順位 4 対 6・Wilcoxon p = 0.009・参照 30s 対 10s: p = 0.051・変換器レビュー 1 巡目の再採点)= rev 前の「網羅は律速でない」は ECAPA の飽和に依った誤り。
- 45 組では 1 組 = 2.2 ポイント・p = 0.6 の標準誤差 7 ポイント。単位平均の条件どうし(目標側 / 元側の単位・参照 10s / 30s)の差はこの範囲 = ECAPA では元話者の内容から単位を取る代価は見えない。ただし WavLM は 22 → 13%(不一致 4 対 0・p = 0.125)で未決(≥ 200 組で測り直す・converter.md C0-1)。
- 単位の一致率の較正(`results/artic_inv/unit_agree.json`・同じ文の DTW 対応・元の音声): 男女 0.448 / 0.360(k50 / k200)・女女 0.491 / 0.410・男男 0.483 / 0.396。**性別による低下は 0.04〜0.05 だけ**で、同性でも 0.4〜0.5 止まり(単位のラベルと DTW の粗さ)。音域移動(RRPS)した男声では 0.408 / 0.314 に下がる(加工の傷)。
- 元の単位内の動きを残すと悪化(36/13 < 64〜69/13〜22)= 元話者の動きは目標の表と合わない(元の包絡の偏差を通すと元話者が残る: zsvc4 の「包絡を内容にすると目標 0.03・元 0.36」と同じ向き)。
- **変換器への含意**: (1) 元話者の包絡を内容として通すと元の動きが残るので、包絡の軌道は内容(話者に依らない表現)から作り直す。(2) 目標の軌道は内容の文脈に条件づけて生成する(単位の平均の並べ替え = 回帰の最適では実軌道の 6〜7 割止まり)。(3) 単位の中の動きを出すには、文脈を長く見る条件づけと分布の目的関数が要る(回帰の平均は s10 の「共有の平滑な型」に潰れる)。
