## 1. アナログモデリングの対応

| アンプのモデリング | 声 |
|---|---|
| ギタリストの演奏(DI の信号) | 操作者の構音の演奏: 調音器官の動き(何を・いつ・どう動かすか)と声源(高さ・有声・大きさ) |
| 回路(アンプ) | 目標話者の構音の構造(声道と声源の器官の形と性質) |
| reamp = 同じ DI を別の回路に通して録る | 同じ演奏を別の構造に通した音。人にも Irodori にも作れない |
| 1 対 1 | 演奏 → ある構造を通った音 |
| 回路の差し替え | 話者の変換 |

reamp の代わりに**自己の reamp** で 1 対 1 の対を作る。目標の音声 y から構造を外した演奏 a(y) を取り出し、同じ話者の別の発話 r から構造 s(r) を取り出して、y を再現する。

- 学習: y ≈ G(a(y), s(r))
- 変換: G(a(x), s(r_目標))(x = 操作者の音声)

## 2. 識別可能性(検査 I の中心)

- **I1 決定**: a(y) と s(r) で y が決まる。決まらない分は、損失の最適解が平均になる(ぼやけ)。
- **I2 分離**: a は構造を運ばない。運ぶと G は a から構造を写す近道を覚え、男声の入力では男声の構造が出る。
- **I3 構造の十分性**: 同じ話者の別の発話から取った s で、その話者の y が決まる。

I1 と I2 は引き合う。a に情報を多く残すほど I1 は満たしやすいが、I2 が崩れる。**「演奏」と「構造」の境界をどこに引くかが本設計の中心の問いで、それを低遅延の制約(§3)の下で決める。**

## 3. フロンティア: 低遅延で実現できるモデリング

- 遅延の台帳: 左寄せの窓の先読み 0(出荷ゲートの規則)+ 塊 + 処理 + 内容の予備 10 ms < 30 ms(p95)。a の取り出しも、s を通した G も因果。
- 構造のうち、今までの演奏から因果に決められる部分は差し替えられる。次の音を知る必要がある部分(先取りの調音結合)は、操作者の演奏に入っている先取り(操作者の口は次の音へ先に動く)を通してしか使えない。**どこまでを因果に差し替えられるかを測るのが本研究。**

既存の到達点(外部の文献。我々の記録ではない):
- **SPARC**(Cho ほか, IEEE JSTSP 2024, [arXiv 2406.12998](https://arxiv.org/abs/2406.12998)): 調音の運動(EMA 12 次元: 舌先・舌体・舌背・下顎・上下の唇)+ 声源(高さ・周期性・大きさ)+ 話者の埋め込みで音声を符号化・合成する。話者の埋め込みを差し替えて zero-shot で変換する。非因果・オフライン。多言語版は JVS(日本語)を学習に含む。ライセンスは未確認。
- **RT-VC**(ACL 2025 demo, [arXiv 2506.10289](https://arxiv.org/html/2506.10289v1)): SPARC の実時間版。因果の逆推定(MFCC → EMA・膨張の因果畳み込み 11 層 + MLP)・因果の声源の抽出・DDSP(倍音 + 雑音)の合成器を、話者の埋め込み(128 次元・FiLM)で条件づける。遅延 61.4 ms = 先読み 32 ms(中心化した 1024 点の窓 @16 kHz の半分)+ 塊 15 ms + 処理 14.4 ms(M3 CPU)。16 kHz・英語。男女間の結果は無い。重みは非公開。
- **本研究の到達目標**: p95 < 30 ms・48 kHz・日本語・男声 → 女声・ASMR / 官能の質・zero-shot。RT-VC の先読み 32 ms は中心化した窓によるもので、左寄せの窓なら 0 にできる。

### 3b. A1 で分かったこと(2026-11-01・外部の実装の測定)

- 演奏(調音の運動 EMA)は性別を運ばない(Irodori 36 声のフレームの探りで性別は偶然の水準)。声ごとには少し運ぶ(0.19・偶然 0.03)。性別は高さが運ぶ。
- 構造を 1 本の 64 次元のベクトル(発話全体の平均)で持つと、本人の演奏でも本人らしさは天井 0.79 → 0.46〜0.50 に落ちる。参照から取っても本人の発話から取っても同じ = 構造の表現力と描画が律速。
- 他人の演奏を使うとさらに 0.29〜0.33 に落ちる = 演奏の側に話者の癖が乗る。どこまでを「構造」として差し替えるか(§2 の境界)は、この癖をどちらに置くかの問い。
- 男声に固有の損失は見えない。

### 3c. A2 で分かったこと(2026-11-01・diag・自前の因果の描画器 G)

演奏 = SPARC の特徴、描画 = BigVGAN の代役(どちらも非因果)の上で、構造の持ち方だけを変えた比較。証拠 = `results/diag_snv_a2_g/verdict.yaml`。
- 学習の領域を Irodori の女声に合わせても、1 本の静的なベクトル(g)は自己の reamp で 0.54(SPARC 0.50)。A1 の構造の側の損失は領域ではなく、構造の持ち方による。
- 参照を調音の状態で読む表現(x)は 0.75(天井 0.81)。x − g = +0.21(声で束ねた 95% [0.10, 0.35]・食い違う 15 本は全て x の勝ち)= 事前登録の H_indexed。
- 注意は出力の時刻ごとに、参照の中で調音の状態が同じ所を読む(読んだ参照の EMA と今の EMA の相関 0.86・時刻を混ぜると 0.00)。読みは柔らかく(1 時刻あたり実効 150〜300 フレーム)、明瞭さは g と同じ = 内容の写しではない。
- 別人の演奏で読ませても目標に寄る(O: 0.68・SPARC 0.29)。本物の男声 → 目標は 0.56(SPARC 0.26)。演奏の側の話者の癖による損失も、構造を状態ごとに読むと小さくなる。
- A2b(問いを内容によらない定数に固定した対照 xs・`results/diag_snv_a2_xs/verdict.yaml`): 本人の演奏(S)では xs 0.65 = 静的な要約と読み替えがほぼ半分ずつで、主の軸の判定は境界(中間)。別人の演奏(O)と本物の男声(M)では xs は g と同じ(O 0.36・M 0.33)で、x との差は O +0.32 [0.21, 0.44]・M +0.24 [0.16, 0.32]。**変換で目標の声を出すのは、参照を今の調音の状態で読み替えることだけ。** 静的な要約は本人の演奏の再現にしか効かない。
- 理論への読み(diag の上の仮説): 回路 = 単一の静的な状態ではなく、**調音の状態ごとの応答の表**(状態依存の回路)。A1 の演奏の側の話者の癖による損失も、この読み替えで構造の側が吸収する。A3 で自前の演奏の信号に替えても持ち越すかを確かめる。
- 自然さは L1 の回帰のぼやけで低い(UTMOS 1.4・SPARC 1.9・BigVGAN の写し 2.5)。A4 の分布の損失の対象。明瞭さ(CER 中央値 0.23)は SPARC(0.20)より悪い。

### 3d. A3 で分かったこと(2026-11-01・diag・自前の因果の演奏の信号 E)

演奏の調音の部分(SPARC の EMA)を、自己の reamp で G と同時に学ぶ自前の因果の符号器 E(左寄せの窓の包絡 → 12 次元)に替えた。証拠 = `results/diag_snv_a3_p/verdict.yaml`。
- 事前登録の H_leak。本物の男声 → 目標 0.13(A2 の x 0.56)・別の声の演奏で読ませると出力は源の声と読まれる(O の read_as_source 0.53)。自己の reamp(S 0.79)と明瞭さ(CER 0.18)は A2 の x より良い = E は内容も声も運ぶ。
- 入力側の摂動(発話ごとの周波数の伸縮・EQ・利得)は効かない(p − n = +0.02・区間は 0 を含む)。
- 較正(走行の後): E の 12 次元の声の探り 0.85 は、生の包絡 0.91・未学習の E 0.80 と同じ水準。**E が声を学んだのではなく、入力が運ぶ声を自己の reamp には捨てる理由が無い。** 参照の鍵と質問が常に同じ話者なので、話者を跨いだ対応を学ぶ信号が学習のどこにも無い。
- 線形の探りは話者ごとの平均の差しか見ない: 包絡から因果の走行平均(1 s)を引くだけで線形は偶然(0.03)まで落ちるが、共分散まで見る探り(QDA)は 0.89 のまま。SPARC の EMA は QDA でも 0.20 = 本当に声を運ばない。以後の構造の漏れは QDA を並べて読む。
- 理論への読み: 演奏の信号に要るのは「話者で正規化された調音の座標」。SPARC の EMA は複数の話者の調音の計測から学んだ逆推定なのでそれを持つ。自前で持つには、話者を跨ぐ仕掛けを損失かデータの分布に置く。
- 話者の敵対(A3b・煙テストだけ): 学習の声の識別器は偶然まで騙せるが、新しく当てはめた探りは検証の声を 0.85 で当てる = その時点の識別器を騙すだけで声は消えない(敵対で属性を消す方法の既知の失敗)。起動しない。
- 話者の統計の差し替え(A3c): E の入力の包絡を声 A の平均・共分散で白色化し、乱数の別の声 B の平均・共分散で着色し直す(入力側だけ)。差し替えた発話は、統計と別の型の探り(GMM・前後 5 フレームの QDA)でも A と読まれる率 0〜0.02・B と 0.77〜1.00。E の入力の声が目標と無関係になり、参照の鍵(A)と質問(B 風)が話者を跨ぐ = 変換の条件で学ぶ。
- A3c の結果(`results/diag_snv_a3c_w/verdict.yaml`)は事前登録の H_leak。本物の男声 → 目標 0.21(A3 の n 0.11 から +0.10・区間 [0.00, 0.22]・A2 の x 0.56)・別の声の演奏が源と読まれる率 0.29(A3 0.60)・明瞭さは保つ(CER 0.24)。
- 物差しを入れ替えると読みが割れる: mel の QDA(フレームの分布)で読むと、A0 の声でも本物の男声でも出力は目標へほぼ完全に移る(O 目標 0.96・源 0.00・M 目標 0.81。A3 の n は 0.15 / 0.61 / 0.25)。ECAPA で読むと、学習の分布の内の検証 30 声でも源の残りがある(源 0.13・目標 0.29)。**全体の統計の差し替えは、出力の大域の分布を目標へ移すが、ECAPA が読む声(状態ごとの包絡の形か長い時間の動き)は残す。** A0 の声や本物の男声が学習の分布の外、という読みは退く。
- 状態ごとの差し替え(A3d の事前検査・5k step × 3・`results/diag_snv_a3c_w/verdict.yaml` の a3d_precheck)は効かない: 入力のフレームの残りの声を探りで 0.44 → 0.11〜0.17 に下げても、変換の出力を ECAPA で読む源の率は 0.16 → 0.15 / 0.13(事前の規則 −0.05 に届かない)→ 起動しない。閉じた組で声を当てる探りは漏れを決めない(SPARC の EMA も 0.61 / 0.68)。
- **律速は話者を跨いだ調音の状態の対応**(注意が読んだ参照の状態と今の状態の相関・EMA は物差しとしてだけ): A2 の x は本人 0.86・別の女声 0.85・Irodori の男声 0.84・本物の男声 0.81。自前の E(A3c)は 0.77・0.72・0.57・0.47。崩れの主は性別(声道長)を跨ぐ所で、本物の録音の分は約 0.1。A3c は源への漏れ(0.13)より目標に届かない(A2 の x 0.75 に対し 0.29・第三の声 0.58)。
- 入力側で質問だけを変形する三つの型(伸縮と EQ = A3 の p・全体の統計 = A3c・状態ごとの統計)はどれも対応を作らない(Irodori の男声 0.53 → 0.55〜0.57)。参照の鍵と質問が常に同じ話者 A から来るので、変形を越えて残る A の形で照合でき、話者を跨いだ対応を学ぶ信号が無い。同型の差し替えは打ち切る。
- 理論への読み: 演奏の信号に要るのは「話者を跨いで同じ調音の状態が同じ座標に来る」こと(SPARC の EMA は複数の話者の調音の計測でそれを得ている)。自己の reamp と入力の変形だけでは得られない。次は話者を跨いだ対応の信号を学習に入れる(同じ文を別の声で読んだ組を E の段で対応させ、出力は自己の reamp のまま)。E1 に偶然の組が 1,891(性別を跨ぐ 613)ある。

## 4. NAM A2 から移すもの

NAM A2(2026-06-02 公開。[TONE3000 の解説](https://www.tone3000.com/guides/nam-a2-the-complete-guide)・[neuralampmodeler.com](https://www.neuralampmodeler.com/post/architecture-a2)):
- 小さな因果の膨張畳み込み(3 段・23 層・受容野 約 132 ms・LeakyReLU)。slimmable(幅 8ch / 3ch を 1 ファイルに詰める)。
- 損失 = MSE + 小さな MRSTFT。1 万回を超える自動の探索と Bayesian Elo で選び、差が小さければ単純な方を採る。

本設計での扱い:
- 回帰が成り立つのは I1〜I3 が成り立つ範囲だけ。成り立たない分(位相・雑音の実現など)は回帰では平均になるので、そこに限って分布の損失を検討する。
- 最良の重みを選ぶ物差しには、自己の reamp の誤差(本人の別の発話を参照にした再現。NAM の ESR に相当)が使える。ただし変換(男声の入力)の良さは保証しないので、変換の物差しを別に持つ。

## 6. 物差し

- 主の入力は本物の男声(外郎売・namikawa・VCTK の男声)。Irodori の男声は学習と補助だけに使う。
- 旧来の物差しのコードは、A0 で較正してから使う。
- A0 の較正の結果(2026-11-01・`results/snv_a0`・`snv_a0b`・`snv_a0c`):
  - 自然さ = UTMOS22 strong。6 種の劣化を全て正しく読む(元 > 劣化の勝率 0.99〜1.00)。ただし Irodori の女声の絶対値は 2.9 と低く出るので、対の差だけを使う。
  - 構造の漏れ = フレーム単位の log-mel のロジスティック回帰の探り。36 声を 0.92 で当て、並べ替え・乱数は偶然の水準。
  - 明瞭さ = Whisper large-v3 の仮名の CER。雑音ボコーダの帯域数と包絡のぼかしに単調に反応するが段差状で、大きな崩れ(4 帯域・200 ms)でだけ動く粗い関門。白色雑音 0 dB・2 kHz の低域通過では動かない(人にも聞き取れる劣化なので対照として不適だった)。ASR の確信度は作り話で逆転するので使わない。
  - 本人らしさ = ECAPA(+ 本物の女声の LDA)。本物の日本語の女声は 15 s で 24 人中 0.92 で見分けるが、Irodori v4.1 の声の組は 0.81 で頭打ち。Irodori が caption 由来の参照から作る声には、話者認識が同じ人と読む声が混ざる。包絡を α 倍にずらすと本人らしさは単調に下がる(構造の変更を読む)。高さ ±4 半音でも同程度に下がる。

## 7. 既知のリスク(仮説・未検証)

- 構造の漏れ(I2 の崩れ): 男声の入力で男声が残る。
- 条件付き平均(I1 の崩れ): ぼやけ。
- TTS の音声から本物の音声への移り(学習は Irodori・評価は本物)。
- 透かし(SilentCipher)と DACVAE の復号の質感が、全ての学習音声に共通する: G がそれを構造として覚える近道になる。
- 男声 → 女声で、操作者の演奏(調音の範囲・声源)が目標の構造に対して範囲の外になる。
- **Irodori の声の多様性は生成した数より少ない**(A0): zero-shot の学習の声の多様性は、生成した数でなく実効の数で測る。
