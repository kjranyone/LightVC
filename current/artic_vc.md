## 2. 定式化

話者 s が内容の並び u_{1:T}(と時間・韻律 π)を話すときの包絡の軌道を

  e_{1:T} = F_s(u_{1:T}, π) + ε

とする。F_s は**話者の構音写像**(系列から系列への関数)。変換は、参照の標本 D_s = {(u^r, e^r)}(20s)から、新しい内容 u^src に対する F_s(u^src) を推定する問題 = **関数の推定**であって、ベクトルの推定ではない。

- 表 T_s(u) = F_s の 0 次近似(単位ごとの定数)。A4 の天井はこの近似の限界。
- A5・A6 から、F_s は『0 次近似 + 加法の補正』に分解できない(補正は自分の 0 次の値と一貫したときだけ意味を持つ)。→ **軌道は丸ごと生成する**。
- 20s の標本だけから F_s を推定するには、多数の話者で学習した**関数の事前分布**(話者に共通な構音の動き方)が要り、話者固有の部分を D_s から**内容で索引した十分統計量**として取り出す。
- 内容で索引した十分統計量 = **記述子の場** d_s(u) ∈ R^m(単位ごと)。表(m = 24 の平均)はその特殊な場合。記述子は、参照の中で単位 u が現れた全箇所を、学習したエンコーダでプーリングした固定長の要約(フレームは保存しない・出力に写さない)。観測の無い/薄い単位は、単位の空間(コードブックの近さ)の上の滑らかな補間で埋める。

## 3. 構成(rev0)

```text
登録(オフライン・1 回): 参照 20s → [F1・C1・CheapTrick] → (単位, 包絡の軌道, f0, c0) の列
                          → 記述子エンコーダ E: 単位 u の各出現の窓(前後 ±k フレームの包絡と単位の並び)→ 出現ごとのベクトル
                          → 単位ごとにプーリング(平均・標準偏差)→ d_s(u)(観測の無い単位は近い単位から補間)
                          → 保存: d_s ∈ R^{K × m}(K = 200・m ≈ 32〜64)と既存の表 T_s

推論(因果・200fps): 元の声 → C1(硬い単位 u_t)・F1(f0)・F2 + 3 平均(c0)
                     → 生成器 G(因果 TCN): 入力 = 単位の one-hot・d_s(u_t)・d_s(u_{t-1} の直前の別単位)・相対 log f0・c0・有声
                     → 包絡の軌道 ê_t(c1..c24・丸ごと)
                     → 出力部 rvoc(既存)
```

- G は表への加算ではなく包絡を直接出す(A5・A6)。ただし初期は『表の引き』を出す恒等に近い初期化にして、学習の出発点を基準(表)に置く。
- 話者の条件は d_s(u_t)(今の単位の記述子)と直前の単位の記述子だけ = 内容で索引(大域の z なし)。
- f0 は中央値の移動のみ(A3)。周期性は話者平均(A3)。c0 は F2 + 因果 3 平均(A3)。

## 4. 学習

- データ: 評価外の日本語女声(実音声)の全話者(評価話者・その TTS 複製・LDA 物差しの評価プールを除く)。話者ごとに発話をファイル単位で**参照用 / 学習用に素に分割**(A9)。参照用から d_s・T_s、学習用の発話を教師。
- 目的(rev0 = 回帰のみ・GAN 不使用): L1(ê, e_real)(有声・活性フレーム)+ 内容の錨(出力の包絡を出力部に通さずに、C1 の事後が元の発話と一致)。回帰の最適は事後平均 = 平滑化の恐れ(D5 型)→ 同一性は学習外の LDA で判定し、MSE の改善を成功にしない。
- 近道の遮断(分布レベル・design_laws):
  - 同じ話者の発話なので、単位の並び・f0・c0 から話者を読む近道がある → 入力側の摂動: 元の発話の音声を声道長 0.8〜1.0 倍・音域 −3〜−8 半音の範囲でワープしてから C1・F1・F2 に通す(教師の包絡は実音声のまま)。
  - 記述子を別の話者のものに差し替えた対(教師は無い)は損失に入れず、評価の対照にだけ使う。
- 規模: G は 192ch × 12 ブロック程度(< 1.5 GMAC/s)・E は登録時のみ。

## 5. 評価の規約(先に固定)

- 物差し: 学習外の LDA(d4b・目標の番号は数値順)。必ず並べる: 本人の実音声(別ファイル)・写し合成・表(基準)。
- 自己変換(内容 = 目標自身の別発話・検出力のため評価外の 150 人 × 3 発話)と製品条件(日本語男声 → 日本語 held 19 人)。
- 対照: 記述子シャッフル(別の話者の d を渡す)= 本来の目標の順位が表の水準以下に落ちること(G が記述子に従っている)。
- 自然さ: フレーム周期の線(表 + 0.1dB 以内)・包絡の変調(4–15 / 15–50Hz が本物の 1.0 倍以下)・内容の一致。耳は数値を通った候補だけ。
