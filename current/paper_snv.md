# 論文の骨格: 演奏と回路の境界は内容で条件づけた共有でだけ決まる — 低遅延のアナログモデリング VC の識別可能性 (status: ADOPTED 製品管路正本・rev248・2026-11-28)

> 2026-11-28（rev248 圧縮整理）: 棄却された中間仮説（M3〜M50 の不採用項・段 T6〜T15・段 I1〜I25・段 P15〜P92/P97〜P122 の逐次試行ログ）を体系的な要約・負例表に圧縮し、理論（命題 1〜3）・現行採用手法（段 P126 `K3G-v4`）・評価規約（§7）・オーナー判断台帳（§9）を無欠損で保持した。圧縮前の全 3,945 行（rev0〜rev247 逐次ログ全文）は git コミット `b749b59` に保存されている。

## 要旨

声質変換（VC）を、音声を「話者の回路を通った演奏」とみなすアナログモデリングとして定式化する（話者 ＝ 構造 `φ_s`、発話 ＝ 演奏 `u` を回路 `F` に通した音、変換 ＝ 回路の差し替え、操作者もまた回路）。

- **命題 1（非識別性）**: 同じ話者の音声だけ（自己の reamp）からは、演奏と回路の分離は話者ごとの可逆写像 `h_s` を除いて決まらず、変換は一意に定まらない。話者横断の内容を参照しない正則化（標準正規事前分布・周辺分布整合・話者判別器・話者別 2 次統計白色化）はそれぞれ不変な変換群を残し、再現損失で学ぶ演奏は構造の近似誤差を補う「写し（源話者漏洩）」へ引き寄せられる。
- **命題 2（条件付き共有による識別）**: 内容 `w` を与えたときの演奏分布 `p(u | w)` が全話者で共通かつ十分に多様であり、内容共有グラフが男女を跨いで連結であれば、`h_s` は全話者で一致し変換が一意に定まる（境界 `I(u; s | w) = 0`）。
- **命題 3（遅延不変性）**: 内容共有の識別項は学習時のみ作用し、推論は因果な演奏抽出器 `Ê` と因果な回路・描画器 `F̂` のみで構成されるため、アルゴリズム先読みを増やさない。
- **到達点（段 P126 `K3G-v4`・2026-11-28 製品採用）**:
  1. 実データでは自己 reamp の再現損失から切り離した自己教師対照予測符号（CPC）に擬似操作者視点（`xview`）と同文異話者 DTW 正例（`dview`）を入れ、さらに**入力表現の異なる独立符号（ピッチ適応窓包絡 2 系 ＋ 固定 40 ms 窓包絡 1 系）の回路出力平均 `K3G`** を組むことで、単一モデルが陥る実音声「源の脆さ」の壁を突破し試験 CER `0.2527 ≤ 0.275` と耳の関門を通過した（段 P93〜P94）。
  2. さらに、① 教師 `harvest` `f0` と因果 3 点包絡平滑の重心 `(t-1)·HOP` に厳密時刻同期した出力部 `snv_p123_s`（`delay = 480`・因果写し PESQ `3.5404`）、② 変換網用 `f0_net` と包絡・写し用 `f0_voc` を分離した因果ピッチ追跡 `v4_dual` と全コーパス `v4` 特徴での `K3G` フル再学習、③ 200 ms 錨ヒステリシスと分離した瞬時 STFT マスク門 `inst_mask = true` を統合した **`K3G-v4`**（段 P123〜P126）により、全客観関門・Rust 4 並列実時間関門 S（最悪 `p99 = 4.89 / 4.67 ms < 5.0 ms`・先読み 0 標本・アルゴリズム遅延 `15.0 ms`）・オーナーの耳の関門（「うーん、ええんちゃう」）を通過して製品既定へ昇格した。

## 1. 問題設定と製品要件

- **製品仕様**: 48 kHz・200 fps（`HOP = 240` 標本 = `5.0 ms`）・CPU 実時間ストリーミング・因果（先読み 0）・**E2E 遅延設計目標 `p95 < 30 ms`（理想 20 ms 級、`p95 ≥ 50 ms` は失格上限）**。
- **制御と変換**: 本物の男声の操作者 → 任意の目標話者（ゼロショット・参照音声 20 秒以上、操作者登録 30 秒程度）。出力ピッチは操作者 `f0` ＋ **利用者固定の `k` 半音（運用・評価は `+0 / +5 / +7 / +12`）**。抑揚と時間構造は操作者に追従する。
- **ノイズ耐性（オーナー 2026-11-09 必須要件）**: 声と時間的に重なる操作者の非音声（手を叩きながら笑う・物音）や背景伴奏の上で、発話（非言語発声を含む）の変換が崩れず、かつ無声時の雑音・手拍子・伴奏を声に化けさせない。
- **データの原則**: 学習データは `Irodori-TTS-v4.1-Small`（MIT・VoiceDesign の架空の声）の生成音声のみ。入力側の乱しに限り許諾明確（CC0 / CC BY / PD・AST 閾値 `0.02` で音声除去済み）な本物の非音声音源（MUSAN・FMA・FSD50K）を使う。既存モデル（WavLM / ECAPA / ASR / PESQ / UTMOS 等）は評価の物差し・参考値に限定し、直接教師・蒸留・表現監督には使わない。

## 2. 生成の模型と変換の定義

| 記号 | 意味 | 変換時の帰属 |
|---|---|---|
| `u = u_{1:T} ∈ 𝒰^T` | **演奏**: 調音運動（何を・いつ・どう）と声源状態 | 操作者 |
| `lf, v` | 対数基本周波数 `log(f0/200)` と有声フラグ | 操作者（`+ k` 半音） |
| `φ_s` | **構造 ＝ 回路**: 話者 `s` の声道・声源器官の静的特性 | 目標話者 |
| `F` | **因果回路・描画族**: `y_t = F(u_{≤t}, lf_{≤t}, v_{≤t}; φ_s)` | 共通網 |
| `w` | **内容**: 台詞文または非言語発声カテゴリ・状況指示 | 学習データでのみ観測 |

- **変換の定義（操作者 `o` → 目標 `t`）**: 真の reamp `y_{o→t} = F(u_o, lf_o + k; φ_t)` を、登録特徴 `φ̂_o, φ̂_t` を用いて `ŷ = F̂(Ê(y_o; φ̂_o), lf_o + k; φ̂_t)` により因果推定する。
- **基本仮定**:
  - **A1（構造の十分性）**: `φ_s` は話者 `s` の普通の発話 20 秒以上から推定できる（注意表型 `x` により成立）。
  - **A2（演奏の話者独立性）**: `p(u | w, s) = p(u | w)`。境界の定義は **`I(u; s | w) = 0`**。
  - **A3（推論符号器の入力分布被覆）**: 推論符号器 `Ê` の不変性は学習入力分布の支えの上でのみ保証される。実音声操作者との乖離は、(a) E 以前の信号処理（ピッチ・有声決定と STFT マスク）と (b) 包絡特徴の擬似操作者摂動（WORLD 声道・ピッチ変換 ＋ 録音鎖 `v2` ＋ 実非音声重畳）の両面で被覆する。
  - **A4（回路・復号器の入力支え）**: 回路 `F̂` が変換時の `(u_o, lf_o + k; φ_t)` を正しく描くには、学習時にも擬似操作者側から元の話者への再構成（`M29`）を行い、`+12` 半音を含む運用ピッチ・有声分布と回路の受容野を一致させる必要がある。

## 3. 主張（命題と実データから導かれた系）

### 主張 1（命題 1）: 自己の reamp では変換が決まらない

任意の因果可逆写像族 `{h_s}` に対し `u′ = h_s(u)`, `F′(·; φ_s) = F(h_s^{-1}(·); φ_s)` は全話者の観測分布 `p(y | s)` を不変に保つが、`h_t^{-1} ∘ h_o ≠ id` ならば変換 `F′(u′_o; φ_t)` は真の reamp と一致しない。■

- **系 1a（話者非依存正則化の限界）**: `N(0, I)` 事前分布は直交回転を、周辺分布一致や話者敵対判別器は保測写像を、話者別 2 次白色化（`P8`）は白色化後の直交回転を不定に残す。
- **系 1b（再現損失による写しへの引き寄せ）**: 構造推定 `φ̂_s` に近似誤差がある実データでは、演奏 `u` に話者微細構造を残す方がフレーム毎の再現損失が大きく下がるため、発話単位の緩い KL 罰や判別器に勝って写し（源話者漏洩）へ収束する。
- **系 1c（配線遮断の不十分性）**: 直通路を削っても注意重み等の別経路から情報が漏れる（分布レベルの遮断が不可欠）。

### 主張 2（命題 2）: 内容で条件づけた共有が変換を決める

`p′(u′ | w, s) = p′(u′ | w)` を課し、条件付き分布族 `{p(· | w)}` の共通対称性が恒等写像のみで、かつ話者間の内容共有グラフが男女を跨いで連結ならば、全話者で `h_s = h` となり変換は真の reamp `F(u_o; φ_t)` に一意決定される。■

実データ（段 I1〜I25・段 P15〜P126）の検証から確定した系:
- **系 2d〜2f（柔らかい共有と学習残差の破綻）**: ELBO の柔らかいテンプレート事前分布はフレーム毎の再現利得に負け（系 2d）、初期座標が話者毎に回転していると平均テンプレート自体が無意味化し（系 2e）、`y` を見る学習残差を足すと残差が全情報を乗っ取る（系 2f）。
- **系 2j〜2r（自己教師 CPC ＋ 話者内正規化 ＋ 擬似操作者 reamp への転換）**: 共有軌跡への直接回帰符号器は合成族外の実音声で崩壊する（`devA` CER `0.73`）一方、**再現損失を持たない対照予測符号（CPC）に擬似操作者視点（`xview`）と同文異話者 DTW 正例視点（`dview`）を与えて学習し、PCA 32 ＋ 128 クラスタ符号帳へのベイズ縮小正規化を施した演奏表現**は、実音声でも内容を保ったまま話者性を除去する（段 P19〜P30）。
- **系 2p〜2t（生成痕跡の罠と、持続門・瞬時マスク・錨の役割分離）**: 合成音声だけで分離網を学ぶと SilentCipher 透かしやデジタル無音を声の近道にするため、背景と擬似操作者波形の双方に透かしと雑音床を揃える（系 2p）。突発非音声（手拍子）や伴奏出だしには **`gate_p ≥ thr` での瞬時 STFT マスク（`inst_mask`）** を掛け、200 ms 以上持続する強伴奏区間でのみ **錨（`anch`: 源包絡フォールバック）** を開くことで、語頭保護と単発拍手遮断（`−33.4 dB`）を両立できる（段 P126）。
- **系 2x（実音声「源の脆さ」と異種入力符号アンサンブル `K3G`）**: `devA` の CER は下位 1/4 話者の「源の脆さ」（微小包絡摂動に対する ASR 崩壊度、順位相関 `+0.75`）で決まり、同一入力特徴上の CPC を増やしても同じ底で飽和するが、**ピッチ適応 CheapTrick 包絡を読む 2 系（`a, b`）と固定 40 ms 窓包絡を読む 1 系（`e`）の計 3 組の回路出力を平均する `K3G`** は誤りが統計的に独立となり、大幅な CER 低減をもたらす（段 P91〜P93）。
- **系 2y（因果ピッチ追跡の網/描画分離と、描画器時刻同期の法則）**: 変換網 `K3G`（`c0` 非入力）は無音・破裂での誤有声化による声幻覚を防ぐ厳格な `f0_net`（8 次 LPC 残差）を要し、包絡抽出・写し描画（`c0` 権威あり）は小声母音の雑音化を防ぐ寛容な `f0_voc` を要する（`v4_dual`・段 P124）。また描画器（`rvoc`）は必ず**教師の綺麗な `harvest` `f0`** で学習し、因果 3 点包絡平滑（群遅延 `240` 標本）に合わせて `f0[t-1]`・`per[t-1]`・目標波形切り出し `delay = 480` を厳密同期させなければならない（段 P121〜P123）。

### 主張 3（命題 3）: 識別の項は遅延を増やさない

内容共有（`dview` 等）および教師 `harvest` `f0` 分析は学習時にのみ用い、推論時は左寄せ窓前段（先読み 0）・因果畳み込み・登録済み参照キャッシュ・因果描画器のみで動作するため、先読みは 0 標本である。

### 主張 4: 物差し

- **境界の物差し D**: 参照なし復号器が演奏表現から元話者を描ける top-1 率（回路 `C` の女→女写し率 `ff216` を予言）。
- **変換品質の物差し**: 本物の男声 `devA`/`devB`/試験 12 区間における仮名 **CER**、A0F 24 声中の目標着地 **M**（正規化利得 `g`）、女→女写し漏れ **`ff216`**。
- **描画・ノイズ・遅延の物差し**: 最適ラグ整合 **PESQ**（UTMOS が盲目な倍音間雑音・声門うなりを検出）、平滑後 `c0` 2 階差比 **`d2`**、実効遅れ（`onset, env_centroid, f0`）と折れ **`zz95`**（`probe4`）、伴奏・手拍子下の **CER** と非音声区間出力レベル **`pad_db`**。

## 5. 方法

### 5.1 現行採用パイプライン（段 P126 `K3G-v4`）の構成

1. **データ（`M1`）**:
   - `data/snv_e1`（架空 600 声［女 480・男 120］× 通常 10 発話）、`data/snv_e1nv`（同 600 声 × 非言語 7 種 × 2）、`data/snv_d`（1,500 文 × 各 `K = 8` 声共有 = 11,992 発話、男女横断 1,254 文）。学習 564 声・検証 36 声。
   - 擬似操作者版 `x16`（`M29`）: 各発話を声ごとの `(r, α, room)` で WORLD（ピッチ `r` 倍・声道長 `α` 倍）＋ 録音鎖 `v2`（残響・帯域制限・雑音床・唸り）に通した入力専用波形 `data/snv_p_wav_x16{,w}` と `v4` 特徴 `data/snv_p_feat*_v4`。
2. **因果前段 `v4_dual` ＋ 瞬時マスク門 `snv_p126_gate_i80`（`M27, M35, M36` ＋ 段 P124/P126）**:
   - 48 kHz・左寄せ窓（先読み 0）・`W_YIN = 600`（12.5 ms）・有声 CheapTrick 半幅上限 `ENV_CAP_MS = 7.5 ms`・無声位置 `TAU_UV_HZ = 500 Hz`。
   - **2 系統因果ピッチ追跡 `v4_dual`**（`snv_f0v4.py` / `p_front.rs`）:
     - `f0_net`（変換網・門側）: 8 次 LPC 残差 `dn8`・`U_COST = 0.50`・`E_FLOOR = 1e-7`・息共鳴除外により無音・破裂での誤有声化を遮断。
     - `f0_voc`（包絡・周期性・写し側）: `0.88·raw + 0.12·dn4`・`U_COST = 0.65`・`E_FLOOR = 1e-9`・副調波脱出により小声母音の有声性を保持。
   - **門と瞬時 STFT マスク**: 門網 `snv_p40_gate_t80` の非音声確率 `p` に対し、錨切替は `op = hysteresis(p, on=40, off=100, thr=0.8)`（200 ms 持続で開・500 ms で閉）、STFT 比マスク `snv_p45_mask` とマスク後 YIN（`myin`）は **`mask_on = op || (p >= 0.8)`（`inst_mask = true`）** で瞬時適用する。
3. **独立 3 符号アンサンブルと回路 `K3G-v4`（`M29, M30, M33, M43, M49` ＋ 段 P125）**:
   - **3 組の CPC 符号器 ＋ 回路 `C`**（各 CPC 30k 歩 → PCA 32 次元 ＋ `K = 128` 符号帳へのベイズ縮小 `TAU = 20, shrink = 0.6` による操作者登録正規化 → 回路 `C` 40k 歩）:
     - 組 `a`（`snv_p125a_c`）: ピッチ適応包絡入力・CPC（`--aug --xview`）＋ 回路 `rend` 項あり。
     - 組 `b`（`snv_p125b_c`）: ピッチ適応包絡入力・CPC（`--aug --xview --dview`、段 D の同文 DTW 対応を正例に追加）＋ 回路 `rend` 項あり。
     - 組 `e`（`snv_p125e_c`）: **固定 40 ms 左寄せ窓包絡**（`snv_p91_stenv.py` / `p_fixenv.rs`）を符号入力とする CPC（`--aug --xview --dview`）＋ 回路 `--no_rend`（出力はピッチ適応包絡）。

4. **時刻同期描画器 `snv_p123_s` ＋ 出力の番 `out_guard`（段 P95・P123）**:
   - 生成型因果ボコーダ `RVoc`（直線補間 ＋ 因果畳み込み `ups = [5, 4, 4, 3]`, 256 ch, 帯域制限パルス列 ＋ 白色雑音励起）。
   - 包絡 25 行に因果 3 点平滑 `[0.25, 0.5, 0.25]`（`env_smooth = 0.25`、重心遅れ 1 フレーム = `240` 標本）を掛け、学習時は教師 `harvest` `f0[t-1]`・`per[t-1]`・目標波形切り出し `delay = 480` を厳密同期して学習。推論出力後段に遅延 0 の尖頭値・無音時利得保護 `out_guard` を通す。

### 9.2 残る限界と今後の課題

- **非言語発声（悲鳴・喘ぎ）における直通路の源声質残留（段 P109〜P112）**: 普通の発話の参照のみから未知の強非言語発声を描く際、回路の直通路が源の声質を一部運ぶ（通常発話の `+12` 着地 `M` を落とさずに非言語着地を引き上げる回路構造が今後の課題）。
- **実録音下位層の源の脆さ（O29, O30）**: 元音声自体が ASR 境界に近い不明瞭な録音話者では、前段・写し段階での情報損失が変換後の明瞭さ上限を規定する。
- **話し癖（O3）**: 発話速度やリズム等の時間的話し癖は操作者側に残る仕様（明示ピッチ・時間追従との設計上のトレードオフ）。
