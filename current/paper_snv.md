# 論文の骨格: 演奏と回路の境界は内容で条件づけた共有でだけ決まる — 低遅延のアナログモデリング VC の識別可能性 (status: PROPOSED・rev40・2026-11-09)

## 要旨

声質変換を、音声を「話者の回路を通った演奏」とみなすアナログモデリングとして定式化する(話者 = 構造 φ_s・発話 = 演奏 u を回路 F に通した音・変換 = 回路の差し替え・操作者もまた回路)。
**命題 1**: 同じ声の音だけ(自己の reamp)からは、演奏と回路の分け方は話者ごとの演奏の可逆な変換 h_s を除いてしか決まらず、変換は一意に決まらない。話者を跨いだ内容を参照しない正則化(演奏の事前分布・周辺分布の一致・話者の識別器・話者ごとの統計の正規化)は、それぞれが保つ変換の類を残す。演奏の取り出しを再現の損失で学ぶと、回路の近似の不足を演奏が補う解(写し)に引き寄せられる。
**命題 2**: 内容 w を与えたときの演奏の分布 p(u | w) が全話者で共通で、内容によって十分に変わり、話者が内容の共有でつながっているなら、h_s は全話者で同じに決まり、変換が一意に定まる。このとき I(u; s | w) = 0 = 演奏は内容を与えれば話者を運ばない(境界の定義)。
方法は命題から導く: 多くの声が同じ内容を発するデータ(Irodori の生成)・内容だけで条件づけた共有の演奏の事前分布(識別の項・学習だけ)・操作者の構造で演奏を取り出す因果の推定器・因果の描画器。
理論の立証は、正解の reamp を作れる合成の世界(演奏と構造が既知)で命題と方法を先に確かめ、その後に Irodori の生成データの全量で同じ管路を走らせる。製品の経路の上のこれまでの観測(P1〜P14・A 線)は §4 で命題の証拠として位置づける。

## 2. 生成の模型と変換の定義

| 記号 | 中身 | 変換での持ち主 |
|---|---|---|
| u = u_{1:T} ∈ 𝒰^T | 演奏: 調音の動き(何を・いつ・どう)と声源の質(息・圧) | 操作者 |
| lf・有声 | 高さと有声(明示の入力) | 操作者(+ k 半音) |
| φ_s | 構造 = 回路: 話者 s の声道と声源の器官の形と性質(時間に依らない) | 目標 |
| F | 描画 = 回路の族: y_t = F(u_{≤t}, lf_{≤t}; φ_s)(因果) | 共通 |
| w | 内容: 何を発するか(台本の文・音素の無い発声の種類と指示) | 学習のデータでだけ観測 |
| ε | 録音と推定の雑音 | — |

- データの生成: 話者 s・内容 w について u ~ p(u | w, s)、y = F(u; φ_s) + ε。
- 変換の定義(o → t): 真の reamp y_{o→t} = F(u_o; φ_t)。推定: ŷ = F̂(Ê(y_o; φ̂_o); φ̂_t)。Ê = 操作者の回路の逆(操作者の構造で操作者の音を説明して演奏を取り出す = de-embed)。φ̂ は登録(操作者 30 s・目標 20 s 以上)から。

- 仮定 A2(演奏は話者に依らない): p(u | w, s) = p(u | w)。話者の回路(器官の形と性質)は、内容に対して何をするかの分布を変えない。話者の話し癖は A2 の外にある(§9 O3)。

## 3. 主張

### 主張 1(命題 1): 自己の reamp では変換が決まらない

任意の可逆写像の族 {h_s : 𝒰^T → 𝒰^T}(因果)について、u′ = h_s(u)・p′(u′ | s) = (h_s)_# p(u | s)・F′(·; φ_s) = F(h_s^{-1}(·); φ_s) とおくと、全ての話者で y の分布は元と同じ。
変換は F′(u′_o; φ_t) = F(h_t^{-1}(h_o(u_o)); φ_t) で、h_t^{-1} ∘ h_o ≠ id なら真の reamp と違う。自己の reamp のデータ(話者 s の (y, φ_s) だけ)はどの族 {h_s} も区別しない。■

- **系 1a(話者に依らない正則化は決めない)**: 話者を跨いで同じ内容を参照しない正則化は、それを保つ h_s の類を残す。演奏の事前分布 N(0, I) → 直交の回転。話者を跨いだ演奏の周辺分布の一致・話者の識別器への不変性 → 周辺を保つ写像(連続の分布では無数)。話者ごとの登録の統計の正規化(平均・白くする)→ 正規化の後の回転。どれも変換を決めない。
- **系 1a′(一意性と帰納の偏りの区別・rev1)**: 命題 1 は一意性の主張で、学習がどの h_s に寄るかは帰納の偏りが決める。段 T(構造を精確に推せる世界)では、N(0, I) の KL だけでも話者を跨いで同じ置き方に寄った(対応 1.0・e 0.36)が、演奏の話者の率は 0.16 で床(0.06)へ下がらなかった = 偏りは途中まで寄せるが決めない。
- **系 1b(写しへの引き寄せ・rev1 で A1 の破れを条件に)**: Ê が y を見て再現の損失で学び、演奏に情報の代価が無いと(決定的な演奏)、話者を演奏に残す h_s に寄る(段 T の a_det e 0.59〜0.62)。情報の代価(KL)があっても、F̂ による φ の使い方が近似でしかない(A1 が破れる)と、話者の情報を演奏に残す方が再現が精確になり、尺度を学ぶ尤度の下でこの精度の差が代価に勝つ(実データの P11・P12)。A1 が成り立つ世界では、尺度を学んでも引き寄せは起きなかった(段 T の T4)。
- **系 1c(配線は決めない)**: 演奏から出力への道を構成で絞っても、演奏が他の道(注意の重み)で同じ情報を運べる限り h_s は残る(設計三層則「配線だけの遮断は停滞する」)。

### 主張 2(命題 2): 内容で条件づけた共有が変換を決める

モデルの側で p′(u′ | w, s) = p′(u′ | w)(内容だけで条件づけた共有の事前分布)を課す。話者 s と r が内容の集合 𝒲_{sr} を共有するとき、(h_r^{-1} ∘ h_s)_# p(· | w) = p(· | w)(全ての w ∈ 𝒲_{sr})。
条件付き分布の族 {p(· | w)}_{w ∈ 𝒲_{sr}} の共通の対称性が恒等写像だけ(十分な多様性)なら h_s = h_r。話者を頂点・内容の共有を辺とするグラフが連結なら、全ての話者で h_s = h、変換は F(h^{-1}(h(u_o)); φ_t) = F(u_o; φ_t) = 真の reamp。■

- 十分な多様性の例: p(· | w) = N(m_w, Σ)(共分散は共通)で、平均 {m_w} が 𝒰 をアフィンに張る(dim 𝒰 + 1 個以上)なら、全ての p(· | w) を保つアフィン写像は恒等だけ。非線形の写像と系列については、補助変数で条件づけた非線形 ICA の識別可能性の条件(Khemakhem ら 2020 の iVAE・Hyvärinen ら 2019)に従う(§8)。

### 主張 3(命題 3): 識別の項は遅延を増やさない

- p′(u | w) は学習だけに使う。推論は Ê(y_o; φ̂_o) と F̂(·; φ̂_t) だけで、どちらも因果、φ̂ は登録の定数 = 遅延は Ê と F̂ の先読み(0)と処理で決まる。
- Ê は演奏を因果に推定する。内容の中の位置が未来を見ないと決まらない分(先取りの調音結合)は推定の誤差として残る。どこまで因果に取り出せるかは synth_nam_vc §3 の測る量そのもの。

## 5. 方法(命題から導く)

### M1 データ: 内容を共有する Irodori の生成
- 系 2b から: 内容の集合を、多くの声で共有するように作る。台本 N_w 文 × 声 N_s、各文を K 声(男女を含む)が読み、各声が多くの文を読む(共有のグラフが連結)。音素の無い発声も、同じ説明文(動作・状況・絵文字)を複数の声で生成して内容として共有する。
- K と N_w の大きさは段 T(§6)の K の曲線から決める。生成の作法は [[irodori-nonverbal-limits]](参照付きは説明文に声質を書かない・CFG)に従う。
- 時刻の揃え・声どうしの音響の回帰は使わない(内容は分布の条件としてだけ使う)。
- **rev27(系 2l rev27・系 2o から・段 D3)**: 族が操作者の母集団(本物の成人男性の声・マイクと部屋の録音)を覆うように、声の説明文と録音の説明文を選ぶ。E1 の男声の説明文に、(v) 操作者の母集団へ向けた声の属性(成人・普通から非常に低めの高さ・太い・こもった・しゃがれた・語りと朗読)と、(r) 録音の文の幅(自宅の部屋の一般的なマイク・少し離れたマイク・放送の語りの収録・ヘッドセット)を足す。
  覆いは学習なしで測ってから生成の量を決める(段 D3): 開発の組の本物の男声(JVNV・VCTK)から最も近い声までの ECAPA の余弦(系 2l の物差し)・高さの域・長時間の平均スペクトル。
  録音の文は Irodori の生成の一部(学習のデータは Irodori の生成だけ・11-01)で、合成の乱し(M16)でも本物の部屋の応答の録音でもない。C の当てる先は各声の自分の音なので、録音の文で作った声の録音は C の学習ではその声の構造の一部になる(推論の目標の参照はきれいな声)。
- **rev28: 段 D3 は H_D3_none(上の系 2l rev28)**: 説明文の型は量を作らない。生成した 96 声(`data/snv_d3`)は学習に使わず記録として残す。

### M2 模型
- Ê(y, 有声; φ̂_o)→ q(u | y, φ̂_o): 因果の膨張畳み込み。操作者の構造(登録)を読む(操作者の回路で説明して外す)。
- F̂(u, lf, 有声; φ̂_t): 因果の描画(回路)。構造は目標の参照から(参照を学習した注意で読む表の型 x・オーナー 11-04 承認)。
- φ̂: 参照(登録)から。学習では同じ声の別の発話。
- **rev2(T5 から)**: 学習の参照を推論の量にそろえる = 同じ声の普通の発話 3 本を最大 10 秒ずつ(約 27 秒)。推論の目標の参照は約 20 秒・操作者の登録は 30 秒で、これまでの学習の参照(2 本を 5 秒ずつ = 約 10 秒)は推論より少なかった(学習と推論の不一致)。構造の推定の精度(A1)は命題 2 の方法の前提(T5)。

### M3 目的(識別の項)
- 内容 w ごとの共有の型 μ_w(内容の中の位置 1..L_w × dim 𝒰・全ての声で共有・学習で求める)と共通の幅 Σ で、p′(u_{1:T} | w) = Π_t N(u_t; μ_w[τ_t], Σ)。τ は発話ごとの単調な対応(フレーム → 内容の中の位置・内容の型への対応を発話ごとに最尤で求める)。系 2c を満たす(u の過去で条件づけない)。
- 損失 = −E_q[log p(y | u, φ̂_s)] + KL(q(u | y, φ̂_s) ‖ p′(u | w))(発話の ELBO)。尤度の尺度は学ぶ(段 T の T4: 固定より少し良い・A1 が成り立つ限り写しへ引き寄せない)。
- A1(構造の推定の精度)は方法の前提: 実データでは段 T の T5 で、A1 を崩したときにも内容の共有の事前分布が写しを防ぐかを確かめてから段 I の構造の推定の形を決める。
- 推論では w も μ も使わない(主張 3)。
- 実装(rev1・`training/train_snv_i.py`): 型の長さ = その内容の発話の長さの中央値 / 8 フレーム(40 ms に 1 つ)。対応 τ は演奏の平均を 4 フレームずつ平均した上で求め(計算量)、学習の切り出し(4 s)に合わせて始まりと終わりは型の途中を許す。
  2 声以上が発する内容だけ型を使い、1 声だけの内容は N(0, I)(段 T: 1 声の型 e 0.443 は N(0, I) の 0.363 より悪い = 系 2b)。内容 = E1 の文(2〜5 声の共有が 1109 文)・段 D の文(8 声・1500 文)・E1-NV の(種類・説明文の番号)(約 300 声)。
- **rev3(段 I の停止から)**: 型 μ_w は、対応 τ を固定したとき KL を最小にする値 = 内容 w の位置 j に対応づけた事後の平均 の平均(閉じた形・EM の M 段)。これを勾配の引数として学ぶと、更新の量が内容の出現の頻度(束の大きさ × 内容の数)に縛られる(段 I: 2,636 内容・束 16 で 1 内容 約 50 回 / 10k step・Adam の一定の引きで最大の移動 0.12 = 型が軌跡を表せない)。
  → 型は内容が束に現れるたびに、対応づけた事後の平均(勾配を止める)で移動平均する(γ = 0.9・最初の出現で初期化・観測の無い位置は最も近い観測で埋める)= 予算が出現の数だけで決まる(VQ の符号帳の移動平均と同じ型)。Σ は勾配のまま。対応の長さは有効なフレームの区間で数える。型と Σ を重みと一緒に保存する(途中の診断のため)。§6 段 T の T6 で、勾配の型を段 I の予算に絞ると効かず移動平均の型は同じ少ない出現で効くことを確かめてから段 I をやり直す。

### M5 境界の拘束(rev5・系 2d から)
- I_q(u; s | w) を直接下げる: 内容の型からのずれ r_t = u_t − μ_w[τ_t](型は止めた値)から学習の声を当てる判別器 Q(因果の畳み込み・学習だけ)を交互に学び、演奏の側は Q の当て(交差エントロピー)を勾配の反転で λ 倍して下げる(分布の段の不変性の正則化・設計三層則の「遮断は分布の段で」)。
  型からのずれで測るので、内容を与えたときの独立(条件付き)になる。型が演奏の座標を声に依らず固定し(命題 2)、判別器は残りの声の符号を罰する = 系 1a の「話者に依らない不変性は回転を残す」は、型と合わせることで閉じる。
- 再現の損失は変えない(尤度の尺度・β・容量を対処に使わない)。声の細部を演奏から外すと自己の reamp の再現は A1 の精度の分だけ悪くなる = それが変換で得られる上限(推論は目標の構造だけで描く)と学習が一致する。
- 推論では Q も型も使わない(主張 3)。

### M6 A1 の精度(rev6・T8 の分かれ道 H_m5_not から)
- 区別: A1 の本人の段(目標の参照から本人と読まれる声を描けるか)と A1 の精度の段(参照から声の細部まで描けるか)。系 2d の力を生むのは精度の段の不足。
- 実データの証拠: 本人の段は表の型 x でおおむね成り立つ(A 線: 外の声の無い調音の表現 EMA を入れた x は目標に M 0.56・天井 0.635)。精度の段は測っていない。段 I の 2 走行では C の参照への注意が一様に近い(最大の重みの平均 0.002・一様は 0.00017)= 演奏が声を運ぶ限り C は参照を読む必要が無く、読む力は学ばれない(近道)。段 T の構造の次元 4 は容量の上限で学習では直らないが、実データの x の読みは学べる形を持つ。
- 測り方: 声の無い演奏の下で(M5 が近道を塞ぐ)、(i) 自己の reamp の検証の L1(声を演奏から外した分だけ悪くなる量 = 精度の段の不足)・(ii) 参照への注意の鋭さ(最大の重みの平均)・(iii) 文の型の説明率(声が外れると同じ文の演奏が寄る = 命題 2 の座標が立つ)・(iv) 変換の M・FF を同時に測る。
- 上げ方(測ってから選ぶ): (i) が大きく (ii) が上がらない → 表の型の読み(鍵 = 参照の演奏・値 = 参照の Y)の形を直す。(ii) が上がり M が上がる → A1 は学習で満たされる = 段 I3 がそのまま方法。

### M7 固い共有(rev7・系 2e から)
- 学習の生成のモデル: 発話 (s, w) の演奏 u_t = μ_w[τ_t] + r_t。μ_w = 内容ごとの共有の軌跡(引数・全ての声の再現の勾配で学ぶ)・τ = 発話ごとの単調な対応(時間の演技)・r = 小さな演技の残差(KL)・高さと有声は明示の入力。y = C(u, lf, 有声; S_s)。
- C は学習で符号器の演奏を見ない(声の近道が無い)。推論の符号器 E は、y と操作者の構造から μ_w[τ_t] + r_t(勾配を止めた値)を当てるように学ぶ = 当てる先が声どうしで共有なので、E の座標は声に依らない。
- 対応 τ: 最初は発話の中の時刻の比・その後は E の出力と型の単調な対応(MAS)。型の学習は稀な項目の引数(実データで 1 内容 約 200 回の出現)= 段 T の予算と比べて lr を決める([[sparse-template-update-budget]] の教訓・閉じた形が無いので勾配で学ぶ)。
- 残差 r は演技の残りを運ぶが声も運べる(系 1b)= 最初の版は r なし(高さ・有声・時間だけが演技)と r あり(KL)を段 T で比べる。
- **rev8(T9 から)**: r なしは演技を失い(回転の無い世界で e 0.651 対 M3 0.291)、r あり(KL だけ)は r が声を運び写しに戻る(e 0.785)。固い共有の下では型が意味を持つので、r から声を当てる判別器(M5)は内容を与えたときの独立 I(r; s | w) を直接下げる(段 I3 の判別器は型が無意味で演奏ほぼ全体に掛かっていた)。= M7 の残差に M5 を掛ける(M7 + M5)。

### M8 学習の残差を持たない固い共有 + 明示の演技(rev11・系 2f から)
- C の入力 = [内容の共有の軌跡 μ_w[τ](59 次元・引数・全ての声の再現の勾配で学ぶ)・明示の演技(5 次元 = 音量 c0 と周期性 4 帯を、その声の参照の平均と標準偏差で標準化・無声の周期性は 0)]・高さ lf と有声(従来どおり)。学習の残差・判別器は無い。
- E は y と操作者の構造から、この 64 次元(軌跡 + 明示の演技)を当てる(勾配を止めた値への二乗誤差)= 推論の経路(E → C)・評価の道具・Rust の p_model は変わらない。明示の演技の部分は E が操作者の登録の統計で標準化することを学ぶ。
- 内容の型の無い発話(1 声だけの文)は C の学習から外す(内容の無い再現になる)。
- 代価: 調音の演技(同じ文を声ごとにどう構えるか)は軌跡の平均に寄る。演技は時間・高さ・音量・息で運ぶ。

### M9 帯の対応の固い共有(rev12 → rev13・系 2g から)
- rev13: 軌跡 μ_w は M8 と同じ内容ごとの引数(全ての声の再現の勾配・lr 5e-3)。rev12 の案(E の出力の対応づけた移動平均 + straight-through)は T11 の回転の世界で声を運び不採用(`results/snv_t11/verdict.yaml`・実装は `--tpl_est ste` として残す)。
- 対応 τ: 発話の中の時刻の比 (off + t) / n_all · L_w を中心に ±δ L_w(δ = 0.1・少なくとも ±1)の帯の中で、E の出力と型の最尤の単調な対応(帯の外は不可・暖機なし)。
- 明示の演技・学習の残差なし・内容の型の無い発話を C と E の学習から外す: M8 と同じ。推論の経路(E → C)は変わらない。
- 学習の途中の健全さ(ログ・打ち切りの規則に使う): 軌跡の切り出しの中の分散 / 束の中の分散(定数への張り付きの検出)・E の内容の当ての誤差 / 軌跡の分散。連結の表現は部分ごとに測る(段 I5 の共有の物差しは E の出力を測り、潰れた軌跡を見ていなかった)。

### M11 M10 + 別の声のずれを見せる C(rev15・系 2h (v) から・rev16 で不採用)
- M10 の C の内容の入力の値に、同じ組の別の声(組の中で順に回す)の同じ位置のずれ sg(ū_{s',j} − ū_{g,j}) を足す(勾配は通さない・別の声がその位置を通らなければ 0・1 声だけの組は 0)。それ以外は M10 と同じ。

### M10 声どうしの平均の軌跡と平均した勾配(rev14・系 2h から)
- 束 = 内容 G 個 × 同じ内容の K 声(K = その内容の声の数と束の大きさの小さい方・切り出しは全員同じ時刻の比の窓)。
- 軌跡 μ_w[j] = 位置 j に対応づけた E の内容の出力の移動平均(勾配なし・束の中の観測を先に平均してから γ で混ぜる・最初の出現で初期化)。対応 τ は M9 の帯。
- C の内容の入力: 値 = μ_w[τ](全ての声で同じ)・勾配 = 同じ組の同じ位置に対応づけた E の出力の束の中の平均 ū_{g,j} を通す(x = μ_w[τ] + ū_{g,τ} − sg(ū_{g,τ}))= 組の全ての声に同じ勾配。
- E の当ての項 ‖u − sg([μ_w[τ], 明示の演技])‖²・明示の演技・学習の残差なし・内容の型の無い発話を外す: M8 と同じ。推論の経路(E → C)は変わらない。
- 健全さ: 軌跡の隣の位置の余弦・E の当ての誤差 / 軌跡の分散(fit)・切り出しの中の分散の比。
- rev17: 段 I7 で勾配の自己の分 ρ = 0.53 が声ごとの押しとして残った(系 2h rev17)→ M12。

### M12 自分を除いた勾配(rev17・系 2h (iv′) から)

- 健全さ: ρ(同じ束の作りで M10 なら残る自己の分)・fit・軌跡の隣の位置の余弦・切り出しの中の分散の比。
- 実装: `--tpl_est gloo`(`training/train_snv_i.py`・`training/train_snv_t.py`)。推論の経路(E → C)は変わらない。

### M13 推論の符号器を回帰だけで学ぶ(rev18・系 2i から)
- G = 学習だけの符号器(EncS・M10: 束の組・帯の対応・声どうしで平均した勾配・当ての項)。軌跡 μ_w = G の内容の出力の対応づけた声どうしの移動平均(M10 と同じ)。C の入力の値 = [μ_w[τ], 明示の演技]・勾配の道は M10 と同じく G へ。
- E = 推論の符号器(EncS・同じ形)。損失は ‖E(y; S_o) − sg([μ_w[τ], 明示の演技])‖² だけ(共有の内容のフレーム)。対応 τ は G の出力で求める。C の参照の鍵 = sg(E(参照))(推論と同じ)。
- 推論の経路(E → C)・Rust の p_model は変わらない(G は書き出さない)。
- 健全さ: E の fit(当ての誤差 / 軌跡の分散)・G の fit・ρ・vr_ct。
- 実装: 段 T は `train_snv_t.py --student`。

### M14 推論の符号器の声の乱し(rev20・系 2j から)
- M13 と同じ(G・C・束・帯の対応・回帰だけで学ぶ推論の E・C の鍵 = sg(推論の E(参照)))。変更は推論の E の入力だけ:
  試料ごとに、発話と、E が読むその声の参照の両方に同じ乱し g_θ を掛ける = 包絡の周波数の一律の伸縮 α ∈ [0.8, 1.25](対数一様・声道の長さの模型)+ 傾き ±0.5(P2b と同じ族・`train_snv_p2_cpc.augment`)。
  当てる先 sg([μ_w[τ], 明示の演技]) と対応 τ は乱していない音から(G の乱していない出力)。加工は入力側だけ(設計三層則)。
- 推論の E は G・C・軌跡へ勾配を返さない(M13)。段 I8 の保存の G・C・軌跡を凍結して推論の E だけを学べば、M13 の推論の E と同じ目的になる(`train_snv_i.py --e_only <段 I8 の last.pt> [--e_aug]`)。
- 推論の経路(E → C → 描画)の形・Rust の p_model は段 I8 と同じ。

### M20 伴奏を分ける前段 = 録音の逆を E の前で学ぶ(rev26・系 2n から)

- 学習: Irodori の学習の声の発話(段 I8 の split の学習の声・48 kHz)を、その場で背景と混ぜる(入力側だけ)。当てる先 = 元の音の前段の特徴(計算済み)。前後に足した無音の当てる先は 0 ベクトル・有声 0(無音の前段の特徴はちょうど 0)。

- 損失の最適: ŷ* = med[y | x̃]・v̂* = P(v | x̃)・l̂f* = med[lf | x̃, v = 1]。声が時間周波数の一部で伴奏より強ければ y・v・lf は識別される。伴奏だけのフレームは当てる先が 0 なので、声の無い入力を「声なし」に写す。声が全ての帯域で伴奏に埋もれたフレームは条件つきの中央値(内容は戻らない)。

- 代価の見込み: きれいな入力で D は前段の特徴を学びで近似するので、その誤差が代価(背景なしの入力での包絡・有声・高さの差と、c_pr の CER の差)。高さの差(セント)は描画の音程の揺れになる。
- **rev27: 製品の経路に採らない(段 I14・H14_sep_none)**: 族の中では伴奏・1/f の雑音・残響・ハムの上の内容を大きく戻す(自己の中央値: 0 dB の伴奏 0.705 → 0.274・pink10 0.805 → 0.158・残響 0.332 → 0.114・rev12 0.843 → 0.397・hum15 0.166 → 0.091)が、本物の操作者の録音へ移らない(試験の伴奏の無い区間の自己 0.149 → 0.390・S 0.750 → 0.653・系 2o)。人の声の背景(babble)は規則で族に無く悪くなる(0.500 → 0.845)。

- 損失の最適: Ê*(x̃) = E[軌跡と明示の演技 | v3(x̃)]。手の音は内容と独立なので、族が覆う手の音の上で最適な Ê は手の音に依らない。手の音だけのフレームの当てる先は、元の音のそのフレームの軌跡(無音・息)= 手の音を内容として読まない。
- 製品の候補 = M22 の E + M15 の C(`training/snv_i10_combo.py`)。前段・C・描画器・推論の経路の形と遅延は c_pr と同じ。
- 段 I15 の切り分け(`results/snv_i15/diag_clap_split.json`)が根拠: c_pr の手拍子の崩れは包絡の側(推論の E が読む入力)だけで起き、有声と高さの側では起きない。

### M23 前段 v3 の時間周波数の重み(rev32・段 I16 の上限から)
- 前段 v3 の計算は変えず、その入力のエネルギーに学んだ重みを掛ける。重み m(t, f) ∈ [0, 1] は 2048 点の左寄せの窓(前段 v3 の周期性と同じ格子・1025 本・ホップ 240)の上で、因果の畳み込み(M20 と同じ網・出力だけ 1025 の重み・初期は 1 に近い)が入力の短時間スペクトルから出す。
- 使い方(`training/train_snv_mask.py` の features): 有声と高さ = 前段 v3 のまま(手の音でほとんど乱れない・段 I15 の切り分け)。周期性 = 前段 v3 の式を、重みを掛けたパワー m² ⊙ P で。包絡 = 前段 v3 の CheapTrick の mel の帯の振幅に、帯の利得 g = √((m² ⊙ P)·fb / (P·fb)) を掛けて対数と DCT。
  = m = 1 なら前段 v3 と 1 bit まで同じ(恒等が作りで決まる)。重みはエネルギーを減らすだけで、包絡の形(共鳴の位置)を推し直さない = 系 2o の代価(本物の声を族へ寄せる)を作りで持たない。
- 学習(入力側だけ): M21 の族(透かし付きの背景・床・帯域・操作者の音・`--fam i15`)の混ぜで、声の成分 S と残り N を分けて持ち、当てる先 = 理想の比の重み |S|² / (|S|² + |N|²)(同じ 2048 点の格子)。損失 = 乱れた音のパワーで重みを付けた L1。
  声の成分は残響と音量と帯域を掛けた後の声(重みは足された音だけを外す・残響は外さない)。
- 損失の最適: m* = E[|S|² / (|S|² + |N|²) | 入力]。声だけの入力では m* = 1(恒等)。手の音だけのフレームでは m* = 0 = 包絡は無音・周期性は 0 = 手の音を声に化けさせない。
- 物差し: 段 I15 と同じ開発の組(本物の手拍子・叩く擦る・伴奏・声の無い時間)・きれいな本物の声で重みが 1 に近いか(VCTK・JVNV・試験の伴奏の無い区間の重みの平均と、前段 v3 との特徴の差)と CER の代価。
- 上限(学習なし・`results/snv_i16/diag_oracle_mask.json`): 理想の重み(包絡だけ)で手拍子 +10 dB の自己 0.125 → 0.000・叩く擦る 0.114 → 0.011・声の無い時間 −4.4 → −59 dB。周期性もきれいなら女声へ 0.172 → 0.022。
- **rev33(段 I17・10k で停止・`results/snv_i17/verdict.yaml`)**: 掛け方は 2048 点の格子の理想の重みで上限に届く(手拍子 0.000 / 0.059・声の無い時間 −58 dB・`results/snv_i17/diag10k_fixed.json`)。学んだ重みは本物の手拍子に移らない(−21 dB)= 族の覆いの不足。
  網はパワーの比を当てるので、features は網の出力の平方根を振幅の重みにする(rev32 の実装は 2 乗していた)。族に本物の手の音を足す(`--fam i18` = i15 + FSD50K の開発の組の手の音・透かし付き・投稿者で分ける)。
- **rev34: 製品の経路に採らない(段 I17・I18 の 2 回・`results/snv_i18/verdict.yaml`)**: 当てる先の比は、手の音が勝つビンで識別できない(系 2q)。声の無い時間の手の音は族の改めで約 10 dB 深くなった(−27〜−31 dB)が、上限(−57 dB)と有声の率(0.087 > 0.03)に届かない。きれいな本物の声の重みの代価(JVNV の包絡の差 0.045)も作りの恒等さを崩す。重み(`results/snv_i18_mask/step10k.pt`)は残す。

### M24 前段 v3 の出来事の判定(rev34・系 2q から・M23 の方向を替える)
- 前段 v3 の計算は変えず、足された出来事の音(手拍子・叩く・擦る)が占めるビンを判定して外す。判定 d(t, f) ∈ {0, 1} は、M23 と同じ網(2048 点の左寄せの窓の格子・因果の畳み込み・先読み 0)が出す確率を 0.5 で切ったもの。
- 使い方(`training/train_snv_mask.py --target det`・保存の kind = det で features が切り替わる): 重み = 1 − d を M23 と同じ掛け方で使う(有声と高さは前段 v3 のまま・包絡の帯の利得・周期性)。判定が出ないビンは前段 v3 と 1 bit 同じ。
- 学習(入力側だけ): i18 の族の混ぜで、声の成分 S・出来事の音 E・残り R(床・伴奏・雑音)を分けて持つ。当てる先 = [|E|² > |S|² + |R|²](同じ格子)。損失 = 乱れた音のパワーの 0.3 乗で重みを付けた 2 値の交差エントロピー。
  床と伴奏は当てる先に入れない = 持続する背景は外さない(伴奏の上の決定の飽和 = 系 2n は本手法の外)。
- 損失の最適: d* = P(出来事の音がビンを占める | 過去の入力)。0.5 で切ると最も確からしい判定になる。声だけの入力では d* = 0(恒等)。声の無い時間の手の音では d* = 1 で外す = 理想と同じ深さ(シグモイドの裾に依らない)。
- 検査 I: 判定の権威は出来事の音のビンの占め方。痕跡(透かし)は声・背景・出来事の音の全てにある(i15 の族)ので近道にならない。声の自分の過渡(破裂・息・笑いの立ち上がり)は声の成分(当てる先 0)として族の中で学ぶ。
  本物の声の過渡(マイクの吹かれ・破裂の音)で判定が出ると、そこで声を外す = 恒等さの代価 → 途中の規則に入れる。
- 上限(学習なし・系 2q の証拠の「判定だけ理想で外す」): 手拍子 +10 dB の自己 / 女声へ 0.049 / 0.130・叩く擦る +5 dB 0.050 / 0.095・手拍子 0 dB 0.041 / 0.111・声の無い時間の手拍子 −57 dB・有声の率 0.005(重みなし 0.103 / 0.153・0.095 / 0.157・0.054 / 0.115・−5 dB・0.111)。
- **rev35: 声と重なる出来事の音には採らない(段 I19・`results/snv_i19/verdict.yaml`)**: 声と重なる所の判定の誤りが内容を壊す(手拍子 +10 dB 0.119・叩く擦る 0.126 対 c_pr 0.103・0.099)。声の無い時間の出来事の音は深く外す(−45.6 dB・有声の率 0.018・恒等 0.0094)ので、声の無い時間を判定する門と組む形で残す(重み `results/snv_i19_det/step10k.pt`)。
- **rev35: M23 の重みを伴奏の前段として評価する(段 I20・学習なし・系 2q (iv))**: M23 は持続する伴奏の上で比が識別できる側にいる。段 I18 の重み(`results/snv_i18_mask/step10k.pt`)を、学習に使っていない音楽(`train_snv_sep.bg_split` の dev の 145 曲)と試験の伴奏の 3 区間で測り、きれいな本物の声の代価(重みの平均 0.60・JVNV の包絡の差 0.045)を CER で測る。
- **rev36(段 I20・`results/snv_i20/verdict.yaml`)**: 伴奏の利得は移った(新しい音楽の 10 dB の女声へ 0.731 → 0.250・試験の伴奏の区間 0.881 → 0.721・製品の CER 0.651 → 0.584)。きれいな本物の声の代価(試験の伴奏の無い区間 0.149 → 0.277)の主は床を外すこと → §5 M25。

### M25 床を操作者の録音に数える比の重み(rev36・段 I20 の切り分けから)
- 網・掛け方・族(`--fam i18`)・予算は M23(段 I18)と同じ。当てる先だけを替える(`training/train_snv_mask.py --target ratio_nf`): |S + F|² / (|S + F|² + |N − F|²)。F = 族の床(色つきの雑音 −70〜−30 dB・ミキサーが別に持つ)。N − F = 伴奏・雑音・出来事の音(足された音)。
- 損失の最適: m* = 条件つきの中央値。床と声だけのビン(声の無い時間の部屋の音・かすかな声)では m* = 1(外さない)= 本物の録音の静かな時間を残す。伴奏と出来事の音が勝つビンでは比(系 2q (iv) で伴奏は識別できる側)。
- 検査 I: 床と伴奏の分けは大きさ(床 −70〜−30 dB・伴奏と雑音は SN 比 0〜20 dB)と持続で決まる。本物の録音の部屋の音は床の側。透かしは全ての成分にある(近道にならない)。
- 検査 C: 重みが伴奏も残す(床と読む)→ 伴奏の条件。重みが声を外す → きれいな本物の声の代価(JVNV・試験の伴奏の無い区間)と、静かなフレームの残すエネルギー。
- 当てる先の違い(族の検証の組・学習なし): 当てる先の平均は伴奏 20 dB で 0.36 → 0.82・伴奏だけの時間帯 0.10〜0.18 → 0.28〜0.83 = M23 の当てる先の「外す」の多くは床だった。
- **rev37(段 I21・`results/snv_i21/verdict.yaml`)**: JVNV と namikawa の恒等は戻り、伴奏の利得は保った(製品の CER 0.592)。族の床より大きい部屋の音の録音(uirou)の代価が残る → 族の床の大きさの域を −70〜−15 dB に広げる(`--fam i22`・段 I22・当てる先と網と予算はそのまま)。床の上限を上げると、SN 比 15〜30 dB の雑音の背景と床が同じ大きさで重なる(持続する色つきの雑音は残す側・音楽と出来事の音は外す側)。
- **rev38(段 I22・`results/snv_i22/verdict.yaml`)**: 床の域を広げても uirou の唸りは外される → 残す・外すの分けを族で直す型は 2 回で打ち切り。重み(段 I21 の 20k)は M27 の門の内側で使う。

### M27 足された音の門(rev38・段 I22 の切り分けから・方向を替える)
- 門 a(t) ∈ {0, 1} = 音楽か出来事の音がフレームではっきりあるか。M23 と同じ網の形(左寄せの窓の短時間スペクトル → 因果の畳み込み・先読み 0)で、出力だけ 1 本(フレームごと)。確率を 0.5 で切る。
- 使い方: 門が開いたフレームだけ、M25 の重み(段 I21 の `results/snv_i21_mask_nf/last.pt`)を前段 v3 の包絡と周期性に掛け、有声と高さを重みで濾した YIN(`snv_p0_front.f0_track_myin`)で決める。門が閉じたフレームは重み 1 = 前段 v3 と 1 bit 同じ(恒等は作りで決まる)。
- 学習(入力側だけ・`--target gate --fam i22`): 当てる先 = [フレームの音楽と出来事の音のパワー > κ × (声 + 床 + 雑音の背景)のパワー]・κ = 0.01(−20 dB)。雑音の背景(MUSAN の雑音)と床は当てる先に入れない = 持続する唸りや部屋の音では門を開かない。損失 = 2 値の交差エントロピー。
- 損失の最適: a* = P(音楽か出来事の音がはっきりある | 過去 1.29 s)。音楽は音の高さと時間の構造を持ち、唸りと部屋の音は持続する = 過去の文脈で分かれる(系 2q (iv) と同じ「過去から推せる」側)。
- 検査 C: 門が本物のきれいな録音(唸り・部屋の音・笑いや叫び)で開く → きれいな本物の声の恒等と代価。門が音楽で開かない → 伴奏の条件。
- **rev39(段 I23・`results/snv_i23/verdict.yaml`)**: 作りの恒等は本物のきれいな録音で戻り、伴奏の利得は保った。門は節の付いた語りで 5〜35 ms だけ瞬き、そこで重みで濾した YIN が有声を入れ替える → 開閉の持続の事前を足す: 門の確率が 0.5 以上で 200 ms 続いたら開き、0.5 未満で 500 ms 続いたら閉じる(因果・学習なし・保存の cfg の hyst = [40, 100] フレーム)。
  伴奏は秒の単位で続き、誤りの開きは数十 ms = 持続で分かれる。出来事の音(手拍子)は短いので持続の門では開かない(声の無い時間の出来事の音は M24 の判定で別に扱う)。
