# 段 1 の基準: 内容の事後 → 条件(e2e_ppg)— status: PROPOSED(rev0・2026-10-18)

計画法(`current/ml_method.md`)の段 1「端から端までの基準」。男声 → 女声の反復が 3 回続けて棄却(rvslm1・rvslm2・diag_condgan1)になり、基準を作らずに部品を磨いていたことへの是正。

## 1. 根拠
- 誤差の分析(`results/LEADERBOARD.md`): 製品の基準の男声 → 女声の偽物らしさの分散の 90% は操作者(入力の男声)で説明される。操作者の発声の質(1〜4 kHz の非周期性 +0.39・音量の揺れ +0.38・暗い傾き −0.36)が出力に持ち込まれている。
- 今の製品の変換は、出力部の条件を操作者の分析値(c0・包絡の動き・周期性)から作る = 操作者の声質がそのまま入る構造。
- 本設計は、操作者から内容(C1 の事後)・高さ・有声だけを取り、c0・包絡・周期性は目標の要約から学習した写像で作る = 操作者の声質が通る道を構造で断つ。

## 2. 構成(推論の経路)
- 前段(固定・因果): Rust の C1(内容の事後 200)・F1(f0・有声)。高さは目標の声域へ移す(操作者の登録の中央値 → 目標の登録の中央値)。
- **E(学習する)**: 因果な 1 次元畳み込み(左寄せ・先読み 0・256 ch・8 層・膨張 1,2,4,8,16,1,2,4・受容野 約 0.6 秒)。入力 = C1 の対数事後(温度 τ で鋭くする = 情報の絞り)+ log f0(目標の声域)・有声 + 目標の要約(目標の参照の条件の有声の平均・標準偏差 58 + log f0 の平均)。出力 = c0・包絡 c1..c24・周期性 4。log f0・有声は入力をそのまま条件へ写す。
- 出力部: rvoc3hi(写し合成で教師並みの条件の空間・D253)。
- 計算: E は 1 フレーム 約 0.4 M MAC(256 ch × 8 層 × 5 タップ)= 製品に載せるときは計算の台帳で確かめる(今の 1 ブロック p99 3.3〜3.6 ms)。

## 3. 学習
- データ: female-dataset の評価外の実女声(診断は 600 人 × 3 クリップ・本番は全量)を 48 kHz に再標本化し、Rust の新しい前段(--causal-ct)で条件(正解)と C1 の事後(入力)を書き出す(`training/d274_data.py`)。TTS は使わない。目標は本物の分析値。
- 自己再構成: 入力 = クリップ A の C1 の事後・f0・有声、要約 = 同じ話者の別のクリップ B、正解 = A の条件。
- 損失: 10·L1(条件)+ 1·LSGAN(条件の 1 秒の窓・要約で条件づけた射影の判別器・D は D273 と同じ形)+ 2·特徴の一致。
- 学習と推論の一致: 入力の種類(C1 の事後・f0・有声・要約)は学習と推論で同じ。違いは C1 の事後が男声から来ること(内容の事後に残る話者の情報)= 下の I で監視。

## 4. 設計三層則(下書き・prereg に転記)
- **L**: L1 の最適 = 条件付き中央値(平均への寄せ)→ LSGAN と特徴の一致で分布の側へ押す。要約が本人らしさの唯一の正規の道。
- **I**: C1 の事後が話者の情報を運ぶと、E は自己再構成でそれを使い、推論で男声の特徴を持ち込む。遮断 = 分布の水準: 事後の温度 τ(鋭く)+ 学習時の入力の摂動(事後に雑音・時間方向のぼかし)。監視 = C1 の事後から話者を当てる探針の精度(学習の前に測る)。
- **C**: (1) C1 の事後の話者の情報から自己再構成する(要約を無視)→ 要約の差し替えの試験(同じ内容で要約を替えると出力の本人らしさが替わるか)。(2) 平均の条件を出す → LSGAN・v1⊥ で検出。
- 人工データを正解の側に置かない(正解 = 実女声の分析値)。VC の教師の蒸留はしない。参照のフレームを検索・複写しない。

## 5. 評価(`results/LEADERBOARD.md` に 1 行)
- 最適化指標: 男声 → 女声の v1⊥ の決定値(dev 3 組 × 60)。基準 = 製品 4.02(dev)。
- 健全性: 保留の実女声の自己再構成の v1(写し合成の水準 0.30〜0.63 に近いか)。
- 満足指標: 本人らしさ(LDA・ECAPA で kNN-VC 以上)・CER。
- 見切り: 学習 30 分で保留の自己再構成の L1 が下がらなければ停止・5k step で男声 → 女声の v1⊥ が基準より 0.4 以上(区間の半幅)良くなければ停止。

## 10. 製品の経路(Rust)への移植(10-19 に試作・既定の経路は不変)
- 対象 = 候補 diag_ppgvoc11 の生成器(TabVoc + CtxEnc)。推論の経路に入るのは生成器だけ(判別器・ECAPA・C1 の内容の一致は学習だけ)。
- 条件の組み立て(artic_vc.rs): 231 行 = [c0n(--causal-ct)・Σ_k p_k T_k / 10(登録の表 × Rust の C1 の事後・既存の表の引きと同じ)・log f0(F1・目標の声域へ)・有声・目標の周期性の 75 パーセンタイル × 有声・C1 の事後 200]。全て既存の部品で揃う。
- rvoc.rs: `D_COND = 31` の固定と `ensure!(d_cond == D_COND)` を cfg の d_cond に置き換える。CtxEnc(1×1 の入力 + 膨張 1..64 の因果 3 タップ × 7 + 残差 + 1×1 の出力)を 200 fps のフレームの水準で状態つきに実装(膨張 64 × 2 タップ = 128 フレームの履歴リング)。
- 書き出し(export_rvoc.py): `tensors()` は R.CConv だけを集める → ctx.out(nn.Conv1d・1×1)を足す。fixture は 231 行の条件で作り、Rust と 1e-4 以内の一致を検査。PyTorch と Rust の鍵名は一致させる(規則)。
- 計算の台帳: pre の入力 31 → 231 で +0.03 GMAC/s・CtxEnc 約 0.17 GMAC/s = 合計 約 +0.2 GMAC/s(rvoc3hi 8.95 GMAC/s の +2.2%)。今の 1 ブロック p99 3.3〜3.6 ms・RTF 0.57〜0.61(MARGINAL)→ 約 0.59〜0.63 の見込み(計測で確かめる)。
- 遅延の台帳: 全て因果・先読み 0(CtxEnc は左寄せ・未来不変性は学習の起動前に 1 bit で検査済み)= 静的遅延は今の経路と同じ(DELAY 5 ms + HOP 5 ms)。
- 着手の条件: 男声 → 女声で解析の線(到達の線 AUC ≤ 0.95 または確認の組で確定の進捗)を通ったとき。今は TTS の入力の局所の床で到達の線に遠い(D295)= 実男声の評価データのオーナー判断待ち。

### 10.2 遅い音色の揺らぎ(10-19・diag_ppgvoc21 → 23 → 24・候補・耳は保留)

- 設計: 包絡の行に遅い揺らぎ z [24, T] を足す(文脈の符号器のずれの後)。学習の自己再構成 = 目標の本物の揺らぎ(包絡 − 表の包絡の 0.5 s 平均 − 区間の平均 → 主成分 8 本へ射影・確率 0.3 で乱数)・交差と推論 = 乱数(固定の統計: 成分ごとの平均のパワースペクトル・標準偏差)。`train_ppgvoc.py --slow_stats`(統計 = results/diag_ppgvoc21/slow_stats.npz)。
