# 研究の未決事項と判断条件

> 整理: 2026-10-13。要件は [README](README.md)、観測と判定は [RESEARCH](RESEARCH.md)。
> 新しい学習ラダーの提案ではなく、現在不足している証拠を示す。従来のY-S1固定ラダーは [保存版](../.archive/docs_2026-10-13_status/current/ROADMAP.md)。

## 1. 到達済みと未達

- 既存部品: Rust登録/推論、部品のparity、ブロックcompute計測、限定的な女声再合成の耳記録。
- 未達: 未知目標への変換の明瞭さ・自然さ・目標話者性の同時合格、実男性/ASMRへの汎化、製品E2E、萌えと制御の成立。
- 現状の表+動き、R、Fの負例から、次の方式が必然的に決まるわけではない。

## 2. 判断に必要な証拠

| 未決の問い | 必要な確認 | 確認後に変わる判断 |
|---|---|---|
| 指標は人の目標らしさを測るか | 既存の目標参照/変換/錨について、受容性と目標らしさの別質問、評価者と試行、指標との一致を確認する | 一致なら話者変換の未達として扱う。不一致なら評価器を開発側で検証し直す。数値の合格線を黙って下げない |
| sourceの構音と話者性を分けた表現があるか | 同じ表現で内容・発音細部を保つ再構成とsource漏れの対照を満たすか | 成立ならtargetの条件づけを評価できる。不成立なら生成器の追加ではなく界面の仮説に戻る |
| 交差ペアの整列・領域差はどこまで影響するか | 整列前後の内容、入力/教師の時間、TTS/実音声、自己/交差の違いを揃えた対照 | 教師/入力の不一致が大きければペアを修正。小さければ表現/学習の説明を検討する。DTW差し替えを全方式のoracle上限にしない |
| 短い診断で何を棄却できるか | データ被覆、反復、学習量、対照、実装一致を宣言し、方式でなく測定対象を特定する | 診断の負例は当該条件に限定。本番比較/昇格はAGENTSの全量要件と全ゲートを満たす |
| 既存部品を繋いだ最新設定は出荷予算に入るか | 同じ重み/設定で実音声の未来不変性、静的台帳、実ストリーミングcomputeとI/O込みE2E | PASSならその構成の速度証拠。FAILなら性能/因果性の制約を明記。旧構成のRTFを流用しない |
| 萌え・息・囁き・連続制御は成立するか | 基礎変換成立後、方向・他軸・選好・受容性・ライブ応答を個別に確認する | 成立した軸だけを製品判断へ。通常会話のCERや話者top-1で代替しない |

これは検査の起動指示ではない。新しい実験は、競合する説明、対照、出力差があること、合否によって異なる次の判断を明記してから選ぶ。診断の新規聴取は、過去の「解析で合格する前に提示しない」というオーナー境界を継承する。

## 3. 評価集合の扱い

- D136〜D142の60組は繰り返し構成選択に使った評価集合であり、未使用の最終評価として再利用しない。
- D144はその時点では未使用の目標/文だったが、その後のD145以降で開発に使った。未使用の実男性話者集合ではなく、以後の最終評価集合でもない。
- 新しい最終評価の話者/文/参照の重なりと声優単位の独立性は未監査。char_idを別人物の保証にしない。
- 平均CER・中央値・件数・裾、話者単位の不確実性を併記する。sourceのASR文字起こしを基準にした差分CERを正解台本に対するCERと混同しない。
- proxyは必要条件。proxy PASSでも耳による採用を省略しない。耳FAILと、欠測/未検証を区別する。

## 4. 保持する制約

[README](README.md)、AGENTS、[design_laws](design_laws.md)、[EVALUATION](EVALUATION.md)の要件を維持する。E2E p95 <30ms、≥50ms失格。学習前L/I/C、長時間学習前Shipping Gate、全量データ、実音声教師、Rust推論、VC teacher蒸留禁止、耳による採用を今回の整理で変更しない。
