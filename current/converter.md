# 変換器 — 構音目標表 × 学習した動き (status: PROPOSED・rev1・2026-10-02・学習未起動・レビュー 1 巡目を反映・表の引きはオーナー判断 A で可)

全体は [a2vc.md](a2vc.md)(物理は骨格とつまみ・話者と細部は学習)、出力部は [renderer.md](renderer.md)、構音の物理は [artic_inv.md](artic_inv.md)。
オーナー判断: 物理は骨格とつまみに限定(10-01)・参照 ≥ 10s・目標は女声に限る(10-01)・構音モデリングを続ける(10-02)。
**本書の規則**: §4 の C0 が全て数値の合否で埋まり、レビューで重大が出なくなるまで、C1・C2 は起動しない。

## 0. 役割と界面
- 入力: 元の音声 48kHz(因果)・目標の参照 ≥ 10s(登録時に 1 回・非因果可)。元話者の音域は因果な走行推定(登録の数秒は split-half で中央 4.3 半音ずれる = 使わない)。
- 出力: 出力部の条件(200fps・31 行・renderer.md §1 rev2)= CheapTrick 包絡の DCT c0..c24・log f0・有声・4 帯の周期性(倍音の山谷比)。
- 正解の作り方: 出力部と同じ分析(`training/pae.py`・中心揃え・教師側だけ)を目標の実音声に掛ける。変換器は因果な入力からそれを予測する。
- 遅延: 内容符号器 先読み 0 + 変換器 先読み 0。台帳 = 出力部の DELAY 5ms + ブロック 5ms + 内容符号器の予備 10ms。io 周期がブロック(5ms)より短い場合は計算の緩衝 1 ブロックを台帳に足す(C0-4)。

## 2. 構成
```text
登録(1 回)
  参照 ≥ 10s → 内容符号器 E_c → 単位の事後 p(u|h) ─┐
             → CheapTrick 包絡の DCT c1..c24 ─────┴→ 構音目標表 T[u](K × 24)と動きの表 D[u, 位置](C0-6 の結果で採否)・f0 の分布・周期性の平均
ストリーム(5ms ブロック)
  x → 因果 log-mel → E_c(因果)→ p_t = p(u|h_t)(K 次元・G に渡す内容はこれだけ)
    → 表の引き ê_t = T[argmax_u p_t[u]](硬い引き・柔らかい引きは平均へ潰れる: c1_1)
    → 因果 YIN(オクターブ補正)→ log f0_out = log f0_src − (走行の中央値_src) + μ_tgt + 音域つまみ   [骨格]
    → c0(元のレベル)・有声(元)                                                             [韻律]
  G(因果)[p_t, ê_t, log f0_out, c0, 有声, FiLM(表の要約)] → Δc_t → c1..c24 = ê_t + Δc_t・周期性   [学習した動き]
  つまみ(表に掛ける): 声道長 α(mel 軸の伸縮・α = 1 で恒等を assert)・母音空間 s(表を平均の周りに拡大縮小)・萌えの方向
```
- **構音目標表**: 目標が各単位で狙う包絡の形。参照から決定的に作る。話者の静的な部分の担い手で、つまみの作用点。物理の管(artic_inv1)は、つまみを表に掛けるときの差分として使う。
- **表の仕様**: K = 200(C0 で 50 と比べて決める)・コードブック = 学習話者だけの ContentVec 単位(評価話者を含めない)・soft の温度は C0 で決める・参照に無い単位は最も近い(コードブック空間で)収録単位の値。
- **G**: 表から外れる部分 = 単位の中の動き・文脈依存の調音結合。恒等初期化(Δ = 0)。G には元の包絡も高次元の内容特徴も入れない(事実 3・漏れの経路を断つ)。
- 周期性: 元の周期性は使わない(男声の測定の傷を写す)。G が内容・有声・目標の平均から出す。
- **f0 の経路(事実 11)**: 生の因果 YIN の誤りが写し合成で PESQ 0.86 に相当する。因果な f0 推定器(harvest を教師にした学習・オクターブと有声判定の誤りを測る・先読みは内容符号器の予備 10ms の内)を C1 と並ぶ部品として設計する(C0-9 で、因果 YIN・オクターブ補正つき YIN・学習した推定器の写し合成 PESQ を出力部 A の重みで比べる)。

- 検査 L(C2): 自己再構成の回帰の最適は E[c | 内容の文脈・表]。表から予測できる話者の動き(C0-6 で測る)は学べ、予測できない動きは平均へ潰れる(事実 6)。**合格線は C0-6 の数値から決める**(届く根拠のない線を置かない)。
- 検査 I: 話者の権威 = 表(と FiLM)。漏れの経路 = p_t(内容符号器が運ぶ元話者)。遮断: (a) G に渡す内容は K 次元の事後だけ・(b) C1 の教師は単位の事後(ContentVec の連続値は元話者を運ぶ)・(c) 入力側の摂動。探針: p_t からの話者の線形探針(C0-2)。
- 検査 C: ずる = 表を無視して平均の話者を出す(自己再構成が罰する)・内容から元話者を写す(p_t の探針と交差の単位平均の一致が罰する)・ê_t をそのまま出す(自己再構成の動きの項)。
- 正解は全て実音声(加工なし)。DTW で伸縮した軌道は使わない(design_laws §3-4)。

## 3c. C3(出力側の同一性監督)の設計 rev0(2026-10-05)
基準線 = P0(§4d・表を引くだけ): ECAPA 0.551 / WavLM 0.151。天井 = 写し合成 1.000 / 0.800。出力部は同一性の足を引っ張らない(P0 = 従来)ので、変換器 G を出力部(凍結)の**上流**で学習し、同一性の損失を**出力の波形**で測る。
```text
ソース側(男声の因果の特徴・全て凍結): C1(単位の事後 p_t)・F1(f0・有声)・元の c0(CheapTrick・[.25,.5,.25] 平滑)
目標側(登録時に前計算): 表 T[u](24 × K)・f0 の中央値 μ・周期性の 4 帯の平均・参照の ECAPA / WavLM-SV の埋め込み(参照 ≥ 10s)
G(因果 TCN ・ 約 1M・恒等初期化 Δ = 0): 入力 [ê_t = T[argmax p_t](平滑 w = 5)・p_t(K 次元)・log f0_out・c0・有声・FiLM(目標の要約: 表の平均 + μ)] → Δc_t(24)+ 周期性の補正(4)
条件 = [c0・ê_t + Δc_t・log f0_out・有声・周期性] を [.25,.5,.25] で平滑 → 出力部(凍結・EMA)→ y
```
損失(出力 y に対して): L = λ_id·(1 − cos(ECAPA(y), e_tgt)) + λ_c·KL(p_src‖q(y)) + λ_Δ·(‖Δc‖² + 隣のフレーム差の二乗)+ λ_p·(周期性の補正)²。
- L_id: 出力側の同一性監督(CIPT・memory cipt-cross-identity-plan: 出力の cross-identity を一度も学習していないことが天井の根因だった)。**学習は ECAPA だけ**・評価は ECAPA と **WavLM-SV(学習に使わない独立の検証器)**: ECAPA だけが上がり WavLM が上がらなければ検証器への「ずる」(fooling)。
- L_c(内容の錨): q(y) = softmax(ContentVec(y)·コードブック / τ)(C1 と同じコードブック・τ = 0.05)・p_src = 同じ式でソースの音声から。時間格子は同じ(出力部の DELAY 5ms を除く)。
- 正則化: Δc は小さく・時間的になめらか(包絡の 4〜15Hz の変動の上限・§5「安定」)。Δc を話者の変動の部分空間(学習話者の表の差の PCA 上位 m 成分)に限る版を比べる(つまみ = 骨格と調音の思想・検証器を騙す自由度を減らす)。
- 抜け道(検査 C): ECAPA の穴を突く波形(同一性の損失だけ下がる)→ WavLM が不変・内容の KL・音質(線・hf・contrast)で検出。内容が壊れる(話者を作るために音素を潰す)→ L_c と CER 代理(ContentVec の単位の一致率)。
データ: ソース = VCTK の男声(評価に使わない 23 人)+ JA TTS 男声(学習用)。目標 = 学習話者の女声(実 2,775 + TTS 669・参照 ≥ 10s の表と埋め込みを前計算)から毎回ランダムに(男 → 女・整列不要・正解波形なし)。区間 2 秒 + 左文脈 1.5 秒(C1・F1 の受容野)・バッチ 8・約 20k step。
評価: P0 の 225 組(VCTK 評価話者・目標は学習に使わない 45 人の女声)+ 内容(ContentVec の単位の一致率)+ 音質(出力部の線・hf・contrast)+ 安定(Δc の変動)。日本語の評価は別(C0-7)。

## 3b. 部品 F1: 因果な f0・有声推定器(C0-9 で必要と決定・表の原則の判断に依らない)
- 役割: 元の音声から、出力部の f0(harvest の軌道 = フレーム t の中心 tH)を因果に推定する。製品の f0 の誤り(オクターブ 8%・有声判定 約 2 割)を除く。
- 入力: 因果 log-mel(内容符号器と共有の前処理)+ 因果 CMNDF 2 窓(48kHz・10ms / 25ms・最新の窓を基準・遅れ 20〜960 を対数 160 点(F1 rev2・f0_range.md・以下の数値は rev1))+ log エネルギー。先読み 0。段差 f0 の整列は 10ms 窓で教師の +2 フレーム(`training/f0est.py` selftest)。F1 起動前レビュー 1 巡目(重大 3)を反映: 基準窓を最新へ(旧版は 30〜40ms 遅れ)・男声の教師の f0_floor を 60 に揃える・合格線は遅れ補正と切り替わり ±2 除外の値で。
- 出力: 有声の確率(BCE)+ log f0 の 20 cent 刻みの分類(50〜1100Hz・ガウスでぼかした正解・CE)。f0 = 最大の近傍の重み付き平均。
- 教師: harvest + stonemask(女声は data/rvoc_f0 の前計算・男声は VCTK の評価話者以外・JA TTS 男で新たに前計算)。男女 1:1。
- 合格(held の男声 = VCTK 評価男声・女声 = held21): オクターブ誤り < 1%・有声の取りこぼし / 誤検出 < 5%・出力部 A の写し合成 PESQ(held21)≥ 2.2(生の YIN 1.65・harvest 2.51・2 フレーム遅れの harvest 1.99 が目安)。
- 検査 L: 各フレームで過去の音声が与えられたときの音高の事後分布の最頻値。オクターブの曖昧さは文脈(直前の音高)で解ける分だけ解ける。I: 権威の衝突なし(単一の課題)。C: ずる = 話者の平均の音高を出す(CE が罰する)・YIN を写す(オクターブで罰される)。
- 出荷: 閾値と最大値を含むので、未来不変性は実音声のプローブ・quantity=False・無音の書き換えで(白色雑音は偽 PASS)。
- データの不足: 男声は英語(VCTK)と、その声を元にした日本語 TTS 47 声だけ = 日本語の実男声が無い(製品の主入力)。日本語の実男声のコーパスを足すかはライセンスが絡むのでオーナー判断の候補。

- **f0est1 の結果(2026-10-02・不合格)**: 生の YIN の誤りをほぼ半分にし(女声 オクターブ 8.2 → 3.7%・取りこぼし 20.7 → 10.1%・誤検出 23.2 → 13.0%)、写し合成 PESQ 2.48(harvest 2.51)だが、合格線(オクターブ < 1.5%・有声 < 5%)に届かず。雑音のバグで事前登録と条件が違う。女声の誤検出の 7 割は本当の誤り(息・ささやきを有声と言う = ASMR でブザーの危険)。取りこぼしの大半は教師の有声判定の甘さ(pYIN も無声)。→ f0est2(雑音の修正・受容野 1.27s・副次の判定 = pYIN と harvest が一致するフレームでの誤り)。
- **f0est2 の結果(2026-10-02・不合格)**: 主 女声 オクターブ 3.25%・取りこぼし 10.6%・誤検出 12.2%(f0est1 とほぼ同じ)。割れていないフレームでは オクターブ 0.4〜0.7%・男声の有声 2.5% / 5.8% と合格水準に近いが、**女声の誤検出 11%**(両方の参照が無声のフレーム・生の YIN も 12.7%)が残る。次: その中身と、出力部でブザーになるかを測る(ASMR のささやきへの影響)。

## 6. 原則との照合(オーナー判断が要る)
- 表の引き ê = Σ p(u|h) T[u] は、内容をキーに目標の参照を引いて単位で平均する = **検索型の要素を含む**(kNN-VC も k = 4 の平均)。違いは、フレームを写さず単位ごとの平均(話者の構音の目標)に要約し、出力は G が生成する点。
- 代わりの案(静的な話者埋め込み + AdaIN/FiLM のみ)は実測で弱い(E1 23%・静的写像 0%)。
- **オーナー判断(2026-10-02): A = 表の引きを使ってよい**。設計上の線(自分で課す): 表は登録時に作る単位ごとの平均(K × 24 の包絡の数値)に限り、参照のフレームや音そのものは写さない。出力は G が生成する。表は構音のつまみ(声道長・母音空間・萌え)の作用点。
